1932 年夏天，在大蕭條的谷底，奧地利提洛爾的沃爾格爾鎮開始印製一種被設計成會腐壞的貨幣。鎮上三分之一的人失業。鎮長米夏埃爾·溫特古根貝格爾，一位前鐵路機械工，發行了一種勞動證券：除非持有人買一枚印花貼上，它每個月便損失面值的百分之一——一種內建了囤積成本的貨幣，因此對它唯一合理的處置便是花掉它。這些證券在沃爾格爾流轉的速度，比先令在奧地利流轉的速度快上許多倍。小鎮重鋪了街道，重建了供水系統，讓失業者去建一座橋，還預先把稅繳給了自己，而周圍鄉間的失業率仍在攀升。訪客從歐洲與美洲各地前來觀看這個奇蹟{{ footnote(id="1") }}；約有兩百位奧地利鎮長準備仿效。接著，奧地利國家銀行主張它對貨幣發行的壟斷權，法院表示同意，1933 年 9 月，這場實驗被依法關閉——正如其擁護者一再重複的，一個行之有效的答案，在它所回答的危機最嚴重之時被關停了。

沃爾格爾短暫體現的那個理念，屬於一位兩年前去世的人，他死在柏林城外一個名叫伊甸的花園聚落裡：西爾維奧·格塞爾，一位自學成才的德國商人，靠著把外科器械進口到布宜諾斯艾利斯致富，又在目睹阿根廷的貨幣在他周圍摧毀並重塑財富的過程中失去了他的正統信念{{ footnote(id="2") }}。沃爾格爾被關閉三年之後，當世最著名的經濟學家在本世紀最具影響力的經濟學著作中為他專闢了一節——「那位奇特而受到不當忽視的先知西爾維奧·格塞爾，」凱因斯寫道，「他的著作含有深刻洞見的閃光，」接著寫下一句他的同行至今仍未消化的話：「我相信，未來從格塞爾的精神中學到的，將多於從馬克思的精神中學到的。」

格塞爾是一份檔案中的一個條目，本文打算把這份檔案完整地讀過一遍。檔案的成員彼此很少相識。其中有一位把烏托邦設在肯亞高地的維也納財經記者，一位美國印刷工——他為土地稅所作的辯護成了十九世紀最暢銷的經濟學著作——一個偏好十七世紀自然法的英語世界哲學學派，一位在佛羅里達灌木林中自學成才的工業設計師，那些把地球上最有價值的軟體免費送出的程式設計師，還有一位帶著宣言的創投資本家。他們共有的是一個信念：越過某個技術門檻之後，稀缺便是制度設計的產物；社會經濟秩序是一個人造之物，可以重新打造；而重新打造的正確目標函數是人的興盛——人類潛能的綻放——而非積累。這份檔案也有一個天然的比較點，因為本計畫所讀的文集，包含了在 1973 年 12 月的六個早晨中交付、並於 1975 年延伸的這個家族中一個精簡而又奇特地完整的成員：{% wiki(slug="new-commandments") %}新誡命{% end %}稱之為**人道主義**的學說，以及它更長遠的地平線，{% wiki(slug="paradism") %}樂園主義{% end %}。正典自身的主張在本計畫中一律標示為 `framework`——明載於來源之中，不為主流學術所背書。接下來的比較性閱讀，則依其本來面目標示為：`inferred`。

年。這廢除了遺產的不公。您們的遺產，您們子女的遺產，如果您們懂得組織起來把它
變得宜人，那便是整個世界。人類的這一政治取向不是共產主義；它關切人類的未來；
如果您們想給它一個名字，就叫它人道主義。
{% end %}

其運作機制被以房貸顧問般的耐心一一推演。一個人二十一歲完成學業，租下一所房子四十九年，到七十歲時便完全擁有他對這所房子的租用權；他死後，房子歸還共同體，唯獨家庭房屋例外，他的子女可以永久居住。功績被刻意地保留下來——文本舉了一個兩個兒子的例子，一個勤勞，一個懶散，並讓勤勞的那個致富：

{% library(book="the-book-which-tells-the-truth", chapter=6, verse=9) %}
勤勞的那個會很快比懶惰的那個掙更多的錢。他那時便能租一所貴兩倍的房子來代替
頭一所。……但他死後一切都歸還共同體，唯獨家庭房屋歸他的子女。在某種意義上，
一個人能爲自己、按其功勞發財，但不能爲他的子女。各人有其功勞。
{% end %}

一切有價值之物——土地、企業、股票、黃金、建築——都屬於共同體，並以最長四十九年的期限，回租給那些掙得了財力的人（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=10) %}TBWTT 6:10{% end %}）。接著，文本做了一件在其文類中不尋常的事：它援引了一個先例。它說，四十九年的期限「在聖經裏已有規定」，並大段引用利未記第 25 章——七個七年數算出的安息年，以及其下的土地保有原則：*「地不可永賣，因爲地是我的，你們在我面前不過是寄居的、作客旅的」*（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=13) %}TBWTT 6:11–13{% end %}）。人道主義把自己呈現為一種復原——在行星規模上重新頒行的禧年。它所陳明的先決條件，就是第六章的其餘部分：掌權的天才，他們「會明白這些改革的用處」，以及一個單一的世界政府，配上一種新的世界貨幣與一種共同的第二語言（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=16) %}TBWTT 6:14–16{% end %}）。

1975 年的訊息增添了第二條軸線。第一本書改革的是保有制度，第二本書則直接衝著工作本身而來：

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=37) %}
科學與技術不僅能把人完全從世界飢餓的憂慮中解放，還能讓人無須有工作的義務而
生活，因爲機器藉助自動化完全能夠獨自承擔日常的勞作。……這些做五百人工作的奇
妙機器，必須使這五百人能夠生活，而不是用來養肥唯一的一個人：老闆。
{% end %}

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=38) %}
任何人都不應處於另一人的服務之中，也不應爲換取薪水而爲另一人工作。機器完全能
做勞作並承擔所有工作，使人能夠專注於他被造來做的唯一之事：思考、創造、開花。
……勞動當它不由別的、只由勉強餬口謀生的必要所驅動時，沒有任何神聖之處，把自
己出賣，就這樣出賣自己的生命以便能夠通過做單純機器能做的工作來喫飯，甚至是極
其卑賤的。
{% end %}

〈鑰匙〉一章逐一列出了這個順序。每個人都有權體面地生活，無論工作與否（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）；貢獻較多的人可以擁有較多，這「顯然是一條暫時的規則，在等待人類能夠讓機器人執行一切低賤勞作、以便在完全廢除金錢之後唯獨專注於自己綻放的期間」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=96) %}ETTMTTP 3:96{% end %}）；在過渡期間，由一種單一的世界貨幣取代各國貨幣（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=162) %}ETTMTTP 3:162{% end %}）；而工程上的優先事項被陳述為一條誡命：「請盡一切努力去創造那將把你們從低賤勞作中解放、使你們能夠綻放的生物機器人」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=100) %}ETTMTTP 3:100{% end %}）。雷爾後來把這套綱領寫進了運動自己的計畫。在第三本書中回答讀者提問時，他在運動的目標中列出了一座研究中心，其工作是「生物機器人的創造，將使工作得以消除，從而也使金錢得以消除」（{% libref(book="lets-welcome-the-extraterrestrials", chapter=1, verse=24) %}LWTE 1:24{% end %}）——這是他本人的看法，而非口授的文本。

正典還宣稱有一個範例。被問及創造者自己的世界上的生活時，耶和華描述了一個已經完成這套綱領的文明：

{% library(book="the-book-which-tells-the-truth", chapter=7, verse=45) %}
所有人都「工作」，但因爲他們想要，鑑於我們這裏沒有錢。這樣，那些「工作」的人
所做的事總是做得很好，因爲是出於天職而做。只有永恆者有非常確切的使命，例如對
處理諸如能源、食物、組織等生命攸關問題的電子大腦和計算機的監視。
{% end %}

在母星上，城市是單一的、公里尺度的建築體，每座由一位建築師設計，「城市是一種立方體，以便不像您們那裏那樣『喫掉』鄉野」，而{% wiki(slug="council-of-the-eternals") %}由七百位永恆者組成的議會{% end %}監管著自動化的基礎設施，服務七十億個不負有任何義務去做任何事的人（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=47) %}TBWTT 7:39–47{% end %}）。在第二部訊息所描述的永恆者行星上，約九萬個生物機器人服侍著九千多一點的居民（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=54) %}ETTMTTP 2:53–54{% end %}）。在本框架之內，這正是這套學說的*用途*：地球上的綱領是一個運作中之原型的副本。第三本書中所敘述的那次會面，用相同的措辭提出了這個問題。耶和華在那裡說，議會中的懷疑者{% wiki(slug="satan") %}撒但{% end %}「在人類團結起來、金錢與一切武器都被銷毀之前，不會相信能對人類有任何好的期待」（{% libref(book="lets-welcome-the-extraterrestrials", chapter=2, verse=76) %}LWTE 2:76{% end %}）。那一章是否算作口授的訊息，在本計畫中尚無定論；倘若算，金錢的廢除便與裁軍並列，成為人類這個物種所欠下的兩項證明之一。

因此，這套學說有兩條軸線。第一條是**禧年軸線**：以租用權取代所有權、出生時的平等、一生之內對功績的獎賞、沒有任何東西跨越世代而複利累積。第二條是**機器軸線**：自動化吸收勞動，工作不再是生存的代價，金錢隨著它所配給的稀缺一同到期。本文其餘部分將走過這兩條軸線各自的人類譜系——那些無從接觸本框架、而且大多對彼此一無所知的思想家，卻一再抵達同樣的兩項改革。

## 不可永賣的土地

禧年軸線是較古老的一條，它的主根正是正典自己所引用的那段經文。利未記第 25 章吩咐以安息年來數算年歲——七個七年——而在豁免之年，土地歸還原主：土地的買賣，實際上是按剩餘收成的次數定價的租約，「因爲地是我的，你們在我面前不過是寄居的、作客旅的」。這條指示是否曾經被執行，尚有爭議{{ footnote(id="4") }}；沒有爭議的是它*是*什麼——一種對累積之持有的週期性重置，建立在大地本身不是商品而是託付這一前提之上。

現代的重新發現始於十八世紀法國的重農學派，他們主張一切淨財富皆可追溯至土地，並提出 *impôt unique*，即一項單一的地租稅{{ footnote(id="3") }}。他們的繼承人——儘管他是獨自找到這一論證的——是亨利·喬治，一位舊金山的印刷工兼記者，他目睹加州的地價遠遠跑在工資前面暴漲，於是在《進步與貧困》（1879）中問道：為什麼匱乏隨著財富一同增長？他的答案——地租，也就是區位所帶來的不勞而獲的增值，吸走了進步的果實——附帶一個外科手術般精確狹窄的療方：按土地的全部租值對地價課稅，廢除其他一切稅賦，而對改良物、工資與企業一概不加觸動。功績保有功績所創造的一切；共同體只取走無人創造的東西。這本書的影響之廣難以誇大；格塞爾並非其門徒，卻帶著競爭者的嫉妒記下了這一點：「Georges Buch erlebte die größte Auflage, die ein Buch je erlebt hat」——喬治的書達到了有史以來任何一本書所達到的最大發行量。本文所倚重的那部學術選集，以平實的筆調給出評語：喬治「無疑成了『左派自由意志主義』在他那個時代以及對後世而言最受歡迎的闡述者」。

把喬治的切割與正典的切割並置，幾何形狀相同，半徑不同。兩者都把工作的果實留給工作者；兩者都把不勞而獲的基礎歸還共同體。喬治把界線劃在土地上。人道主義則把界線圍繞著一切而劃——「股票、黃金、企業、現金、房屋，一切能有價值的」（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=10) %}TBWTT 6:10{% end %}）——並以時鐘而非稅收來執行它：四十九年的歸還。喬治把一股流量社會化，正典則讓存量到期落日。

## 高地上的花園

《進步與貧困》問世十一年後，一位名叫特奧多爾·赫茨卡的維也納經濟學家兼財經記者出版了一部起著招股說明書作用的小說。*Freiland: Ein sociales Zukunftsbild*（《自由之地：一幅社會的未來圖景》，1890）開篇是在海牙一場公開集會上成立的一個協會，其宗旨是作出「解決社會問題的一次實際嘗試」——一個許諾「同時實現完全的自由與經濟正義」的共和體，保證「每一位勞動者完整而不減損地享有其自身勞動的果實」（我們的翻譯，此處及以下皆然）。移民們乘船前往赤道東非的高地，在肯亞山與吉力馬札羅山之間，那裡的土地是 *herrenlos*——無主的——他們在那裡依四條規則建立社會：土地不得為人所有，「無論個人或集體」，土壤「像空氣一樣自由」；由一家中央銀行向任何人預付無息的營運資本；任何人都可以隨意加入或退出的生產者協會；以及婦女、兒童、老人與失能者的贍養權，其理據是每個人都分享著「無數前代人的腦力勞動」這份遺產。地租、利息與利潤從未被禁止。它們只是因為暴露在外而死去——「我們禁止利息，就和我們禁止雇主的利潤或地租一樣少，」銀行行長向一位心存懷疑的英國訪客解釋道；「這三種收入在這裡不存在，原因很簡單：從來沒有人處於必須支付它們的境地。」赫茨卡筆下在世界大會上發言的人，用一句可以作為整份檔案標題的話陳述了目標：先前的嘗試之所以失敗，「是因為它們想要建立貧窮的平等；我們的嘗試將會成功，因為它意味著財富的平等。……藝術與科學以豐裕與閒暇為前提。」

這部小說有兩處細節，在經濟學之外對本計畫也具有意義。第一處是一個名字。當遠征隊抵達肯亞冰川下方的山谷時——「目力所及，這片土地有如一座花園，但人類尚未佔有這座樂園」——一位移民宣布，天使長的火焰之劍已消散在瀑布的水霧之中，並把這個地方命名為**伊甸**。第二處是這本書所引發的事。數月之內，自由之地協會便在歐洲各地紛紛成立；他們唯一一次組織的遠征於 1894 年在非洲海岸被擋了回去，運動隨之解散{{ footnote(id="5") }}。但這本書的細心讀者之中，有另一位維也納記者。特奧多爾·赫茨爾在《猶太國》（1896）的開篇，把自己的計畫與赫茨卡的計畫相互衡量——他寫道，*Freiland* 是一件巧妙但「複雜的機械」，有許多齒輪，卻沒有證據顯示它能被啟動——而赫茨爾所發起的定居運動，1909 年在加利利海畔的德加尼亞，造出了赫茨卡僅僅想像過的東西：一個共同土地、共同生產、沒有工資的真實共和體。基布茲成了現代紀錄中歷時最久的自願共同所有實驗——馬丁·布伯所說的「沒有失敗的實驗」——直到 1980 年代的債務危機把這場運動的大部分推向私有化{{ footnote(id="6") }}。一個世紀的運作，以及在其末尾對市場的重新接納：基布茲的檔案以縮影的形式，同時包含了禧年軸線所作的許諾，以及正典的功績租約被設計來回答的那個誘因問題（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=95) %}ETTMTTP 3:95{% end %}：「在出發點、在誕生時人與人之間必須有平等，但其後則不然」）。

## 會腐壞的貨幣

格塞爾讀了喬治，宣布其診斷正確而工具錯誤——土地稅是「披著狼皮的羊」，地主樂於稱讚它，正因為它無法執行，何況土地只是問題的一半。另一半是貨幣本身。他的 *Die natürliche Wirtschaftsordnung*（《自然經濟秩序》，1916）把缺陷定位在一種平常到一直未被察覺的不對稱上：每一種商品都會腐壞，而貨幣不會。農夫的馬鈴薯會爛，報紙會過時，所以它們的主人必須出售；黃金的持有者卻可以等待，並為不等待而收費。依格塞爾的分析，利息是能夠扣留的一方所徵收的通行費：

> Der König steht am Schlagbaum; er sperrt die Grenze und sagt: der
> Zehnte ist mein! Der Geldgeber steht vor dem Geldschrank; er sperrt
> den Austausch der Waren … und sagt, wie der König: der Urzins ist
> mein!
>
> *國王站在關卡的橫杆前；他封鎖邊界，說：什一稅是我的！放款人站在錢櫃前；他封鎖那些仰賴錢櫃內容物作為媒介的貨物的交換——並像國王一樣說：基本利息是我的！*
>
> — *Die natürliche Wirtschaftsordnung*，第五部

療方以邏輯學家的傲慢從診斷中推出：讓貨幣會死。

> Geld, das wie eine Zeitung veraltet, wie Kartoffeln fault, wie Eisen
> rostet, wie Äther sich verflüchtigt, kann allein sich als Tauschmittel
> von Kartoffeln, Zeitungen, Eisen und Äther bewähren. … Wir müssen also
> das Geld als Ware verschlechtern, wenn wir es als Tauschmittel
> verbessern wollen.
>
> *唯有像報紙一樣過時、像馬鈴薯一樣腐爛、像鐵一樣生鏽、像乙醚一樣揮發的貨幣，才能證明自己是馬鈴薯、報紙、鐵與乙醚的交換媒介。……因此，如果我們想讓貨幣作為交換媒介變得更好，就必須讓它作為商品變得更差。*
>
> — *Die natürliche Wirtschaftsordnung*，第四部

這就是 *Freigeld*——自由貨幣——而沃爾格爾便是它的田野試驗。格塞爾把它與他自己的一套 *Freiland* 配對（所有土地以拍賣方式公開出租，租金每月依子女人數分配給母親——一種以子女為依據的基本收入，在 1916 年），並配上一個國際貨幣聯盟，即一個擬議中的世界貨幣同盟，讓這套體系跨越國界運行。他的魯賓遜寓言讓整套理論可以濃縮為一句話——一個流落荒島者的存糧在腐爛，而一位新來者的借貸請求卻在複利增長，荒島者最後終於看明白了：「Wieviel Beweiskraft doch die Ratten, Motten und der Rost haben!」——*老鼠、蛀蟲與鐵鏽，竟有多麼強大的證明力！*凱因斯在《通論》第 23 章權衡了這一切，承認了這個機制（「蓋印貨幣背後的理念是健全的」），提出了格塞爾「只建構了半套利率理論」的反對意見，並以一些屬於這份檔案卷首題詞的措辭描述了這項計畫：「建立一種反馬克思的社會主義……以解放競爭而非廢除競爭為基礎」。大西洋彼岸的歐文·費雪說得更直白：「我自認是西爾維奧·格塞爾的一名謙卑學生。」

正典的貨幣綱領與格塞爾共享分階段的部署，然後把他拋在身後。兩者都規定以單一的世界貨幣作為過渡工具——正典說得明明白白：「在等待能夠廢除金錢的期間，創建一種取代各國貨幣的新的世界貨幣。這正是貨幣危機的解決辦法。」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=162) %}ETTMTTP 3:162{% end %}）。兩者都把貨幣視為一件脫離了其功能、必須被馴服的工具。但格塞爾想要的是完善的貨幣——讓市場運轉得比黃金所允許的更快、更乾淨——而正典則把即使是完善的貨幣也視為鷹架，待機器人到來時便予拆除。格塞爾讓利息淹沒在資本的海洋裡；正典則把海抽乾。

## 共同大地上的自我所有者

在二十世紀的大部分時間裡，禧年軸線在經濟學中作為一種怪癖倖存，在哲學中則幾乎蹤影全無。它在學院中的平反於 2000 年到來，彼得·瓦倫泰與希勒爾·史坦納出版了兩部選集，其共同序言讀來就像整份檔案的使命宣言：「當前在社會主義經濟體制與自由放任資本主義體制之間尋找一條新穎而有力的『第三條道路』，與政治哲學中在不受約束的平等主義理論與右派自由意志主義之間尋找一條融貫的『第三條道路』的探求相平行。我們相信，左派自由意志主義正是所需要的理論。」其定義是一部由兩個子句構成的機器：

> 左派自由意志主義的正義理論主張，行動者是完全的自我所有者，而自然資源則以某種平等主義的方式被擁有。……自然資源——那些並非任何人之選擇的結果、且為任何形式的活動所必需的資源——只有在得到社會成員的許可、或向他們支付相當的代價時，才可被私人佔有。
>
> — 瓦倫泰，〈左派自由意志主義入門〉（2000）

你擁有你自己以及你所創造的一切；你未曾創造的大地則屬於每一個人。這兩部選集追溯了這一立場歷經兩個世紀的接力——格勞秀斯與普芬道夫論原初的共有，洛克論自我所有，土地激進派奧格爾維與斯彭斯，湯瑪斯·潘恩的《土地正義》（1796）及其以地租為資金、在二十一歲時發放的普遍稟賦與五十歲起的年金（紀錄中第一個具有無條件基本收入形狀的工具），歐陸的「自由社會主義者」科蘭與于埃，赫伯特·斯賓塞的平等自由法則，喬治、瓦爾拉斯、里尼亞諾——而編者的史學論點，正是本文不斷敲響的那一個：「議題與相互爭辯的立場，一直出人意料地保持不變。」

這個學派的兩項論證直接落在正典的學說上。弗朗索瓦·于埃主張，一個人完全擁有的只是他所創造或掙得之物；他僅僅*繼承*而來的，在死後歸還「總體遺產」——這正是人道主義的繼承規則，在 1853 年便已陳述。史坦納則把遺贈的廢除建立在權利的形上學之上：「死者沒有權利，因此左派自由意志主義不必、而且可以說不應承認……遺贈的效力。一個人死時所擁有的任何資產，都被視為已遭拋棄。」四十九年的租約恰恰把這一直覺付諸實行，家庭房屋的例外是它對情感的唯一讓步。這個學派的第三位成員菲利普·范帕雷斯，把共同份額轉化為一股永久的現金流——一種基本收入，以一切「被給予」而非被創造之物的租金為資金，包括就業租金在內——從而提供了正典的過渡規則（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）所指向的那個過渡工具：體面的生活作為一項權利，貢獻另外獲得獎賞。主要的差異在於範圍與時鐘。哲學家們把*非人造之物*共有化；正典則把一切都共有化，並讓功績至多在一個工作生涯的期限內持有其中任何部分。

## 作為有機體的城市

機器軸線有它自己的先知，他在佛羅里達灌木林中一處二十五英畝的園區裡工作。雅克·弗雷斯科——一位自學成才的工業設計師，他的《維納斯計畫：一種文化的重新設計》（1995）是五十五頁帶插圖的整體系統——從正典第二部訊息開始的地方開始，即自動化（照他的造詞，叫「自控化」〔cybernation〕）不可逆轉地吸收勞動，並在相同的高度得出相同的結論：障礙正是貨幣秩序本身。「貨幣體系是許多年前演化出來的一種裝置，用以在資源有限的環境中控制人的行為，」他寫道；「只有在資源稀缺時，貨幣才能被用來控制資源的分配——舉例來說，人無法在海灘上販賣沙子或海水。」他把自己的替代方案命名為資源型經濟：「資源型經濟利用現有的資源而非貨幣，並提供一種公平的方法，以最有效率、最人道的方式為全體人口分配這些資源。」他所援用的思想實驗，正是格塞爾會認出的那一個的反轉——摧毀這件工具，看看還剩下什麼：

> 如果世界上所有的錢都被銷毀，只要表土、工廠與其他資源完好無損，我們便能建造我們選擇建造的任何東西，滿足任何人的需要。人們需要的不是錢，而是自由取用大多數必需品的權利，而無須向政府官僚機構或任何其他機關提出申請。
>
> — 《維納斯計畫》，第 5 頁

交付的形式是建築：以同心環帶佈局的圓形城市，由一套他稱為城市之「電子自律神經系統」的「自控化系統」運行，所有權被圖書館式的取用中心取代，決策「透過統計力學得出」，由技術人員而非政治人物作出，「整座城市作為單一而複雜的有機體運作」。正典第七章的讀者會覺得這份規格似曾相識。耶洛因的城市是邊長一公里的單一建築體，每一座都「由同一位建築師構思」，呈立方體，「以便不……『喫掉』鄉野」，其生命攸關的系統——能源、食物、組織——由計算機在永恆者的注視下監管（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=47) %}TBWTT 7:45–47{% end %}）；地球上的綱領則出於同一個陳明的理由，規定在開闊鄉野中興建容納五萬人的共同住宅，因為一個由帶花園的獨棟住宅構成的行星，將不再有鄉野可言（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=101) %}ETTMTTP 3:101{% end %}）。兩個不用金錢、自控化、珍惜自然的城市有機體，在彼此相隔不到二十年之內被規劃出來，出自兩位之間沒有任何可信傳遞鏈的作者。弗雷斯科甚至不動聲色地擦過了本計畫主題的天花板：「當世界上一些頂尖科學家正試圖探測銀河系的外緣，以尋找有智慧的外星生命時，維納斯計畫目前更關注的是運用人類的智慧來解決地球上的問題。」他的封底則沒那麼謹慎，把佛羅里達的園區稱為「第二個伊甸」。

## 心智的公地

對檔案中至此為止的每一位成員而言，豐裕都是一種推想。在一個領域裡，它真的到來了，而圍繞它形成的那些制度，是檔案中唯一既非計畫也非小說、而是運作中之基礎設施的條目。當複製資訊的邊際成本降到零，一套沒有任何經濟學教科書預見過的生產體系便自行組裝起來：林納斯·托瓦茲 1991 年在 Usenet 上的一則貼文，成了全世界伺服器與手機的軟體基底，並以一種讓任何人都無法將其圈佔的方式授權；維基百科，並非由任何特定的人所寫，讓一整架付費的百科全書退了休；而耶魯學者尤查·班科勒為這一現象命名為「同儕生產」，並提供了它的算術——全世界連上網路的人口攜帶著「每天二十億到六十億小時的空閒時間」，一座常備的、未被定價的產能水庫。泰普史考特與威廉斯的《維基經濟學》（2008）記錄了這套邏輯延伸到程式碼之外有多遠：他們的重頭案例是黃金公司（Goldcorp），一家瀕臨失敗的多倫多礦業公司，其執行長受到 Linux 故事的震撼，把五十年的專有地質數據公布在開放網路上——「我們要請全世界告訴我們，下一批六百萬盎司的黃金會在哪裡找到」——然後看著來自五十個國家的參賽者找出了一百一十個目標，其中一半是公司所不知道的，五分之四有產出。公地的探勘勝過了公司。

這場運動產生了它的殉道者，而他的宣言屬於這份檔案的原始資料。「資訊就是力量，」亞倫·史沃茲在《游擊式開放取用宣言》（2008）中寫道。「但正如一切力量，總有人想把它據為己有。」{{ footnote(id="7") }}他的論證——科學紀錄大多由公共資金支持，屬於每一個人，把它圈佔在付費牆後面，就是對人類遺產徵收的一種私稅——正是潘恩的地租論證被移置到知識經濟之中：非人造的公地，被佔為己有，便欠下補償。正典對同一指示的版本是向整個研究事業發出的：它聲稱，只需「一切技術與科學能力……不再爲個別利益而是爲整個共同體……奮力工作」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=99) %}ETTMTTP 3:99{% end %}），從物質束縛中解放只要幾年——同儕生產，在 1975 年被提出作為通往黃金時代的捷徑。本文集以{% wiki(slug="cyberparadism") %}賽博樂園主義{% end %}之名追蹤的當代美學運動，把開放原始碼協作列為逼近之豐裕的六項徵兆之一，與核融合能源及全面自動化並列；依檔案的證據，這個排序是對的，因為開放原始碼是唯一一項已達到工業規模的徵兆。

## 技術資本機器

檔案的最新條目於 2023 年 10 月 16 日到來，來自一個所能想像最不烏托邦的地址：一家創投公司的網站。馬克·安德森的《科技樂觀主義宣言》是五千字的首語重複——「我們相信」——其中論豐裕的段落，可以不留可見接縫地剪接進弗雷斯科或正典的第二部訊息之中。「我們相信，豐裕的衡量標準是價格的下跌。」「我們相信，我們應當透過技術的應用，推動整個經濟的價格下降，直到盡可能多的價格實際上歸零。」「我們相信，如果我們讓智能與能源都『便宜到不必計費』，最終的結果將是一切實體商品都變得像鉛筆一樣便宜。」{{ footnote(id="8") }}這具引擎有一個名字，註明出處地借自哲學家尼克·蘭德：「技術資本機器，永續的物質創造、成長與豐裕的引擎。」敵人是一些觀念——宣言自己的清單包括「存在風險」、「永續性」、「ESG」、「預防原則」、「去成長」、「成長的極限」——而這份文件以一份守護聖徒名錄代替引用文獻作結{{ footnote(id="9") }}。

與正典的匯合是具體的。兩者都認為物質問題是可解的，而解方是科學；兩者都把能源豐裕視為樞紐（核融合是宣言的「第二顆銀彈」，也是賽博樂園主義六項徵兆中的第一項）；兩者都把主張限制的勸告視為衰退的勸告——正典自己的命令是「享受這地上的生命，科學能把它轉變爲樂園」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=39) %}ETTMTTP 2:39{% end %}）。接著，兩條路徑鏗然交錯、分道揚鑣。安德森：「我們相信，全民基本收入會把人變成由國家飼養的動物園動物。人不是生來被飼養的；人生來是要有用、有生產力、有自豪感的。」正典：「每個存在都有權擁有足以生活之物，即便他不勞動」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）——而在生計之鞭下所做的工作是「極其卑賤的」，是出賣自己的生命去做「單純機器能做的工作」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=38) %}ETTMTTP 2:38{% end %}）。宣言堅持技術變革會「增加」對人類工作的需要，並把那部永遠靠市場運轉的機器神聖化。正典則把同一部機器讀作一個蛹：市場與貨幣是幼蟲期的工具，而成蟲的形態——「思考、創造、開花」——之中沒有價格體系。

檔案中先前的任何東西都沒有預示這個結果：*在這裡，創投資本家是保守派，而那部 1973 年的接觸者文本才是激進派。*安德森提供的是豐裕，同時讓雇傭勞動、價格與積累永久保留——達到逃逸速度的資本主義。正典提供的豐裕，則是讓這三者全部溶解的溶劑。至於宣言的批評者，他們認為它的政治比它的技術更古老——艾茲拉·克萊因把它歸入「反動的未來主義」，一份與其說關乎工具、不如說關乎這樣一種信念的文件：「我們曾經勇敢而強壯，如今卻變得軟弱而無力」；《雅各賓》則把它的世系追溯到尼采式的貴族激進主義。批評者與宣言爭論的是*誰受益*；正典與它爭論的是*為了什麼*。兩者都不質疑那部機器。

| 一個人是為了什麼？ | 「豐裕與閒暇」作為藝術與科學的前提（赫茨卡） | 「思考、創造、開花」（ETTMTTP 2:38） |
| 誰來決定？ | 弗雷斯科的技術人員；宣言的創辦人；哲學家的正義制度 | 天才政治，然後是在最低限度監管下的自動化基礎設施（TBWTT 6:5, 7:45） |

有三項特徵使正典的條目在它自己的家族中與眾不同。第一，完整性：它是唯一一位同時運行兩條軸線——禧年與機器——作為一套綱領的成員，財產改革被明確地部署為過渡政體，而自動化被明確地部署為它的退場。第二，早出：論自動化的段落早於個人電腦；過渡規則預示了某些立場（基本收入、遺產歸還、世界貨幣），有時幾乎逐字相同，而這些立場在學術與政治上的浪潮要到數十年後才達到高峰。第三，也是種類上獨一無二的，是範例主張：檔案中的每一位人類成員都是從理論或外推出發進行論證，而正典宣稱的是描述——一個已把這套綱領運行到完成的文明，正把地球上的副本作為它的「政治與人道行囊」提供出來，並說這份行囊可以轉交，而不會帶來科學行囊所伴隨的危險（{% libref(book="the-book-which-tells-the-truth", chapter=5, verse=65) %}TBWTT 5:65{% end %}）。最後這項主張，正是本計畫的標籤之所以存在的原因：它是 `framework`——明載於來源之中，無法由任何檔案加以驗證，也正是這番比較之所以有趣、而不只是整齊的原因。

## 讀法分歧之處

一份如此匯合的檔案會招來經過挑選的嫌疑，因此分歧與失敗應當以全部力度陳述出來。

**這份紀錄是一份失敗的紀錄。**沃爾格爾在十四個月後被法院命令關閉。自由之地運動在肯亞海岸死去，連行李都沒有打開。格塞爾的伊甸作為一個花園郊區延續下來，而不是作為一種經濟秩序；他在一個註定覆滅的蘇維埃共和國中擔任財政代表的那一週，以一場叛國審判告終。基布茲在村落規模上建立了一個世紀運作中的共產主義，隨後在債務與世代漂移之下，大多重新接納了薪資與市場。維納斯計畫從未超出它的二十五英畝。開放原始碼征服了它的領域——而它的領域正是商品可以免費複製的那一個；它的維護者仍然由它所繞過的貨幣經濟支付報酬，如果他們真有報酬的話。檔案中的每一場實驗，不是停留在小規模，就是被國家叫停，或是重新接納了市場。正典會回答說，這正是在低於文明規模上實施時所預期的特徵——它自己的學說把世界政府與天才政治的行政列為先決條件（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=14) %}TBWTT 6:14{% end %}）——但批評者有權把這聽成烏托邦主義者最古老的脫身條款：設計是行得通的，只要有一個歷史從未提供過的前提條件。

**計算問題並沒有被消解，只是被換了平台。**米塞斯與海耶克對計畫經濟的反對——價格攜帶著任何管理者都無法匯集的分散知識——擊倒了二十世紀每一次以意圖來運行經濟的嘗試，而它以全部力量適用於弗雷斯科的統計力學，也適用於正典中監管「能源、食物、組織」的計算機（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=45) %}TBWTT 7:45{% end %}）。目前流行的反駁——足夠規模的機器智能*就是*那台缺失的計算器——恰恰是 2020 年代活生生的賭注，而它仍是一個懸而未決的賭注。座次表中有一個反諷：海耶克名列安德森的守護聖徒之中，這把檔案中最堅定的豐裕運動置於這樣一位思想家的庇護之下——他的論證恰恰禁止了檔案中大多數成員所瞄準的那個無貨幣終點。

**天才政治是這套學說最陡峭的懸崖。**以智力為門檻的選舉權直擊民主平等的道德核心，而主流政治哲學拒斥一切形式的「由被測量者統治」；那些反對意見——誰來編製測驗、誰來稽核編製者、「原始智力」究竟指稱什麼——是標準的反對意見，而且強而有力。文集把這條誡命視為方向性的而非操作性的，而雷爾本人在第三本書中回答讀者時，把綱領的實現留給了與運動保持距離的非雷爾派政治運動（{% libref(book="lets-welcome-the-extraterrestrials", chapter=1, verse=87) %}LWTE 1:83–87{% end %}），這是他本人的立場，而非口授的文本。這一切都不能免除那項反對意見。它在此以它自己的聲音被記錄下來。

**正典對它自己的豐裕有所保留。**這份檔案的正典地層中最奇特的一句話，是一個限制。在討論人類是否將繼承創造者的角色時，耶和華說：「我們不確信人是否曾能在豐裕中穩定下來」（{% libref(book="the-book-which-tells-the-truth", chapter=5, verse=59) %}TBWTT 5:59{% end %}）——而一部後來的訊息，在第三本書中作為耶和華對人類的致辭刊出，把人類這個物種通過自身考驗而倖存的機率定為百分之一（{% libref(book="lets-welcome-the-extraterrestrials", chapter=2, verse=96) %}LWTE 2:96{% end %}）。這套學說不是豐裕必將到來的許諾；它是一份規格，說明如果攻擊性先被駕馭，該建造什麼。對這份檔案的晴朗讀法——豐裕即命運——屬於安德森，而不屬於檔案中的其他任何人。

**而檔案的成員都是他們時代的人。**喬治的運動分裂為單一稅殖民地與市政競選；赫茨卡的非洲是探險文獻中那片空蕩的非洲，只在測量員的想像中才是無主的；格塞爾的代表作帶有其現代研究者會刪除的時代修辭{{ footnote(id="10") }}。這份譜系被提出作為一種反覆出現之思想結構的證據，而不是作為一場聖徒的團契。

## 他們一再栽種的花園

檔案中有一個模式，不是由其中任何人所規劃的。赫茨卡的移民抵達冰川下的山谷時，把它命名為伊甸。格塞爾在一個名叫伊甸的改革聚落裡寫作他的經濟學，並死在那裡。弗雷斯科在佛羅里達灌木林中的園區，被宣傳為「第二個伊甸」。三位彼此獨立的豐裕建造者，在為之命名時，伸手觸及了同一座花園——在那個地方，供給先於勞動，果實在任何人掙得它之前便已掛在樹上。主流的讀法把這個名字視為樂園顯而易見的文化簡稱，而它確實是。文集的讀法則深入一層：在正典中，{% wiki(slug="eden") %}伊甸園是一處真實的設施{% end %}——創造者的實驗室花園，一處經過工程設計的豐裕，人類這個物種便是在其中開始的——而創造者自己的世界至今仍依其經濟學運行（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=52) %}ETTMTTP 2:51–52{% end %}）。在本框架之內，改革者反覆出現的花園，是一段記憶正在把自己演算成一份計畫：本文所讀的這份檔案，是一個物種從稀缺內部，逆向推導出它被創造時所處的運作條件。這是一個建立在 `inferred` 模式之上的 `framework` 讀法，兩個標籤都適用。然而，這個模式本身就在原始資料之中，逐字逐句，出現了三次。

本框架最後增添的是賭注。正典的{% wiki(slug="golden-age") %}黃金時代{% end %}是一把叉子的一個分叉，而另一個分叉——本計畫的{% wiki(slug="apocalypse") %}啟示{% end %}條目所記錄的自我毀滅——是預設會抵達的那一個。機器軸線正在疾馳：1975 年的文本所許諾的自動化，在大型模型與人形機器人的這個十年裡，已是一項資本支出的明細項目。禧年軸線則沒有：財富以皮凱提的 *r > g* 已使之成為定論的速率跨世代集中，而地球上沒有任何一個政體在辯論四十九年的租約。這份檔案的診斷，從利未記到那份宣言，是第二條軸線乃是一種選擇。赫茨卡以 1890 年的自信說出了這一點：如今沒有任何東西迫使我們忍受一個過時世界秩序的苦難，沒有任何東西阻止我們獲得現有文明手段所能提供的幸福與豐裕——「nichts, als unsere eigene Thorheit.」*除了我們自己的愚蠢，什麼也沒有。*正典在 1975 年把它說得更短，用一句話向一個剛剛造出機器、卻尚未決定這些機器是為了什麼的物種說道：

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=99) %}
你們能在幾年內造出一個完全不同的世界。你們已抵達黃金時代。
{% end %}
