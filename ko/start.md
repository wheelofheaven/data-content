## 1. 전제, 그리고 그것을 제시하는 사람 {#premise}

*약 1분.*

Wheel of Heaven은 창세기가 {% wiki(slug="elohim") %}엘로힘{% end %}이라 부르는 존재들이 다른 세계에서 온, 작고 기술적으로 진보된 인간 문명이었다고 제안합니다.
그들은 인류를 포함한 지구의 생명을 설계했으며, 여러 전통의 종교 텍스트는 그들의 작업에 대한 압축된 기억을 간직하고 있습니다.

{% rows() %}
출처 | 클로드 보릴롱(라엘)이 1974년부터 펴낸 라엘리안 메시지입니다.
방법 | 이 사이트는 고대 자료를 그 렌즈를 통해 읽으며, 그 사실을 공개적으로 밝힙니다.
저자 | 한 사람의 [라엘리안](/ko/wiki/raelism/) 저자가 필명으로, AI의 도움을 받아 씁니다.
위상 | 라엘리안 무브먼트의 공식 출판물이 아닙니다.
{% end %}

자세한 내용은 [프로젝트 소개](/ko/about/)와 [저자](/author/zara-zinsfuss/) 페이지에 있습니다.

## 2. 자료와 해석을 구별하는 법 {#labels}

*약 2분.*

주장은 그것이 제시되는 자리에서 네 종류 가운데 하나로 표시됩니다.
표시된 문장에는 표지의 색으로 된 가는 밑줄과 점이 붙으며, 점을 누르면 그 표지가 무엇을 뜻하는지 볼 수 있습니다.

{% rows() %}
claim:direct | 일차 자료에 진술되어 있고 논란의 여지가 없는 주장.
claim:framework | 라엘리안 정전에 진술되어 있으나 주류 학계가 받아들이지 않는 주장.
claim:inferred | 자료가 그대로 진술하지는 않지만 자료에 대한 합리적인 읽기인 주장.
claim:speculative | 어떤 단일 자료도 넘어서는 종합.
{% end %}

종류마다 예를 하나씩, 항목에서 표시되는 그대로 보입니다:

- {% claim(type="direct") %}히브리어 낱말 *엘로힘*은 형태상 복수이다.{% end %}
- {% claim(type="framework") %}엘로힘은 물리적 존재들의 문명이다.{% end %}
- {% claim(type="inferred") %}바벨탑은 만든 이들에게 바치는 화해의 제물로 세워졌다.{% end %}
- {% claim(type="speculative") %}그리스, 메소포타미아, 가나안의 신들의 전투 이야기는 같은 충돌을 기억한다.{% end %}

긴 페이지에는 한 종류 이상의 주장이 들어 있습니다.
표지는 논증이 기대고 있는 주장들을 표시하며, 나머지는 본문이 진행되면서 "이 독해에 따르면"이나 "주류 학계는 ~라고 본다" 같은 표현으로 표시합니다.
[방법](/ko/method/) 페이지가 이 표지들을 온전히 설명합니다.

## 3. 한 구절, 면밀히 읽기 {#verse}

*약 3분.*

{% library(book="genesis-woh", chapter=1, verse=26) %}
엘로힘이 말하였다, "우리 형상대로, 우리 모습을 따라 사람을 만들자; 그들이 바다의 물고기와, 하늘의 새와, 가축과, 온 땅과, 땅 위를 기는 모든 것을 다스리게 하자."
{% end %}

**히브리어가 말하는 것.**
화자는 형태상 복수인 명사 *엘로힘*입니다.
동사 *na'aseh*("우리가 만들자")는 1인칭 복수이며, 소유 표현 *be-tzalmenu*("우리 형상대로")와 *ki-dmutenu*("우리 모습을 따라")도 그러합니다.
이 형태들에는 논란이 없습니다.

{% interlinear(script="he", dir="rtl", caption="창세기 1:26의 첫 낱말들을 오른쪽에서 왼쪽으로 읽습니다. 표시된 형태는 복수입니다.") %}

**보통 어떻게 읽힙니까.**
독자들은 이 복수를 크게 네 가지 방식으로 풀어 왔습니다:

{% rows() %}
왕이 쓰는 "우리" | 위엄의 복수: 한 화자가 자기 자신을 복수로 일컫는 것.
삼위일체 | 그리스도교 신의 세 위격에 대한 예표.
회의 | 신이 시중드는 천상 존재들의 회의에 말을 거는 것. | 오늘날 대부분의 학자
복수의 창조자들 | 문자 그대로의 복수: 만든 이들이 하나보다 많았다는 것. | !Wheel of Heaven
{% end %}

오늘날 대부분의 성서학자는 {% libref(book="psalms", chapter=82, verse=1) %}시편 82편{% end %}과 {% libref(book="1-kings", chapter=22, verse=19) %}열왕기상 22장{% end %}의 천상 회의에 견주어 회의 독해를 선호합니다.

**Wheel of Heaven이 제안하는 것.**
네 번째 독해입니다. 엘로힘은 하나의 집단이었기 때문에 집단으로서 숙의합니다. 그들은 인류를 자신들의 물리적 모습대로 만들려 하는 설계자 팀이었습니다.
"형상"을 뜻하는 명사 *tselem*은 보통 구체적인 형체, 곧 조각상이나 깎아 만든 모상을 뜻하며, 이는 영적인 닮음보다 물리적인 닮음에 더 잘 들어맞습니다.

**그 이유.**
복수 발화는 같은 종류의 순간마다 되풀이됩니다. 인류를 만들 때, 에덴 이후("그 사람이 우리 중 하나같이 되었다", {% libref(book="genesis-woh", chapter=3, verse=22) %}창세기 3:22{% end %}), 그리고 {% wiki(slug="babel") %}바벨{% end %}에서({% libref(book="genesis-woh", chapter=11, verse=7) %}창세기 11:7{% end %}).
매번 복수의 화자들은 인류에 관해 무언가를 결정하고 그대로 행합니다.
라엘리안 메시지는 문법과는 무관하게 창조에 대해 같은 설명을 제시합니다.

## 4. 가장 강력한 반론 {#against}

*약 2분.*

*엘로힘*이 이스라엘의 신을 가리킬 때에는 대개 단수 동사를 취합니다.
성경의 첫 구절은 *bara Elohim*, 곧 "엘로힘이 창조하였다"로 읽히며, 동사는 단수입니다.
대부분의 독자에게는 그것으로 문제가 해결됩니다. 이 명사는 형태상 복수이지만 의미상 단수이며, 26절의 "우리"는 하위 존재들의 회의를 향한 말이라는 것입니다.

Wheel of Heaven은 그 문법을 받아들이며, 자신의 논거를 복수 형태에 두지 않습니다.
논거는 본문이 복수로 말하는 구절들과, 단수 동사를 집단을 대신하여 행동하는 한 대표자의 말로 읽는 라엘리안 설명에 있습니다.

{% compare(left="회의 독해", right="복수 창조자 독해", shared="둘은 모두 복수를 진지하게 받아들입니다. 둘은 그 자리에 누가 있었는지를 두고 갈라집니다.") %}
누가 "우리"라고 말합니까? | 하나의 신이 하위 존재들의 회의를 향해 | 만든 이들이 서로에게
단수 동사 | 하나의 신이 행동한다 | 한 대표자가 집단을 대신하여 행동한다
지지하는 쪽 | 오늘날 대부분의 성서학자 | 라엘리안 메시지와 Wheel of Heaven
{% end %}

히브리어만으로는 둘 사이를 결정할 수 없으며, [엘로힘](/ko/wiki/elohim/#what-would-revise-this-reading) 항목은 프로젝트의 독해를 약하게 만들 발견들을 나열합니다.
