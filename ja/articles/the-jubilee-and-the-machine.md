1932年の夏、世界恐慌のどん底で、オーストリアのチロル地方の町ヴェルグルは、腐るように設計されたお金を刷り始めました。町の三分の一が失業していました。元鉄道機関工の町長ミヒャエル・ウンターグッゲンベルガーは、所持者が印紙を買って貼らないかぎり、毎月額面の1パーセントを失う労働証明書を発行しました。それは溜め込むことに費用が組み込まれた通貨であり、それをどうするかについて唯一理にかなった選択は、使うことでした。証明書は、シリングがオーストリア全土を巡るよりも何倍も速くヴェルグルの中を巡りました。町は通りを舗装し直し、水道を作り直し、失業者を橋の工事に就かせ、税を前払いで自らに納めました。そのあいだも、周囲の国では失業が増え続けていました。ヨーロッパとアメリカの各地から、この奇跡を見に訪問者がやって来ました。{{ footnote(id="1") }}およそ二百人のオーストリアの町長が、それを模倣する準備をしました。そこでオーストリア国立銀行が貨幣発行の独占権を主張し、裁判所がそれを認め、1933年9月、実験は法によって閉じられました。それに賛同する人々が飽くことなく繰り返したように、機能していた答えが、それが答えていた危機の頂点で閉ざされたのです。

ヴェルグルが束の間体現した着想は、その二年前に、ベルリン郊外のエデンという名の園芸コロニーで亡くなった一人の男のものでした。シルビオ・ゲゼルです。独学のドイツ人商人で、ブエノスアイレスに外科器具を輸入して財をなし、アルゼンチンの通貨が周囲の財産を破壊し作り変えるのを見つめるうちに正統的な考えを失った人物でした。{{ footnote(id="2") }}ヴェルグルが閉ざされた三年後、存命中の最も有名な経済学者が、その世紀で最も影響力のある経済学書の一節を彼に捧げることになります。「奇妙な、不当に無視された預言者シルビオ・ゲゼル」とケインズは書きました。「その著作には深い洞察のひらめきが含まれている」。そして、彼の職業がいまだに消化しきれていない一文を述べたのです。「私は、未来はマルクスの精神よりもゲゼルの精神から多くを学ぶだろうと信じる」。

ゲゼルは、本稿が全体として読もうとする系列の一項目です。この系列の成員が互いを知っていたことはほとんどありません。そこには、ケニアの高地にユートピアを設定したウィーンの経済ジャーナリスト、地租を擁護する議論が十九世紀で最も売れた経済学書となったアメリカの印刷工、十七世紀の自然法を好む英語圏の哲学者たちの一学派、フロリダの低木林にいた独学の工業デザイナー、地球上で最も価値あるソフトウェアを無償で手放したプログラマーたち、そして宣言を携えたベンチャー・キャピタリストが含まれています。彼らが共有しているのは一つの確信です。一定の技術的閾値を越えれば、欠乏は制度設計の産物であること。社会経済秩序は作られたものであり、作り直すことができること。そして作り直しにとって正しい目的関数は、蓄積ではなく人間の開花、すなわち種の潜在力の花開きであること。そしてこの系列には自然な比較点があります。このプロジェクトが読むコーパスは、1973年12月の六つの朝にわたって伝えられ、1975年に拡張された、この一族の簡潔で不思議なほど完全な一員を含んでいるからです。{% wiki(slug="new-commandments") %}新しい戒め{% end %}が**ヒューマニタリアニズム**（人道主義）と名づける教義と、そのより長い展望である{% wiki(slug="paradism") %}パラディズム{% end %}です。カノン自身の主張は、このプロジェクトでは一貫して`framework`とラベルづけされています。原典には明示されていますが、主流の学問には支持されていないということです。続く比較の読みには、それにふさわしいラベルが付されます。`inferred`です。

## 噴火口のメッセージ

枠組みの内部では、舞台はクレルモン＝フェラン近郊の死火山の噴火口です。そこで二十七歳の自動車レース・ジャーナリスト、クロード・ヴォリロン――二日目の朝からは{% wiki(slug="rael") %}ラエル{% end %}――は、のちに{% wiki(slug="yahweh") %}ヤハウェ{% end %}と呼ぶことになる訪問者との六日間の対話を報告しました。彼が翌年に刊行した書物の第六章は、ほかの何であるにせよ、一つの政治経済学です。それは{% wiki(slug="geniocracy") %}ジェニオクラシー{% end %}――知性によって選別された統治――から始まり、ただちに財産へと進みます。

あなたがたの世界は利益によって麻痺しており、共産主義は人々に努力し進歩したいという欲を起こさせる十分なにんじんを与えるに至りません。あなたがたは平等に生まれます。これも聖書の書物にあります。権力は、あなたがたを財産においてほぼ平等に生まれさせねばなりません。……それを避けるには、共産主義を導入することなく所有を廃止せねばなりません。この世界はあなたがたのものではありません。これも聖書に書かれています。あなたがたはその借り手にすぎません。こうして、すべての財は四十九年間賃借されねばなりません。それは相続の不正を廃止します。あなたがたの遺産、あなたがたの子らの遺産、それは、あなたがたが世界を快適にするよう組織することを知るなら、世界全体です。この人類の政治的方向は共産主義ではありません。それは人類の未来を気にかけます。名を与えたければそれを人道主義と呼びなさい。
{% end %}

その仕組みは、住宅ローンの相談員のような辛抱強さで詰められています。ある人が二十一歳で学業を終え、四十九年間家を賃借し、七十歳でその保有権を完全に自分のものとします。彼の死に際して家は共同体に戻りますが、家族の家だけは例外で、子どもたちが永久に住むことができます。功績ははっきりと保たれています。テクストは、勤勉な者と怠惰な者という二人の息子の例を挙げ、勤勉な方が豊かになるに任せます。

{% library(book="the-book-which-tells-the-truth", chapter=6, verse=9) %}
勤勉な者は怠惰な者よりずっと早く多くの金を稼ぐでしょう。彼はそのとき、最初のものの代わりに二倍高い家を賃借できるでしょう。……しかし彼の死ではすべてが共同体に戻ります、家族の家を除いて、それは彼の子らに戻ります。いわば、人は自分のために、その功績に応じて財産を作れますが、その子らのためにはできません。各人にその功績を。
{% end %}

価値あるものはすべて――土地、企業、株、金、建物――共同体に属し、最長四十九年間、その手段を得た者たちに賃貸し戻されます（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=10) %}TBWTT 6:10{% end %}）。そしてテクストは、このジャンルとしては異例のことを行います。先例を引くのです。四十九年という期間は、とテクストは言います。「すでに聖書に定められています」。そしてレビ記25章を長く引用します。七たび七と数えられる安息の年と、その根底にある土地保有の原則です。*「地は永久に売られてはならない。なぜなら地はわたしのものであり、あなたがたはわたしのもとの寄留者、滞在者だからである」*（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=13) %}TBWTT 6:11–13{% end %}）。ヒューマニタリアニズムは自らを回復として提示します。惑星規模で再発行されたヨベルです。その明示された前提条件は、第六章の残りの部分です。権力の座にある天才たち、彼らは「これらの改革の有用性を理解するでしょう」。そして新たな世界通貨と共通の第二言語をもつ、単一の世界政府です（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=16) %}TBWTT 6:14–16{% end %}）。

1975年のメッセージは第二の軸を加えます。最初の書が保有を改革したのに対し、第二の書は労働そのものに挑みます。

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=37) %}
科学と技術は、世界の飢えの心配から人間を完全に解放できるだけでなく、機械が自動化のおかげで日々の労役をすっかり一人で引き受けられるので、働く義務なしに生きることをも人間に可能にできます。……五百人の仕事をするこれらの素晴らしい機械は、たった一人の人、すなわち雇い主を肥やすのに役立つ代わりに、これら五百人を生きさせられねばなりません。
{% end %}

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=38) %}
いかなる人も他人の奉仕にあってはならず、賃金と引き換えに他人のために働いてもなりません。機械は労役を十分にこなし、すべての仕事を引き受けられ、人間が、それのために作られた唯一のこと、すなわち考え、創造し、開花することに専念することを可能にします。……労働は、苦しく生きるに足るものを稼ぐ必要以外の何ものによっても動機づけられないとき、何ら神聖なものはなく、自分を売ること、こうして単純な機械ができる仕事をして食べられるよう自分の人生を売ることは、ひどく卑しめさえします。
{% end %}

「鍵」の部は、その順序を明確に述べます。働いていようといまいと、誰もがまっとうに暮らす権利をもちます（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）。より多く貢献する者はより多くをもってよいのですが、それは「明らかに暫定的な規則であり、人間が金銭を完全に廃止した後、自分の開花のみに専念するためにすべての下働きをロボットに遂行させられるようになるのを待っての間のこと」です（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=96) %}ETTMTTP 3:96{% end %}）。その間、単一の世界通貨が各国の通貨に取って代わります（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=162) %}ETTMTTP 3:162{% end %}）。そして技術上の優先事項は、一つの戒めとして述べられます。「あなたがたを下働きから解放し開花を可能にする生物ロボットを創造するためにすべてを尽くしなさい」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=100) %}ETTMTTP 3:100{% end %}）。ラエルはのちに、この計画を運動自身の構想に書き込みました。第三の書で読者の質問に答えて、彼はその目標の一つに研究センターを挙げ、その研究による「生物学的ロボットの創造は、労働の廃止、ひいては金銭の廃止を可能にするでしょう」と述べています（{% libref(book="lets-welcome-the-extraterrestrials", chapter=1, verse=24) %}LWTE 1:24{% end %}）。これは彼自身の見解であり、口述されたテクストではありません。

そしてカノンは手本を主張します。創造者たち自身の世界での生活について問われ、ヤハウェは、この計画をすでに完了した文明を描写します。

{% library(book="the-book-which-tells-the-truth", chapter=7, verse=45) %}
すべての人は「働き」ますが、それは彼らがしたいからです。なぜなら、われわれのところには金がないからです。こうして、「働く」者は、天職によってなされるので、つねに非常によくなされた物事を行います。永遠者だけが非常に正確な使命を持ちます。たとえば、エネルギー、食糧、組織などの生命的な問題を扱う電子頭脳とコンピュータの監視のように。
{% end %}

その母星では、都市はそれぞれ一人の建築家が設計した、一キロメートル規模の単一の構造物であり、「一種の立方体」で、それは「田園を『食って』しまわないため」です。そして{% wiki(slug="council-of-the-eternals") %}七百人の評議会{% end %}の永遠者たちが、何をする義務もまったくない七十億の人々のために、自動化された基盤を監督しています（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=47) %}TBWTT 7:39–47{% end %}）。第二のメッセージに描かれる永遠者の惑星では、およそ九万体の生物学的ロボットが、九千人を少し超える住民に仕えています（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=54) %}ETTMTTP 2:53–54{% end %}）。枠組みの内部では、これこそが教義の*目的*です。地上の計画は、機能している原本の写しなのです。第三の書に語られる出会いは、問いを同じ言葉で立てています。そこでヤハウェは、評議会の懐疑家である{% wiki(slug="satan") %}サタン{% end %}は「人間が団結し、金銭とあらゆる武器が破壊されるまでは、人間から何かよいことが期待できるとは納得しないだろう」と言います（{% libref(book="lets-welcome-the-extraterrestrials", chapter=2, verse=76) %}LWTE 2:76{% end %}）。その章が口述されたメッセージに数えられるかどうかは、このプロジェクトではまだ決着していません。もし数えられるなら、貨幣の廃止は、軍備の放棄と並んで、種が果たすべき二つの証明の一つということになります。

こうして教義には二つの軸があります。第一は**ヨベルの軸**です。所有に代わる保有、誕生時の平等、一生の内で報われる功績、そして世代を越えて複利で増えていくものは何もないこと。第二は**機械の軸**です。自動化が労働を吸収し、労働が生存の代価であることをやめ、貨幣が配給していた欠乏が終わるときに貨幣もまた失効すること。本稿の残りでは、それぞれの軸の人間による系譜をたどります。枠組みに触れる手立てをもたず、たいていは互いのことも知らずに、同じ二つの改革に繰り返したどり着いた思想家たちです。

## 売ることのできない土地

ヨベルの軸のほうが古く、その主根は、カノン自身が引用するテクストです。レビ記25章は、年を安息の年で――七たび七と――数えるよう命じ、解放の年には土地が戻ります。土地の売買は、事実上、残る収穫の数によって値をつけられた賃借なのです。「なぜなら地はわたしのものであり、あなたがたはわたしのもとの寄留者、滞在者だからである」。この指示が実際に執行されたことがあるかどうかには異論があります。{{ footnote(id="4") }}異論がないのは、それが*何であるか*です。蓄積された保有を周期的にリセットすることであり、大地そのものは商品ではなく信託されたものだという前提の上に築かれています。

近代における再発見は、十八世紀フランスの重農主義者たちとともに始まりました。彼らは、すべての純粋な富は土地に由来すると論じ、地代に対する単一の税である*impôt unique*（単一税）を提案しました。{{ footnote(id="3") }}その後継者は、議論を自力で見いだしたとはいえ、ヘンリー・ジョージでした。サンフランシスコの印刷工でありジャーナリストであった彼は、カリフォルニアの地価が賃金を置き去りにして暴騰するのを目の当たりにし、『*進歩と貧困*』（1879年）において、なぜ富とともに窮乏が増すのかと問いました。彼の答えは、地代、すなわち立地がもたらす不労の増分が進歩の利得を吸い取ってしまう、というものでした。そしてそこには、外科手術のように限定された処方が添えられていました。地価にその賃貸価値の全額まで課税し、他のあらゆる税を廃止し、改良、賃金、事業には手を触れない。功績は、功績が生み出すものをすべて保持し、共同体は、誰も作らなかったものだけを取る。この書の影響力は誇張しがたいほどです。弟子ではなかったゲゼルでさえ、競争相手の羨望をこめてそれを記録しています。「Georges Buch erlebte die größte Auflage, die ein Buch je erlebt hat」――ジョージの書は、およそ書物が達したことのある最大の部数に達した。本稿が依拠する学術的な論集は、その評決を冷静に述べています。ジョージは「疑いなく、その時代においても後の世代にとっても、『左派リバタリアニズム』の最も人気ある主唱者となった」。

ジョージの切り分けをカノンのそれと並べると、幾何学は同じで、半径だけが異なります。どちらも労働の果実を働く者のもとに残し、どちらも不労の基盤を共同体に戻します。ジョージは線を土地に引きます。ヒューマニタリアニズムはそれをあらゆるものの周りに引きます。「株、金、企業、現金、建物、価値を持ちうるすべて」（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=10) %}TBWTT 6:10{% end %}）。そしてそれを税ではなく時計によって執行します。四十九年での返還です。ジョージがフローを社会化するところで、カノンはストックに期限を設けるのです。

## 高地の園

『*進歩と貧困*』の十一年後、テオドール・ヘルツカという名のウィーンの経済学者であり経済ジャーナリストが、目論見書として機能する一篇の小説を刊行しました。『*フライラント――社会の未来像*』（*Freiland: Ein sociales Zukunftsbild*、1890年）は、ハーグでの公開集会で「社会問題の解決に向けた実践的な試み」を行うために設立された協会から始まります。それは「完全な自由と経済的正義を同時に」約束し、「すべての労働者に、自らの労働の果実の完全で減じられることのない享受を」保証する共同体です（ここでも以下でも私たちの訳です）。入植者たちは、ケニア山とキリマンジャロのあいだにある赤道東アフリカの高地へと船出します。そこでは土地は*herrenlos*――持ち主がいない――であり、彼らはそこに四つの規則にもとづく社会を築きます。「個人的にも集団的にも」土地の所有はなく、土壌は「空気のように自由」であること。中央銀行から誰にでも前貸しされる無利子の運転資本。誰もが意のままに加わり、また去ることのできる生産者組合。そして女性、子ども、老人、働けない者のための扶養の権利です。この権利は、「先行する無数の世代の精神的労働」という遺産に対する各人の取り分として正当化されています。地代、利子、利潤が禁じられることは決してありません。それらはただ、さらされて死に絶えるのです。「私たちが利子を禁じないのは、雇用主の利潤や地代を禁じないのと同じことです」と、銀行の頭取は懐疑的なイギリス人の訪問者に説明します。「これら三つの所得部門がここに存在しないのは、誰ひとりそれを支払わねばならない立場に置かれることがないという単純な理由によるのです」。世界会議でのヘルツカの語り手は、この系列全体の冒頭に掲げてもよい一文で目的を述べます。以前の試みが失敗したのは「それらが貧困の平等を打ち立てようとしたからである。私たちの試みは成功するだろう。それは富の平等を意味するからである。……芸術と科学は豊かさと余暇を前提とする」。

この小説の二つの細部は、その経済学を越えて、このプロジェクトにとって重要です。第一は一つの名前です。遠征隊がケニアの氷河の下にある谷にたどり着いたとき――「目の届くかぎり、土地は園のようであったが、人はまだこの楽園を手にしてはいなかった」――ある入植者は、大天使の燃える剣が滝のしぶきの中に散ったと宣言し、その地を**エデン**と名づけます。第二は、この書が動かしたものです。数か月のうちにヨーロッパ各地にフライラント協会が生まれました。彼らが送り出した唯一の遠征隊は1894年にアフリカ沿岸で引き返させられ、運動は解散しました。{{ footnote(id="5") }}しかし、この書の熱心な読者の中に、もう一人のウィーンのジャーナリストがいました。テオドール・ヘルツルは『*ユダヤ人国家*』（1896年）を、自らの計画をヘルツカの計画と比べることから始めています。『*フライラント*』は、と彼は書きました、巧妙だが、多くの歯車をもち、動かせるという証明のない「複雑な機械仕掛け」である、と。そしてヘルツルが始めた入植運動は、1909年、ガリラヤ湖畔のデガニアにおいて、ヘルツカが想像したにすぎなかったものを生み出しました。共有の土地、共同の生産、そして賃金のない、現実の共同体です。キブツは、近代の記録において最も長く続いた自発的な共同所有の実験となりました。マルティン・ブーバーの言う「失敗しなかった実験」です。やがて1980年代の債務危機が、運動の大半を民営化へと押しやりました。{{ footnote(id="6") }}一世紀の運営と、その終わりにおける市場の再受け入れ。キブツの記録は、ヨベルの軸が掲げる約束と、カノンの功績にもとづく賃借が答えるよう設計されているインセンティブの問題の両方を、縮図として含んでいます（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=95) %}ETTMTTP 3:95{% end %}：「出発点において、誕生において人間の間に平等がなければなりませんが、その後はそうではありません」）。

## 傷む貨幣

ゲゼルはジョージを読み、診断は正しいが手段は誤っていると断じました。地租は「狼の皮をかぶった羊」であり、執行できないからこそ地主たちが称賛しやすいものであって、いずれにせよ土地は問題の半分にすぎない、と。残りの半分は貨幣そのものでした。彼の『*自然的経済秩序*』（*Die natürliche Wirtschaftsordnung*、1916年）は、あまりにありふれていたために見過ごされてきた非対称性に欠陥を見いだします。あらゆる商品は傷むが、貨幣は傷まない。農民のじゃがいもは腐り、新聞は古びるので、その持ち主は売らねばならない。金を持つ者は待つことができ、待たないことに対して料金を取る。ゲゼルの分析によれば、利子とは、出し渋ることのできる側が課す通行税なのです。

> Der König steht am Schlagbaum; er sperrt die Grenze und sagt: der
> Zehnte ist mein! Der Geldgeber steht vor dem Geldschrank; er sperrt
> den Austausch der Waren … und sagt, wie der König: der Urzins ist
> mein!
>
> *王は遮断機のところに立つ。彼は国境を閉ざして言う。十分の一税はわがものだ！ 金貸しは金庫の前に立つ。彼は、その中身を媒介として頼る商品の交換を閉ざす――そして王のように言う。基礎利子はわがものだ！*
>
> — *Die natürliche Wirtschaftsordnung*, Part 5

処方は、論理学者の不遜さをもって診断から導かれます。貨幣を死すべきものにせよ。

> Geld, das wie eine Zeitung veraltet, wie Kartoffeln fault, wie Eisen
> rostet, wie Äther sich verflüchtigt, kann allein sich als Tauschmittel
> von Kartoffeln, Zeitungen, Eisen und Äther bewähren. … Wir müssen also
> das Geld als Ware verschlechtern, wenn wir es als Tauschmittel
> verbessern wollen.
>
> *新聞のように古び、じゃがいものように腐り、鉄のように錆び、エーテルのように揮発する貨幣だけが、じゃがいも、新聞、鉄、エーテルの交換手段としての真価を示すことができる。……それゆえ私たちは、貨幣を交換手段として改善したいのであれば、商品としての貨幣を悪化させねばならない。*
>
> — *Die natürliche Wirtschaftsordnung*, Part 4

これが*Freigeld*――自由貨幣――であり、ヴェルグルはその実地試験でした。ゲゼルはこれに、自らの*Freiland*（自由地）を組み合わせました（すべての土地を競売によって公的に賃貸し、その地代を子どもの数に応じて毎月母親たちに分配する――1916年の、子ども数にもとづくベーシックインカムです）。さらに、国境を越えてこの制度を運ぶための世界通貨同盟の提案である、国際通貨協会を組み合わせました。彼のロビンソン・クルーソーの寓話は、理論全体を一文に収めてみせます。漂流者の蓄えは腐っていき、新参者の借入の申し出は複利で膨らみ、漂流者はついにそれを悟るのです。「Wieviel Beweiskraft doch die Ratten, Motten und der Rost haben!」――*鼠と、衣魚と、錆とは、なんという証拠能力をもっていることか！* ケインズは、『*一般理論*』第23章でそのすべてを秤にかけ、機構を認め（「スタンプ付き貨幣の背後にある着想は健全である」）、ゲゼルは「利子率の理論の半分しか構築しなかった」という異議を書き留め、そしてこの系列の題辞にふさわしい言葉でその計画を描写しました。「反マルクス主義的社会主義の確立……競争の廃止ではなく、その解放にもとづく」。大西洋の向こうでは、アーヴィング・フィッシャーがもっと率直でした。「私は自らをシルビオ・ゲゼルのつつましい弟子とみなしている」。

カノンの貨幣計画は、ゲゼルの段階づけを共有し、それから彼を置き去りにします。どちらも、移行のための手段として単一の世界通貨を処方します。カノンはまさにその言葉で述べています。「金銭を廃止できるようになるのを待っての間、国の通貨に代わる新しい世界通貨を創りなさい。それが通貨危機の解決策です」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=162) %}ETTMTTP 3:162{% end %}）。どちらも貨幣を、自らの機能から逸脱してしまい、手なずけ直さねばならない道具として扱います。しかしゲゼルが貨幣の完成――金がかつて許したよりも速く清潔に回る市場――を望んだのに対し、カノンは完成された貨幣でさえ足場として扱い、ロボットが到来したら取り払うべきものとします。ゲゼルは資本の海で利子を溺れさせ、カノンは海そのものを干上がらせるのです。

## 共有の大地の上の自己所有者たち

二十世紀の大半を通じて、ヨベルの軸は、経済学においては奇矯な説として生き延び、哲学においてはほとんど生き延びませんでした。その学問的な復権は2000年に訪れました。ピーター・ヴァレンタインとヒレル・スタイナーが二冊の論集を刊行し、その共通の序文は、この系列全体の使命宣言のように読めます。「社会主義的経済体制と自由放任の資本主義的経済体制のあいだの、新しく説得力のある『第三の道』をめぐる現在の探求は、政治哲学における、制約なき平等主義理論と右派リバタリアニズムのあいだの首尾一貫した『第三の道』の探求と並行している。私たちの信じるところでは、左派リバタリアニズムこそが必要とされている理論である」。その定義は、二つの条項からなる機械です。

> 左派リバタリアンの正義論は、行為者は完全な自己所有者であり、天然資源は何らかの平等主義的な仕方で所有されると主張する。……天然資源――誰の選択の結果でもなく、あらゆる形態の活動に必要な資源――は、社会の成員の許可を得るか、彼らに相当の支払いをする場合にのみ、私的に専有されうる。
>
> — Vallentyne, "Left-Libertarianism: A Primer" (2000)

あなたはあなた自身と、あなたが作るすべてのものを所有する。あなたが作らなかった大地は、万人のものである。二冊の論集は、この立場を二世紀にわたるリレーを通してたどります。原初の共有についてのグロティウスとプーフェンドルフ、自己所有についてのロック、農地急進派のオグルヴィとスペンス、二十一歳での普遍的な基金と五十歳での年金を地代でまかなうトマス・ペインの『*土地分配の正義*』（1796年。記録に残る最初のベーシックインカム型の手段です）、大陸の「自由主義的社会主義者」コランとユエ、ハーバート・スペンサーの平等な自由の法則、ジョージ、ワルラス、リニャーノ。そして編者たちの史学上の論点は、本稿が繰り返し打ち当たるものと同じです。「論点と対立する立場は、驚くほど一定のままである」。

この学派の二つの手は、カノンの教義に直接着地します。フランソワ・ユエは、人が完全に所有するのは自らが創造したか稼いだものだけであり、単に*相続した*ものは死に際して「一般的世襲財産」に戻ると考えました。これは、1853年に述べられたヒューマニタリアニズムの相続規則にほかなりません。そしてスタイナーは、遺贈の廃止を権利の形而上学に基礎づけます。「死者は権利をもたない。それゆえ左派リバタリアニズムは、遺贈の有効性を……認める必要はなく、おそらく認めるべきでもない。ある人が死に際して所有していた資産はすべて、放棄されたものとみなされる」。四十九年の賃借は、まさにこの直観を運用可能にしたものであり、家族の家という例外が、心情への唯一の譲歩です。この学派の三人目、フィリップ・ヴァン・パリースは、共有の取り分を恒久的な現金の流れに変えます。作られたものではなく「与えられた」あらゆるものに対する地代――雇用の地代も含めて――を財源とするベーシックインカムであり、それによって、カノンの暫定的な規則（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）が指し示す移行の手段を提供しています。権利としてのまっとうな暮らしと、その上に報われる貢献です。主な違いは範囲と時計です。哲学者たちは*作られなかったもの*を共有にします。カノンはあらゆるものを共有にし、功績にはそのどれをも、せいぜい働く生涯のあいだだけ保有させるのです。

## 有機体としての都市

機械の軸にはそれ自身の預言者がおり、彼はフロリダの低木林にある二十五エーカーの敷地で仕事をしていました。ジャック・フレスコは独学の工業デザイナーであり、その『*ヴィーナス・プロジェクト――文化の再設計*』（1995年）は、五十五ページにわたる図版入りの全体システムです。彼は、カノンの第二のメッセージが始まるところから始めます。自動化（彼の造語では「サイバネーション」）が不可逆的に労働を吸収していくことです。そして同じ高度で同じ結論を引き出します。障害は貨幣秩序そのものだ、というのです。「貨幣制度は、限られた資源しかない環境の中で人間の行動を管理する装置として、何年も前に発展した」と彼は書きます。「資源が乏しいときにのみ、貨幣はその分配を管理するために用いることができる――たとえば、浜辺で砂や海水を売ることはできない」。彼は自らの代案を資源基盤型経済と名づけました。「資源基盤型経済は、貨幣ではなく既存の資源を活用し、それらの資源を全住民のために最も効率的かつ人道的なやり方で分配する公平な方法を提供する」。彼が持ち出す思考実験は、ゲゼルなら裏返しで見覚えがあったであろうものです。道具を壊し、何が残るかを見るのです。

> 世界中のお金がすべて破壊されたとしても、表土や工場やその他の資源が無傷で残っているかぎり、私たちは建てたいものを何でも建て、人間のどんな必要をも満たすことができるだろう。人々が必要としているのはお金ではなく、政府の官僚機構やその他のいかなる機関にも訴えることなく、ほとんどの必需品に自由にアクセスできることなのである。
>
> — *The Venus Project*, p. 5

その実現は建築として示されます。同心円状の帯に配置された円形都市。それを運営するのは、彼が都市の「電気的な自律神経系」と呼ぶ「サイバネーション化されたシステム」です。所有は図書館のようなアクセス・センターに取って代わられ、決定は政治家ではなく技術者によって「統計力学を通じて到達され」、「都市全体が単一の複雑な有機体として機能する」のです。カノンの第七章の読者は、この仕様に見覚えを感じるでしょう。エロヒムの都市は一辺一キロメートルの単一の構造物であり、それぞれが「同じ建築家によって構想され」、「田園を『食って』しまわないため」に立方体をなし、その生命的なシステム――エネルギー、食糧、組織――は永遠者たちの目のもとでコンピュータによって監督されています（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=47) %}TBWTT 7:45–47{% end %}）。地上の計画は、五万人のための共同住宅を田園のただ中に建てるよう処方しており、その明示された理由も同じです。庭付きの一戸建てからなる惑星には、田園が残らないというのです（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=101) %}ETTMTTP 3:101{% end %}）。貨幣がなく、サイバネーション化され、自然を損なわない二つの都市有機体が、互いに二十年以内に、両者のあいだにもっともらしい伝達経路をもたない著者たちによって仕様化されたのです。フレスコは、このプロジェクトの主題の天井にさえ、真顔でかすめるように触れています。「世界有数の科学者の一部が、知的な地球外生命を求めて銀河の外縁を探ろうとしている一方で、ヴィーナス・プロジェクトは現在、地球上の問題を解決するために人間の知性を応用することにより大きな関心を寄せている」。より無防備な裏表紙は、フロリダの敷地を「第二のエデン」と呼んでいます。

## 精神のコモンズ

ここまでの系列のどの成員にとっても、豊かさは投影でした。ある一つの領域で、それは到来しました。そしてその周りに形成された制度は、計画でも小説でもなく、稼働しているインフラであるという点で、系列の中で唯一の項目です。情報を複製する限界費用がゼロにまで下がったとき、どの経済学の教科書も予測していなかった生産システムがおのずから組み上がりました。リーナス・トーバルズの1991年のUsenetへの投稿は、世界のサーバーと電話のソフトウェア基盤となり、誰も決して囲い込めないようライセンスされました。特定の誰でもない人々によって書かれたウィキペディアは、有料の百科事典の棚を引退させました。そして、この現象を「ピア・プロダクション」と名づけたイェール大学の研究者ヨハイ・ベンクラーは、その算術を示しました。世界のつながった人口は「その間に、毎日二十億から六十億時間の余暇」を抱えており、それは価格のつかない能力の常設の貯水池なのです。タプスコットとウィリアムズの『*ウィキノミクス*』（2008年）は、この論理がコードをはるかに越えて及ぶことを記録しました。その見せ場はゴールドコープです。経営不振のトロントの鉱山会社で、その最高経営責任者はLinuxの話に電撃を受け、五十年分の独自の地質データを公開ウェブに掲載しました。「次の六百万オンスの金がどこで見つかるかを、世界に教えてもらおう」。そして五十か国からの参加者が百十の目標地点を特定し、その半分は会社の知らないものであり、その五分の四が産出をもたらすのを目の当たりにしたのです。コモンズは企業よりもうまく探鉱しました。

この運動は殉教者を生み、彼の宣言はこの系列の一次資料に属します。「情報は力である」と、アーロン・スワーツは『*ゲリラ・オープンアクセス宣言*』（2008年）に書きました。「しかし、あらゆる力と同じく、それを自分たちのために独占したがる者たちがいる」。{{ footnote(id="7") }}彼の議論――大部分が公的資金でまかなわれた科学の記録は万人のものであり、それを有料の壁の向こうに囲い込むことは種の遺産に課される私的な税である――は、知識経済へと移し替えられたペインの地代の議論です。作られなかったコモンズが専有され、補償を負っている、というのです。同じ指示のカノン版は、研究活動全体に向けられています。物質的拘束からの解放は、とカノンは主張します、「すべての技術的・科学的能力が……もはや個別の利益のためではなく共同体全体のために、懸命に働き始め」さえすれば、ほんの数年しかかからないだろう、と（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=99) %}ETTMTTP 3:99{% end %}）。1975年に、黄金時代への近道として提案されたピア・プロダクションです。このコーパスが{% wiki(slug="cyberparadism") %}サイバーパラディズム{% end %}として追跡している現代の美的運動は、迫りくる豊かさの六つの「しるし」の一つに、核融合エネルギーや完全な自動化と並んでオープンソースの協働を数えています。この系列の証拠に照らせば、その順序づけは正しいと言えます。オープンソースは、すでに産業規模に達している唯一の「しるし」だからです。

## テクノ資本の機械

この系列の最も新しい項目は、2023年10月16日、想像しうるかぎり最もユートピア的でない住所、すなわちベンチャー・キャピタル企業のウェブサイトから届きました。マーク・アンドリーセンの『*テクノ楽観主義者宣言*』は、「私たちは信じる」という首句反復からなる五千語の文書であり、その豊かさにかかわる一節は、継ぎ目が見えることなくフレスコやカノンの第二のメッセージに接ぎ合わせることができるほどです。「私たちは、豊かさの尺度は価格の下落であると信じる」。「私たちは、技術の応用を通じて経済全体の価格を引き下げ、できるだけ多くの価格が事実上ゼロになるまで推し進めるべきだと信じる」。「私たちは、知性とエネルギーの両方を『計量するまでもないほど安く』すれば、究極の結果として、あらゆる物理的な財が鉛筆のように安くなると信じる」。{{ footnote(id="8") }}そのエンジンには、哲学者ニック・ランドから出典を明示して借用された名があります。「テクノ資本の機械、永続的な物質的創造、成長、豊かさのエンジン」。敵は観念です。宣言自身の一覧は、「存在論的リスク」「持続可能性」「ESG」「予防原則」「脱成長」「成長の限界」と続きます。そして文書は、引用文献の代わりに守護聖人の名簿で締めくくられます。{{ footnote(id="9") }}

カノンとの収斂は具体的です。どちらも物質的な問題は解決可能であり、その溶剤は科学であるとします。どちらもエネルギーの豊かさを蝶番として扱います（核融合は宣言の「第二の銀の弾丸」であり、サイバーパラディズムの六つの「しるし」の筆頭です）。どちらも限界の勧めを衰退の勧めとみなします。カノン自身の命令は「科学が楽園に変容させうるこの地上での生を享受しなさい」というものです（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=39) %}ETTMTTP 2:39{% end %}）。そこで道は交差し、音を立てて分かれます。アンドリーセンはこう言います。「私たちは、ユニバーサル・ベーシックインカムは人々を国家に飼育される動物園の動物に変えてしまうと信じる。人間は飼育されるために作られたのではない。人間は役に立ち、生産的であり、誇り高くあるために作られたのだ」。カノンはこう言います。「各々の存在は、たとえ働かなくとも、暮らせるものを持つ権利を持ちます」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）。そして生存の鞭のもとで行われる労働は「ひどく卑しめ」るものであり、「単純な機械ができる仕事」をするために自分の人生を売ることだ、と（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=38) %}ETTMTTP 2:38{% end %}）。宣言は、技術の変化が人間の労働の必要を「増やす」と主張し、市場で永遠に動く機械を聖別します。カノンは同じ機械を蛹として読みます。市場と貨幣は幼虫期の道具であり、成体の形――「考え、創造し、開花する」――には、価格体系が含まれていないのです。

この系列のそれ以前のどれも、この結果を予告していません。*ここではベンチャー・キャピタリストが保守派であり、1973年のコンタクティーのテクストが急進派なのです。* アンドリーセンは、賃労働、価格、蓄積を永遠に保存したままの豊かさを差し出します。脱出速度に達した資本主義です。カノンは、その三つすべてが溶けてしまう溶剤としての豊かさを差し出します。宣言の批評家たちはといえば、その政治をその技術よりも古いものとして読みます。エズラ・クラインはそれを「反動的未来主義」に分類しました。道具についてというよりも、「私たちはかつて勇敢で強かったのに、軟弱で弱くなってしまった」という確信についての文書だ、というのです。『ジャコバン』誌は、その系譜をニーチェ的な貴族的急進主義にまでたどりました。批評家たちの争点は宣言の*誰が利益を得るのか*にあり、カノンの争点は*何のためか*にあります。どちらも機械そのものには異を唱えません。

## 一つの教義、二つの軸

並べてみると、この系列は一つの表へと収束します。どの成員も一片を握っており、1973年から75年にかけてまるごと口述されたカノンの教義は、そのすべてを一度に握っています。

| 人は何のためにあるか | 芸術と科学の前提としての「豊かさと余暇」（ヘルツカ） | 「考え、創造し、開花する」（ETTMTTP 2:38） |
| 誰が決めるのか | フレスコの技術者、宣言の創業者たち、哲学者たちの正しい制度 | ジェニオクラシー、その後は最小限の監督のもとでの自動化された基盤（TBWTT 6:5, 7:45） |

三つの特徴が、カノンの項目をその一族の中で際立たせています。第一に、完全性です。それは二つの軸――ヨベルと機械――を一つの計画として走らせる唯一の成員であり、財産改革は明示的に移行体制として段階づけられ、自動化は明示的にその引退として段階づけられています。第二に、早さです。自動化にかかわる一節はパーソナル・コンピュータに先立っており、暫定的な規則は、学問的・政治的な波が数十年後に頂点を迎えることになる立場（ベーシックインカム、相続の返還、世界通貨）を、ときに字句どおりに先取りしています。第三に、そして種類において唯一のものとして、手本の主張です。系列の人間の成員はみな理論や外挿から論じますが、カノンは描写を主張します。計画を完了まで走らせた文明が、地上向けの写しを自らの「政治的・人道的な荷」として差し出しており、それは科学的な荷にともなうであろう危険なしに受け渡すことができる、と言うのです（{% libref(book="the-book-which-tells-the-truth", chapter=5, verse=65) %}TBWTT 5:65{% end %}）。この最後の主張こそ、このプロジェクトのラベルが存在する理由です。それは`framework`です。原典には明示されており、いかなる記録庫によっても検証できず、そしてこの比較を単に整然としたものではなく興味深いものにしている理由なのです。

## 読みが分かれるところ

これほど収斂する系列は恣意的な選別の疑いを招きます。したがって、分岐と失敗は全力で述べておくべきです。

**記録は敗北の記録です。** ヴェルグルは十四か月後に裁判所の命令によって閉ざされました。フライラント運動は、荷を解くこともなくケニアの沿岸で死に絶えました。ゲゼルのエデンは、経済秩序としてではなく、田園郊外として存続しました。破滅を運命づけられたレーテ共和国の財務担当委員としての彼の一週間は、大逆罪の裁判で終わりました。キブツは村落規模で一世紀にわたる機能する共産主義を築き、それから債務と世代の移り変わりのもとで、大半が給与と市場を再び受け入れました。ヴィーナス・プロジェクトは二十五エーカーを越えて育つことはありませんでした。オープンソースは自らの領域を征服しました――そしてその領域とは、財が無償で複製される領域です。その保守管理者たちは、報酬を受けているとしても、いまなおオープンソースが迂回している貨幣経済から支払われています。系列のあらゆる実験は、小さなままにとどまったか、国家によって止められたか、市場を再び受け入れたかのいずれかでした。カノンなら、これは文明規模に満たない実施が示すと予測されていた署名だと答えるでしょう。カノン自身の教義は、世界政府とジェニオクラシーによる行政を前提条件として挙げているからです（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=14) %}TBWTT 6:14{% end %}）。しかし批評家は、それをユートピア主義者の最も古い逃げ口上として聞く権利をもっています。設計は機能する、ただし歴史がただの一度も満たしたことのない前提条件が与えられれば、というわけです。

**計算問題は解消されたのではなく、プラットフォームを移されただけです。** 計画に対するミーゼスとハイエクの異議――価格は、いかなる管理者も集めることのできない分散した知識を運ぶ――は、意図によって経済を運営しようとした二十世紀のあらゆる試みを切り倒しました。そしてこの異議は、フレスコの統計力学にも、「エネルギー、食糧、組織」を監督するカノンのコンピュータにも全面的に当てはまります（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=45) %}TBWTT 7:45{% end %}）。現在よく聞かれる反論――十分な規模の機械知性こそが、欠けていた計算機*である*――は、まさに2020年代の生きた賭けであり、それは未決の賭けです。座席表には皮肉があります。ハイエクはアンドリーセンの守護聖人の一人であり、そのことは、系列の中で最も熱心な豊かさの運動を、系列の大半がめざす貨幣なき終着点を禁じる議論をした思想家の庇護のもとに置いているのです。

**ジェニオクラシーは、この教義の最も険しい崖です。** 知性によって門を設けた選挙権は、民主的平等の道徳的核心を打つものであり、主流の政治哲学は、測定された者による統治をそのあらゆる変種において退けています。異議――誰がテストを作るのか、誰が作り手を監査するのか、「生の知性」とはそもそも何を単位とするのか――は標準的なものであり、強力です。コーパスはこの戒めを運用上のものではなく方向を示すものとして扱っており、ラエル自身も第三の書で読者に答えて、計画の実現を、距離を置いた非ラエリアンの政治運動に委ねました（{% libref(book="lets-welcome-the-extraterrestrials", chapter=1, verse=87) %}LWTE 1:83–87{% end %}）。これは彼自身の立場であり、口述されたテクストではありません。そのいずれも、異議を解消するものではありません。異議はここに、それ自身の声で記録されています。

**カノンは自らの豊かさに留保をつけています。** この系列のカノンの地層の中で最も奇妙な文は、一つの限界です。人類が創造者の役割を受け継ぐかどうかを論じる中で、ヤハウェはこう述べます。「われわれは、人間が豊かさの中で安定しうるとは確信しません」（{% libref(book="the-book-which-tells-the-truth", chapter=5, verse=59) %}TBWTT 5:59{% end %}）。そして後のメッセージ、第三の書にヤハウェの人類への呼びかけとして収められたものは、種が自らの試練を生き延びる見込みを百に一つとしています（{% libref(book="lets-welcome-the-extraterrestrials", chapter=2, verse=96) %}LWTE 2:96{% end %}）。この教義は豊かさが到来するという約束ではありません。攻撃性がまず克服されたなら何を築くべきかという仕様書なのです。この系列の楽天的な読み――運命としての豊かさ――は、アンドリーセンのものであり、系列の中の他の誰のものでもありません。

**そして系列の成員たちは、それぞれの時代の人間でした。** ジョージの運動は単一税コロニーと市政のキャンペーンへと分裂しました。ヘルツカのアフリカは探検文学に描かれた空っぽのアフリカであり、持ち主がいないのは測量士の想像の中でだけでした。ゲゼルの主著は、現代の研究者たちが削除する時代のレトリックを含んでいます。{{ footnote(id="10") }}この系譜は、繰り返し現れる思考の構造の証拠として示されているのであって、聖人たちの交わりとして示されているのではありません。

## 彼らが植え続けた園

系列の中の一つの型は、そこにいる誰によっても計画されたものではありませんでした。ヘルツカの入植者たちは、氷河の下の谷にたどり着いて、そこをエデンと名づけました。ゲゼルはエデンという名の改革コロニーで経済学を書き、そこで亡くなりました。フロリダの低木林にあるフレスコの敷地は「第二のエデン」として宣伝されました。豊かさを築こうとした三人の独立した建設者が、名を求めて手を伸ばし、同じ園に手を伸ばしたのです。それは、供給が労働に先立つ場所、誰かがそれを稼ぐ前に果実が木になっている場所です。主流の読みは、この名を楽園を表すわかりきった文化的な略記とみなしますし、実際そのとおりです。コーパスの読みは、もう一層深く進みます。カノンにおいて、{% wiki(slug="eden") %}エデンは現実の施設でした{% end %}。創造者たちの実験室の園であり、種がそこで始まった、設計された豊かさです。そして創造者たち自身の世界は、いまもその経済で動いています（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=52) %}ETTMTTP 2:51–52{% end %}）。枠組みの内部では、改革者たちが繰り返し描く園は、計画として自らを形にしていく記憶です。本稿が読んできた系列は、欠乏の内側から、自らが創造されたときの稼働条件を逆行分析している種なのです。これは`inferred`な型の上に立つ`framework`の読みであり、両方のラベルが当てはまります。とはいえ、型そのものは一次資料の中に、字句どおり、三度現れています。

枠組みが最後に付け加えるのは、賭けられているものです。カノンの{% wiki(slug="golden-age") %}黄金時代{% end %}は、一本の分かれ道の一方の枝であり、もう一方の枝――このプロジェクトの{% wiki(slug="apocalypse") %}黙示録{% end %}の項目が記録する自己破壊――には、何もしなければたどり着きます。機械の軸は疾走しています。1975年のテクストが約束した自動化は、大規模モデルと人型ロボット工学の十年にあって、設備投資の一項目になっています。ヨベルの軸はそうではありません。富は、ピケティの *r > g* が定説にした速度で世代を越えて集中し、地球上のいかなる政体も四十九年の賃借を議論してはいません。レビ記から宣言に至るまで、この系列の診断は、第二の軸は選択の問題だというものです。ヘルツカはそれを1890年の自信をもって述べました。時代遅れの世界秩序の悲惨を耐え忍ぶよう私たちを強いるものはもはや何もなく、既存の文明の手段が与えうる幸福と豊かさから私たちを妨げるものは何もない――「nichts, als unsere eigene Thorheit」。*私たち自身の愚かさのほかには、何も。* カノンはそれをもっと短く、1975年に、機械をつくり上げたばかりで、それが何のためにあるのかをまだ決めていなかった種に向けた一文で述べました。
