**ヘブライ語聖書**（ヘブライ語：תָּנָ״ךְ、*タナハ*）は、二十四書からなるヘブライ語の聖典集成です。**トーラー**（教え）、**ネビイーム**（預言者）、**ケトゥビーム**（諸書）の三部に分かれ、その頭文字から頭字語 *タナハ* が作られています。{{ footnote(id="1") }}ユダヤ教の正典であり、キリスト教の旧約聖書の源であり、イスラームがクルアーンを通して読みつつ敬意を払う本文でもあります。およそ十二世紀にわたって成立し、{% wiki(slug="masoretic-text") %}マソラ{% end %}の伝統を通じて類まれな忠実さで伝えられてきたこの集成は、人類史上最も綿密に研究されてきた著作群の一つであり、本文研究、考古学、神学、文学の学術研究がひとしく取り組んできました。

Wheel of Heavenの枠組みにおいて、ヘブライ語聖書は本文献集が読む第一の典拠であり、その総合の中心にある本文です。{% claim(type="framework", id="woh-claim-0053") %}本枠組みはこれを、信仰や寓意を必要とする宗教的神話の書としてではなく、歴史的記録として扱います。科学以前の語彙ゆえに不完全ではあるものの、[エロヒム](../elohim/)と諸時代にわたる彼らの介入について報告していることにおいては、実質的に正確な記録です。{% end %}本文献集はこの立場を[ヤハウェ](../yahweh/)の声で述べています。

> *「ヘブライ語聖書は、字義どおりの信仰か寓意的な再解釈かのどちらかを必要とする宗教的神話の書ではない。それは歴史的記録であり、科学以前の語彙においては不完全だが、内容においては実質的に正確であって、解釈の鍵が手に入れば直接読むことができる。」*

本文献集の他のほぼすべての項目が、この書のいずれかの箇所に依拠しています。

## 構成、言語、本文

### 三つの部

**トーラー**、すなわち創世記、出エジプト記、レビ記、民数記、申命記のモーセ五書は、創造と原初の物語、族長たちの歴史、シナイの律法を収めています。**ネビイーム**は、征服から王国時代を経てバビロン捕囚までを物語る前の預言者（ヨシュア記、士師記、サムエル記、列王記）と、後の預言者（イザヤ書、エレミヤ書、エゼキエル書、十二小預言書）に分かれます。**ケトゥビーム**は残りを集めたもので、詩編、箴言、ヨブ記の詩と知恵、五つの巻物（雅歌、ルツ記、哀歌、コヘレトの言葉、エステル記）、そしてダニエル書、エズラ記・ネヘミヤ記、歴代誌を含みます。ユダヤ教の数え方ではこれらは合わせて二十四書です。プロテスタントの旧約聖書は、サムエル記、列王記、歴代誌、エズラ記・ネヘミヤ記、十二小預言書をそれぞれの構成書に分けることで三十九書となります。カトリックと正教会の正典は、そのどちらにもない第二正典を加えています。

### 言語

本文は主に**聖書ヘブライ語**で書かれており、その形は長い成立期間を通じて変化しています。わずかな箇所は、ペルシア時代の帝国の共通語であった**聖書アラム語**で書かれています。ダニエル書2章4節b–7章28節、エズラ記4章8節–6章18節および7章12–26節、エレミヤ書10章11節の一節、そして創世記31章47節の二語からなる地名です。

### 成立と正典化

主流の学術研究は、この集成の成立を、後期青銅器時代（紀元前12世紀頃）からペルシア時代とヘレニズム時代にかけてのおよそ十二世紀に位置づけ、ダニエル書を含む最も新しい資料は紀元前2世紀に及ぶとしています。伝統的なユダヤ教の年代づけでは、いくつかの書がより早く置かれます。正典は段階的に閉じられました。まずトーラー、次に預言者、そして諸書であり、三部構成は第二神殿時代後期までにおおむね固定されました。

### 本文証言

受け継がれてきたヘブライ語本文は**マソラ本文**です。これは、紀元6世紀から10世紀ごろにかけてティベリアのマソラ学者たちが母音符号と朗唱符号を付した子音本文であり、主要な写本はアレッポ写本（紀元930年頃）と完全なレニングラード写本（1008年）です。さらに三つの証言が本文の歴史を支えています。{% wiki(slug="dead-sea-scrolls") %}**死海文書**{% end %}（紀元前2世紀頃〜紀元1世紀）は、写本証拠をまるまる千年さかのぼらせました。アレクサンドリアで作られた紀元前3〜2世紀のギリシア語訳である{% wiki(slug="septuagint") %}**七十人訳**{% end %}（LXX）は、時にマソラ以前のヘブライ語の読みを保存しています。**サマリア五書**は、トーラーの独立した校訂本を伝えています。これらの証言は綴り、語順、時に節の単位で異なりますが、実質においては緊密に一致しています。イザヤ書大巻物（1QIsaᵃ、紀元前125年頃）は、千年を超える筆写を隔てて、マソラ本文のイザヤ書と一致しているのです。{{ footnote(id="6") }}エマヌエル・トーヴの『ヘブライ語聖書の本文批評』は、この資料についての標準的な総合であり続けています。{{ footnote(id="5") }}

## Wheel of Heavenの読解

### なぜヘブライ語本文が第一なのか

本文献集はヘブライ語聖書を、エロヒムの働きについて現存する古代の記録の中で最も正確なものとして扱います。ただしその根拠は神学的なものではなく、系譜的なものです。ラエルの典拠資料において、イスラエルの民は、その地に実験施設を置いていた創造者チーム、すなわち[エデン](../eden/)の作業を担ったチームが造った人間たちであり、かつエロヒムの息子たちと人の娘たちの結合を通じて、創造者たちの「直系の子孫」です（[ヘブライ人](../hebrews/)を参照）。この本文はその民の文学です。その正確さは接触の連続性から生じています。この本文を生み出した系統は、本文が記録する働きの担い手である同盟と、最も密接に、最も長く関係を保ち続けたのです。{{ footnote(id="3") }}本文献集はこの読解を直接に述べています。

> *「総合の構造的な中心にあるのはヘブライの伝統である。本文献集の読解では、ヘブライ語聖書は同盟の地球との交信についての最も直接的で、最も媒介の少ない記録である。この本文は特定の系統、すなわちエデン系統、エデンという地理的場所で同盟が育てた元の集団の子孫によって、牡牛座の時代の再建から牡羊座の時代の預言者の伝統に至る長い弧のなかで生み出された。」*

この優位は現実のものですが、排他的なものではありません。他の創造チームの人間たちもそれぞれの起源の伝統を保ち、その多くは比較神話学の資料、すなわちメソポタミア、エジプト、ヴェーダ、ギリシアなどの集成のなかに断片的な形で残っています。典拠が述べるとおり、ヘブライ語聖書は「いくつかある伝統の一つであって、唯一特権的な典拠ではない。しかし、最も完全で最も明確に展開されたものであり、それゆえ本文献集はこれを最も綿密に読む」のです。並行する近東の本文、すなわち *アトラ・ハシース*、*ギルガメシュ*、シュメールの洪水と創造の資料は、同じ出来事についての隣り合う記憶として読まれます。それらを伝えた系統では、記録がヘブライの系統よりも速く劣化したのです。

### 解読の解釈学

神話としてではなく記録として読むと、本文は一貫した実務上の意味の組を示します。本文献集は、創世記1章を超自然的な創造ではなく遺伝子工学の記述として、[ネフィリム](/wiki/nephilim/)を同盟と人間の混血として、[大洪水](../great-flood/)を気象ではなく意図的な大災害として、シナイを神の顕現ではなく同盟との公式の謁見として、分かたれた水を指向性ビームによる作業として、そして[エロヒム](../elohim/)を単数ではなく複数として解読します。この解読は、聖書の著者たちに欠けていた語彙を備えた、科学的に成熟した読者を前提としています。だからこそ本枠組みは、現在の時代を、この本文がついにそれが常に語ってきたとおりに読める時として扱うのです。

### ヘブライ語原文を読む

本枠組みの方法は、翻訳の背後にあるヘブライ語を読むことです。それが覆す最も重大な操作は、複数形の *エロヒム* を単数の「神」と訳すことです。*[Message from the Designers](/wiki/message-from-the-designers/)* が述べるとおり、*「創造者たちを指す言葉『エロヒム』を、神という単数の言葉に置き換えたこと——エロヒムはヘブライ語でエロハの複数形であるのに——そうして創造者たちを単一の理解できない神に変えたこと」* です。その論証の全体は[神々の複数性](../plurality-of-gods/)で展開されています。創世記の複数形の動詞と代名詞、すなわち「*我々* は造ろう」「*我々の* 像に」「*我々の* 一人のように」は、文字どおりに読まれます。

他にもいくつかの翻訳上の操作が、具体的なヘブライ語を神学的抽象へと平板化しています。{{ footnote(id="4") }}

- **タニーニーム**（創世記1章21節）：創造の記述における「大きな爬虫類」すなわち竜が、「鯨」や「大きな海の生き物」へと和らげられています。
- **マラキーム**：「使者」すなわち使節に、「天使」という超自然的な意味が重ねられています。
- **ナハシュ**：園の単なる「蛇」として読まれ、[蛇](../serpent/)、すなわち追放された[ルシファー](../lucifer/)派閥の工作者を指す実務上の呼称としての役割が覆い隠されています。
- **ベネイ・ハ＝エロヒム**：「エロヒムの息子たち」。その複数の指示対象は、翻訳のなかで繰り返しぼかされています。

ここで正典上の厳密さを一点述べておく必要があります。伝統はまさにその混同を招くからです。エデンの蛇はルシファー派閥であり、自らの被造物の側に立ち、人間たちに造り手についての真実を告げようとした創造者たちです。それは[サタン](../satan/)では *ありません*。サタンは別の、正反対の派閥を率いていました。人間の計画を誤りと判断し、その破壊を強く求めた廃絶派です。ルシファーとサタンを宇宙的な悪の一人の人物に融合させた中世の混同は、本文献集の読解では、解釈の歴史において最も代償の大きい混同の一つであり、本枠組みは両者をはっきりと区別しています。

### 不完全さと、教会の役割

以上のどれも、本文を無謬のものとして扱うものではありません。本枠組みは、人間の著者たちが記録したことを常に理解していたわけではないこと、数世紀にわたる編集が元の内容の上に文化的な枠組みを重ねたこと、そして正典化の過程がある本文を残し他の本文を落としたことを認めています。除外されたものの中には[エノク書](/wiki/watchers/)があります。これらは解読可能な層であって、致命的な改竄ではありません。記録はそれらを越えて生き残っています。本文献集は、この本文を世界へ運んだ伝統にも同じ節度ある判断を向けます。翻訳上と神学上の誤りを名指ししながらも、伝承の功績は認めているのです。*「しかしそれをあまり責めないでください。なぜなら、真実の証人である聖書が全世界に見いだされうるのは、それのおかげだからです。」* この読解では、ヘブライ語聖書は翻訳において最も歪められた本文であると同時に、そのおかげで最も広く行き渡った本文でもあります。

### 本文献集独自の翻訳

読解がヘブライ語にかかっているため、本文献集は受け継がれた英語訳に頼らず、引用する本文を自ら翻訳しています。[Wheel of Heaven翻訳プログラム](https://docs.wheelofheaven.world/contributing/content/source-text-translation/)はマソラ本文を節単位の注解つきで英語に訳し、各章は公開前に審査と承認を経ます。対象は{% libref(book="genesis-woh") %}創世記{% end %}と{% libref(book="daniel-woh") %}ダニエル書{% end %}の全体、そして三つの正典の書が引用する他の書の章です。すなわち{% libref(book="exodus-woh") %}出エジプト記{% end %}、{% libref(book="numbers-woh") %}民数記{% end %}、{% libref(book="deuteronomy-woh") %}申命記{% end %}、{% libref(book="joshua-woh") %}ヨシュア記{% end %}、{% libref(book="judges-woh") %}士師記{% end %}、{% libref(book="1-samuel-woh") %}サムエル記上{% end %}、{% libref(book="1-kings-woh") %}列王記上{% end %}、{% libref(book="2-kings-woh") %}列王記下{% end %}、{% libref(book="isaiah-woh") %}イザヤ書{% end %}、{% libref(book="jeremiah-woh") %}エレミヤ書{% end %}、{% libref(book="ezekiel-woh") %}エゼキエル書{% end %}、{% libref(book="amos-woh") %}アモス書{% end %}、{% libref(book="jonah-woh") %}ヨナ書{% end %}、{% libref(book="zephaniah-woh") %}ゼファニヤ書{% end %}、{% libref(book="zechariah-woh") %}ゼカリヤ書{% end %}、{% libref(book="psalms-woh") %}詩編{% end %}、{% libref(book="job-woh") %}ヨブ記{% end %}、{% libref(book="proverbs-woh") %}箴言{% end %}、そして{% libref(book="ecclesiastes-woh") %}コヘレトの言葉{% end %}です。この翻訳は神の名を「主」ではなく *YHWH* と表記し、正典自身の読解は、伝統的な読解や批評的な読解と並んで、明確に区別された受容注に置かれています。正典がどの章を引用しているかは、書ごとに[ラエリアン正典の参照コーパス](../reference-corpus-of-the-raelian-canon/)に示されています。

### 天体の語彙

ヘブライ語聖書は天文学についてはわずかしか語らないため、星座への二つの明示的な言及はとりわけ目を引きます。つむじ風の中から、ヨブ記38章32節は、ヨブが「**マザロト**（מַזָּרוֹת）をその時に引き出す」ことができるかと問います。これは古代の諸訳がもはや翻訳できなかった *孤語*（ハパックス・レゴメノン）です。そのほぼ双子にあたる**マザロート**（מַזָּלוֹת）は、列王記下23章5節に、ヨシヤ王が「太陽と月とマザロートと天の万象に」香をたいた者たちを一掃した対象の一つとして現れます。標準的な語源説によれば、両者はアッカド語の *manzaltu*（「星の座」）に由来し、本文献集はそれらを、ヘブライの系統が担ってきた黄道十二宮の伝統についてのその系統自身の証言として読みます。専用の扱いは[マザロト](/wiki/mazzaroth/)にあります。

## 学術的・批判的観点

本枠組みの読解は、意図的に主流の学術研究に対立するのではなくそれと並び立つものであり、その事実的基盤の多くを共有しています。

**資料批判。** 文書仮説は、ユリウス・ヴェルハウゼンが *Prolegomena zur Geschichte Israels*（1878年）で古典的な形を与え、リチャード・フリードマンの *Who Wrote the Bible?*（1987年）で平易なものとなりました。この仮説はモーセ五書を四つの資料（J、E、D、P）から織り上げられたものとして読みます。これは、神名 *YHWH* と *エロヒム* の交替が最初に示唆した再構成です。{{ footnote(id="2") }}本枠組みは本文が複合的であることに異を唱えません。ある箇所をどの資料層が保存したかにかかわらず、残された内容を実際の出来事の記録として読み、継ぎ目を、複数の経路を通じて伝えられた記憶の痕跡として扱います。

**本文研究と考古学の学術研究。** 伝承については、本文献集は本文批評（トーヴ）と、本文の安定性を裏づけた死海文書の確認と一致しています。考古学については、証拠が確立していることと推測にとどまることとを区別しています。イスラエル・フィンケルシュタインとニール・シルバーマンの最小主義的読解（*The Bible Unearthed*、2001年）は退けられるのではなく取り上げられ、それが反発した以前のオルブライト学派の伝統も同様です。イスラエル宗教の歴史については、本枠組みは、フランク・ムーア・クロスとマーク・S・スミスによる神々の会議とカナンとの連続性に関する研究を、本文献集が歴史の水準で読む複数性を文献学の水準で取り戻すものとして読みます。ロバート・オールターの文学的翻訳と注解、そして大陸系の注解の伝統（ヴェスターマン、カッスート、サルナ、クーゲル）は、本文の技法と意味について取り戻しているものゆえに読まれています。

**代替史の読解。** 本枠組みは、その介入主義的な前提を、より広い再解釈の文献と共有しています。ジャン・サンディの文献学的読解、マウロ・ビリーノの厳密な逐語の方法、ポール・アンソニー・ウォリスの比較研究、そしてそれ以前のゼカリア・シッチンのアヌンナキ再構成です。本枠組みはヘブライ語を文字どおりに読むというビリーノの規律を採用しつつ、自らの解釈をシッチンのシュメール的図式ではなくラエルの正典に基づかせています。シッチンが創世記をシュメールの典拠からの派生物として扱うのに対し、本文献集はそれを、同じ出来事についての独立した、そして上に述べた系譜的な論拠からすれば、より正確な記録として読みます。
