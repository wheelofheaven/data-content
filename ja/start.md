## 1. 前提と、それを唱えているのは誰か

*約一分。*

Wheel of Heaven は、創世記が{% wiki(slug="elohim") %}エロヒム{% end %}と呼ぶ存在たちは、別の世界から来た、小さく技術的に高度な人類の文明であったと提唱します。
彼らは人類を含む地球の生命を設計し、多くの伝統の宗教テキストは、その作業の記憶を圧縮された形で保存しています。

この提唱は、クロード・ヴォリロン(ラエル)が1974年以降に発表したラエリアンのメッセージに由来します。
本サイトは古代の資料をそのレンズを通して読み、そのことを公然と述べています。
本サイトを書いているのは一人の{% wiki(slug="raelism") %}ラエリアン{% end %}の著者であり、筆名を用い、AI の助けを得て執筆しています。ラエリアン・ムーブメントの公式出版物ではありません。
詳しくは[プロジェクトについて](/ja/about/)と[著者](/ja/author/zara-zinsfuss/)のページをご覧ください。

## 2. 典拠と解釈をどう見分けるか

*約二分。*

各ページには、そのページが主に行っている主張の種類を示すバッジが付いています。

- **直接的(Direct)**:一次資料に述べられており、異論のないもの。*ヘブライ語の* elohim *は形のうえで複数形である。*
- **枠組み(Framework)**:ラエリアンの正典に述べられているが、主流の学術には受け入れられていないもの。*エロヒムは物理的存在の文明である。*
- **推論的(Inferred)**:典拠がそのとおりの言葉では述べていないが、典拠の合理的な読みであるもの。*バベルの塔は造り手たちへの和平の捧げ物として建てられた。*
- **思弁的(Speculative)**:単一の典拠を超え出る総合。*ギリシア、メソポタミア、カナンの神々の戦いの物語は、同じ一つの争いを記憶している。*

長いページには、複数の種類の主張が含まれます。
バッジが示すのは主たる主張であり、それ以外の主張は本文の中で、「この読みでは」や「主流の学術は……とする」といった言い回しによって、その都度示されます。
ラベルについての詳しい説明は[方法](/ja/method/)のページにあります。

## 3. 一節を精読する

*約三分。*

{% library(book="genesis-woh", chapter=1, verse=26) %}
エロヒムは言った、「われわれの形にかたどり、われわれに似せて人を造ろう。そして彼らに、海の魚、天の鳥、家畜、地のすべて、また地の上を這うすべての這うものを治めさせよう」。
{% end %}

**ヘブライ語が述べていること。**
語り手は *Elohim*、形のうえで複数形の名詞です。
動詞 *na'aseh*「造ろう」は一人称複数であり、所有接尾辞 *be-tzalmenu*(「われわれの形に」)と *ki-dmutenu*(「われわれに似せて」)も同じく一人称複数です。
これらの形については争いがありません。

**通常どう読まれているか。**
読者たちはこの複数を主に四つの仕方で解決してきました。王の「われわれ」(尊厳の複数形)として、三位一体の予示として、天の従者たちの会議に向けた神の語りかけとして、そして文字どおり複数の造り手として、です。
今日の聖書学者の多くは、{% libref(book="psalms", chapter=82, verse=1) %}詩篇82篇{% end %}や{% libref(book="1-kings", chapter=22, verse=19) %}列王記上22章{% end %}の天の集会と比較して、会議の読みを支持しています。

**Wheel of Heaven が提唱すること。**
四つ目の読みです。エロヒムが集団として協議するのは、彼らが実際に集団、すなわち人類を自分たちの身体的な似姿に造ろうとしている設計者のチームだったからです。
「形」と訳される名詞 *tselem* は、通常は像や切り抜かれた似姿といった具体的な形象を意味し、霊的な類似よりも身体的な類似によく合います。

**その理由。**
複数形の発話は、同じ種類の場面で繰り返し現れます。人類の創造の場面、エデンの後(「人はわれわれの一人のようになった」、{% libref(book="genesis-woh", chapter=3, verse=22) %}創世記3:22{% end %})、そして{% wiki(slug="babel") %}バベル{% end %}({% libref(book="genesis-woh", chapter=11, verse=7) %}創世記11:7{% end %})です。
そのたびに、複数の語り手たちは人類について何かを決め、それを実行に移します。
ラエリアンのメッセージは、文法とは独立に、創造について同じ説明を与えています。

## 4. 最も強い反論

*約二分。*

*Elohim* がイスラエルの神を指すとき、通常は単数の動詞をとります。
聖書の最初の節は *bara Elohim*「エロヒムは創造した」であり、動詞は単数形です。
多くの読者にとって、それで問題は決着します。この名詞は形のうえでは複数形でも意味は単数であり、26節の「われわれ」は従属する存在たちの会議に向けられている、というわけです。

Wheel of Heaven はこの文法を受け入れており、その論拠を複数形そのものに置いてはいません。
論拠を置いているのは、テクストが複数形で語る箇所と、ラエリアンの説明です。この説明は、単数の動詞を、集団のために行動する一人の代表者の発話として読みます。
会議の読みも、複数の造り手の読みも、どちらも複数形を真剣に受け止めています。両者が異なるのは、その場に誰がいたのかという点です。
ヘブライ語だけではそのどちらとも決められません。[エロヒム](/ja/wiki/elohim/#what-would-revise-this-reading)の項目は、プロジェクトの読みを弱めうる知見を挙げています。

## 5. 次に読むもの

*約二分。*

- **物語をたどる。** [年表](/ja/timeline/)は、歳差の各時代に一章ずつ、十二の章で物語を語ります。
- **用語を調べる。** [エロヒム](/ja/wiki/elohim/)の項目は、サイトで最も多くリンクされているページです。[百科事典](/ja/wiki/)には約150の項目があります。
- **典拠を読む。** [ライブラリ](/ja/library/)には、ラエリアンの書物と、創世記その他のテキストの新しい翻訳が収められており、原語を並べて示し、争点となる各語に注を付けています。
- **方法をその全体において見る。** [サンディとラエリアンのメッセージ](/ja/articles/sendy-and-the-raelian-messages/)は、最初のラエリアンの書物とジャン・サンディの先行する著作とを箇所ごとに比較し、ラエルがサンディから借用したという見方を衡量しています。
- **データを使う。** [Divine-Council Index](/datasets/divine-council-index/)(神的会議索引)は、十二の伝統にわたる神的会議を出典箇所とともに CSV と JSON で一覧にしており、誰でも検証・再利用できます。
