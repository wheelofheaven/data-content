## 1. 前提と、それを唱えているのは誰か {#premise}

*約一分。*

Wheel of Heaven は、創世記が{% wiki(slug="elohim") %}エロヒム{% end %}と呼ぶ存在たちは、別の世界から来た、小さく技術的に高度な人類の文明であったと提唱します。
彼らは人類を含む地球の生命を設計し、多くの伝統の宗教テキストは、その作業の記憶を圧縮された形で保存しています。

{% rows() %}
典拠 | クロード・ヴォリロン(ラエル)が1974年以降に発表したラエリアンのメッセージです。
方法 | 本サイトは古代の資料をそのレンズを通して読み、そのことを公然と述べています。
著者 | 一人の[ラエリアン](/ja/wiki/raelism/)の著者であり、筆名を用い、AI の助けを得て執筆しています。
位置づけ | ラエリアン・ムーブメントの公式出版物ではありません。
{% end %}

詳しくは[プロジェクトについて](/ja/about/)と[著者](/author/zara-zinsfuss/)のページをご覧ください。

## 2. 典拠と解釈をどう見分けるか {#labels}

*約二分。*

主張には、それが述べられるその場所で、四つの種類のいずれかのラベルが付けられます。
ラベルの付いた文には、ラベルの色の細い下線と点が付いています。点をタップすると、そのラベルの意味が表示されます。

{% rows() %}
claim:direct | 一次資料に述べられており、異論のないもの。
claim:framework | ラエリアンの正典に述べられているが、主流の学術には受け入れられていないもの。
claim:inferred | 典拠がそのとおりの言葉では述べていないが、典拠の合理的な読みであるもの。
claim:speculative | 単一の典拠を超え出る総合。
{% end %}

それぞれの例を一つずつ、項目の中で付けられるのと同じ形でラベルを付けて示します。

- {% claim(type="direct") %}ヘブライ語の *elohim* は形のうえで複数形である。{% end %}
- {% claim(type="framework") %}エロヒムは物理的存在の文明である。{% end %}
- {% claim(type="inferred") %}バベルの塔は造り手たちへの和平の捧げ物として建てられた。{% end %}
- {% claim(type="speculative") %}ギリシア、メソポタミア、カナンの神々の戦いの物語は、同じ一つの争いを記憶している。{% end %}

長いページには、複数の種類の主張が含まれます。
ラベルが示すのは論証が拠って立つ主張であり、それ以外の主張は本文の中で、「この読みでは」や「主流の学術は……とする」といった言い回しによって、その都度示されます。
ラベルについての詳しい説明は[方法](/ja/method/)のページにあります。

## 3. 一節を精読する {#verse}

*約三分。*

{% library(book="genesis-woh", chapter=1, verse=26) %}
エロヒムは言った、「われわれの形にかたどり、われわれに似せて人を造ろう。そして彼らに、海の魚、天の鳥、家畜、地のすべて、また地の上を這うすべての這うものを治めさせよう」。
{% end %}

**ヘブライ語が述べていること。**
語り手は *Elohim*、形のうえで複数形の名詞です。
動詞 *na'aseh*「造ろう」は一人称複数であり、所有接尾辞 *be-tzalmenu*(「われわれの形に」)と *ki-dmutenu*(「われわれに似せて」)も同じく一人称複数です。
これらの形については争いがありません。

{% interlinear(lang="he", dir="rtl", caption="創世記1:26の冒頭の語を、右から左へ読みます。印の付いた形は複数形です。") %}
וַיֹּאמֶר | vayyomer | そして言った | 動詞、単数
אֱלֹהִים | Elohim | エロヒム | 名詞、形のうえで複数 | *
נַעֲשֶׂה | na'aseh | 造ろう | 動詞、複数 | *
אָדָם | adam | 人 | 名詞、単数
בְּצַלְמֵנוּ | be-tzalmenu | われわれの形に | 「われわれの」、複数 | *
כִּדְמוּתֵנוּ | ki-dmutenu | われわれに似せて | 「われわれの」、複数 | *
{% end %}

**通常どう読まれているか。**
読者たちはこの複数を主に四つの仕方で解決してきました。

{% rows() %}
王の「われわれ」 | 尊厳の複数形。一人の語り手が自分自身について複数形を用います。
三位一体 | キリスト教の神の三つの位格の予示。
会議 | 天の従者たちの会議に向けた神の語りかけ。 | 今日の学者の多く
複数の造り手 | 文字どおりの複数。造り手は一人ではありません。 | !Wheel of Heaven
{% end %}

今日の聖書学者の多くは、{% libref(book="psalms", chapter=82, verse=1) %}詩篇82篇{% end %}や{% libref(book="1-kings", chapter=22, verse=19) %}列王記上22章{% end %}の天の集会と比較して、会議の読みを支持しています。

**Wheel of Heaven が提唱すること。**
四つ目の読みです。エロヒムが集団として協議するのは、彼らが実際に集団、すなわち人類を自分たちの身体的な似姿に造ろうとしている設計者のチームだったからです。
「形」と訳される名詞 *tselem* は、通常は像や切り抜かれた似姿といった具体的な形象を意味し、霊的な類似よりも身体的な類似によく合います。

**その理由。**
複数形の発話は、同じ種類の場面で繰り返し現れます。人類の創造の場面、エデンの後(「人はわれわれの一人のようになった」、{% libref(book="genesis-woh", chapter=3, verse=22) %}創世記3:22{% end %})、そして{% wiki(slug="babel") %}バベル{% end %}({% libref(book="genesis-woh", chapter=11, verse=7) %}創世記11:7{% end %})です。
そのたびに、複数の語り手たちは人類について何かを決め、それを実行に移します。
ラエリアンのメッセージは、文法とは独立に、創造について同じ説明を与えています。

## 4. 最も強い反論 {#against}

*約二分。*

*Elohim* がイスラエルの神を指すとき、通常は単数の動詞をとります。
聖書の最初の節は *bara Elohim*「エロヒムは創造した」であり、動詞は単数形です。
多くの読者にとって、それで問題は決着します。この名詞は形のうえでは複数形でも意味は単数であり、26節の「われわれ」は従属する存在たちの会議に向けられている、というわけです。

Wheel of Heaven はこの文法を受け入れており、その論拠を複数形そのものに置いてはいません。
論拠を置いているのは、テクストが複数形で語る箇所と、ラエリアンの説明です。この説明は、単数の動詞を、集団のために行動する一人の代表者の発話として読みます。

{% compare(left="会議の読み", right="複数の造り手の読み", shared="どちらも複数形を真剣に受け止めています。両者が異なるのは、その場に誰がいたのかという点です。") %}
「われわれ」と言うのは誰か | 唯一の神が、従属する存在たちの会議に向けて | 造り手たちが、互いに向けて
単数の動詞 | 唯一の神が行動する | 一人の代表者が集団のために行動する
支持するのは | 今日の聖書学者の多く | ラエリアンのメッセージと Wheel of Heaven
{% end %}

ヘブライ語だけではそのどちらとも決められません。[エロヒム](/ja/wiki/elohim/#what-would-revise-this-reading)の項目は、プロジェクトの読みを弱めうる知見を挙げています。
