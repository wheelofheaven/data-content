**亚当**（<span class="hebrew">אָדָם</span>，*ʾāḏām*）与**夏娃**（<span class="hebrew">חַוָּה</span>，*ḥawwāh*）是希伯来圣经《创世记》叙事中的最初人类。亚当在《创世记》2:7 中由耶和华·耶洛因「用地上的尘土」造成；夏娃在《创世记》2:21–22 中由他肋旁的一部分建造而成，并在《创世记》3:20 中被命名为「众生之母」（*ʾēm kol-ḥay*）。二人一同是《创世记》第 2—4 章的核心夫妇：被安置在伊甸园中，被授予关于[分别善恶之树](../tree-of-the-knowledge-of-good-and-evil/)的唯一禁令，受[蛇](../serpent/)劝诱而吃了树上的果子，被逐出园子，并被记为该隐、亚伯与塞特的父母。他们在希伯来圣经中的记载以亚当 930 岁去世告终（《创世记》5:5）；夏娃之死未有记载。

按雷尔派源材料所发展、并为 Wheel of Heaven 文集所采纳的解读，亚当与夏娃是历史人物，而非象征，也并非一般意义上的最初人类。他们是[耶洛因](../elohim/)创造者之**以色列团队**在其[伊甸](../eden/)装置中的奠基人类夫妇——那是分布在洪水前超大陆上的七个创造者团队装置之一——于狮子座时代晚期（约公元前 8,850 年）、伊甸阶段末尾被设计制造出来；该团队定型的人类谱系，即最初的亚当人，则在更早的狮子座时代开端（约公元前 11,375 年）就已合成。{{ footnote(id="5") }} 他们由[遗传工程](../genetic-engineering/)以耶洛因的遗传物质与地球基质组装而成，在伊甸围场内受教育，并在那里得到持异见的[路西法](../lucifer/)派系向他们披露的、被扣留的科学知识——即《创世记》第 3 章所记的蛇之干预。当母星议会着手限制这一知识时，他们遭到驱逐，而他们的后代开创了伊甸世系的文明，其后来的历史为希伯来圣经所保存。{{ cite(id="the-book-which-tells-the-truth", text="[1]", title="佛里翁（雷尔），《真理之书》（1974），第 2 章——亚当与夏娃作为以色列团队最初设计制造的人类") }}

## 《创世记》叙事

《创世记》包含两段创世记述，文集将其读作涵盖不同的范围，而非把一个故事讲了两遍。{{ footnote(id="1") }} 《创世记》1:26–28 是概述：「我们要照着我们的形像造人」（*naʿaśeh ʾāḏām bə-ṣalmēnû*），「造男造女」。其中没有点出任何个人的名字；复数的「我们要造」是耶洛因以其本来所是的复数文明在说话。

详细的记述随后见于《创世记》第 2 章。在那里，耶和华·耶洛因造出第一个人，并赋予他生命：

{% library(book="genesis-woh", chapter=2, verse=7) %}
YHWH 厄罗音用大地的尘土形塑人，将生命的气息吹入他的鼻孔；人就成了有生命的存在。
{% end %}

耶和华·耶洛因「在东方的伊甸」立了一个园子，在其中设置生命之树与分别善恶之树，并颁下唯一的禁令：那第二棵树上的果子「你不可吃」。那人为动物命名；随后，因「没有遇见配偶帮助他」，耶和华·耶洛因使他「沉睡」（*tardēmâ*），取下他的一条肋骨（*ṣēlāʿ*），用它建造成一个女人，那人称她为「我骨中的骨，我肉中的肉」。这一章以二人「赤身露体，并不羞耻」作结。

《创世记》第 3 章围绕着那「比田野一切的活物更狡猾」的蛇展开，蛇告诉女人，她不会死，反而会「如耶洛因能知道善恶」。她吃了，又给亚当，他也吃了；他们的眼睛就明亮了；他们遮盖自己。耶和华·耶洛因质问他们——男人归咎于女人，女人归咎于蛇——并对三者分别宣判，将这对夫妇逐出园子，安设基路伯和「四面转动发火焰的剑」，把守通往生命之树的道路。《创世记》第 4—5 章接着记载他们的子女（该隐、亚伯、塞特以及其他未具名者），以及从亚当到挪亚的谱系。

## 词源与命名

这些名字承载着分量。希伯来文 *ʾāḏām* 与 *ʾădāmâ*（「地、土壤」）紧密相连，二者都来自词根 *ʾ-d-m*，「发红」，得名于黎凡特的红色土壤。《创世记》2:7 将这一双关明白道出：*ʾāḏām* 由 *ʾădāmâ* 造成。在整部希伯来圣经中，*ʾāḏām* 在三个层面上运作——泛指的「人类」（如《创世记》1:26）、与动物相对的物种名称，以及第一个男人的专名，带定冠词的 *hā-ʾāḏām*（「那人」）逐渐让位于作为名字的 *ʾāḏām*。文集将这一文字游戏读作希伯来语在词汇本身中保存了它所阐发的主张：第一个人是用这颗行星的材料组装而成的，并以这些材料命名。

*Ḥawwāh* 在《创世记》3:20 中有其自身的释义——「众生之母」——来自词根 *ḥ-y-h* / *ḥ-w-h*，「活」。她是「活着的那一位」，伊甸世系的女始祖。学者们还提出了其他关联：与亚兰文 *ḥewyāʾ*（「蛇」）相关，此说见于《创世记大拉比注释》并在卡巴拉中得到发挥；以及与一位腓尼基生命女神相关，希伯来圣经被认为去除了其名字的神话色彩。文集以《创世记》明言的词源为首要词源，并不采纳与蛇的关联；按其解读，夏娃不应被等同于蛇。这些名字向外传播，成为希腊文的 *Adam* 与 *Heua*、拉丁文的 *Adam* 与 *Heva*（后作 *Eva*），以及古兰经传统中阿拉伯文的 *Ādam wa-Ḥawwāʾ*。

## Wheel of Heaven 的解读

文集将《创世记》第 2—3 章读作对伊甸装置中所完成之工作的压缩但忠实的记录，并具体地解读其细节。

**创造即工程。** 亚当与夏娃是被造出来的，而非生出来的。「地上的尘土」被读作实验室合成所用的地球原材料，「生命之气」则被读作已完成的有机体依耶洛因基因模板被赋予生命的那一刻。{{ footnote(id="2") }} *ʾāḏām* 这个名字记录了基质；*bə-ṣelem ʾĕlōhîm*（「照着耶洛因的形像」）记录了模板——人类与其造物主之间具有这一短语所说的、在遗传和结构上的高度相似。亚当先被造出；夏娃则用在 *tardēmâ*——即麻醉状态下的「沉睡」——期间从他身上取下的细胞或遗传物质建造而成，这就是为什么 *ṣēlāʿ*——「肋骨」，也可指「侧面」或「支撑」——使她与亚当具有密切的遗传亲缘，也为他认出她是「我骨中的骨」提供了依据。

{% claim(type="framework", id="woh-claim-0018") %}**伊甸即实验室。** 这座园子是以色列团队封闭而受控的场所，这对夫妇在那里被合成、受教育、受观察。{% end %}他们所受的教育是真实的，但有边界：议会的遏制政策扣留了创造者的科学知识，而关于分别善恶之树的禁令，正是这一政策的叙事形式——一道命令，不让造物缩小与其造物主之间的差距。

**披露。** 《创世记》第 3 章的蛇既不是一条蛇，也不是撒但。它是处于披露角色中的路西法派系——以色列团队自身科学家中的少数派，由后世传统称为路西法的那位以罗亚（Eloha）领导，他们对自己所造的人类产生了感情，认为遏制令不公。他们的行动，就是把亚当与夏娃被拒绝给予的知识交给他们。按文集的解读，蛇并没有说谎：它的两项断言——人类不会死，以及他们会「如耶洛因能知道善恶」——都成立。这一点需要审慎对待。作出披露的派系（路西法，即蛇）希望人类得到提升与启蒙；它与[撒但](../satan/)恰恰相反，后者领导的是母星上另一个派系，认为整个地球项目是一个错误，并希望将其终止。后来的传统将蛇、路西法与撒但融合为一个魔鬼，由此抹去了创造者文明内部一道真实的分野。

**驱逐即限制。** 《创世记》第 3 章的宣判被读作议会在披露已无法挽回之后作出的裁决。「用肚子行走」而受诅咒的蛇，是路西法派系的放逐——被困于地球，与母星断绝联系——置身于它选择去教导的人类之中。亚当与夏娃被逐出围场，靠自己的劳作为生。按源材料，基路伯和「四面转动发火焰的剑」被读作把守通往生命之树之路的武装哨卫。披露同样是两个人的作为与选择；文集拒绝那种认为唯独夏娃有罪的解读。{{ footnote(id="4") }}

**伊甸之后。** 亚当与夏娃的子女——该隐、亚伯、塞特及其他人——开创了洪水前的伊甸文明，并继续受被放逐的路西法派系教导。文集将该隐与亚伯读作他们寻常的儿子，不接受将该隐视为蛇之世系后代的读法。亚当所记载的 930 岁被读作路西法派系后来为伊甸诸先祖取得的[生命之树](../tree-of-life/)长寿，而非人类的自然寿命。源材料还称亚当为第一位先知——第一个直接接收创造者讯息的人类——并报告亚当与夏娃都位列在永恒者行星上复活的人之中，等待在水瓶座时代大使馆处的公开归来。{{ footnote(id="6") }}{{ cite(id="extraterrestrials-took-me-to-their-planet", text="[2]", title="佛里翁（雷尔），《外星人带我去他们的星球》（1975）——永恒者行星与复活的诸先知") }} 框架坚定持守的一点是：亚当与夏娃是*一个*世系的最初人类，而非全人类的最初人类。{{ footnote(id="3") }}

## 比较视野中的最初人类传统

最初人类的故事在各文化中反复出现，文集将其中最接近者读作平行的记忆而非巧合——这是一项比较性主张，作为诠释提出，持守得比上文正典内部的解读更为宽松。

美索不达米亚最近的邻居是《吉尔伽美什史诗》中的**恩奇都**——一个由女神阿鲁鲁用黏土塑成的人，一直处于野性状态，直到女子沙姆哈特将他引入人的意识。经由一个女人的中介从野性走向知识，这一过程与夏娃叙事十分接近，比较学术早已注意到这一点。{{ cite(id="george-epic-of-gilgamesh", text="[3]", title="乔治（译），《吉尔伽美什史诗》（1999）——恩奇都叙事") }} **阿达帕**神话在被扣留的生命这一点上更为接近：最初的智者阿达帕受其庇护神埃阿警告，不要吃他在天上将被赐予的食物——而那食物原来正是生命之粮——他因此失去了不朽，这恰是伊甸禁令的翻转。{{ cite(id="before-the-muses", text="[4]", title="福斯特，《缪斯之前》（2005）——阿达帕神话") }} 在美索不达米亚之外，这一模式进一步扩展：吠陀传统中的**摩奴**是最初之人与洪水幸存者；北欧的**阿斯克与恩布拉**由木头削成，由诸神赋予气息与心智；**女娲**用黄土造出最初的人类；玛雅的《波波尔·乌》则记载诸神先后尝试用泥土和木头造人而未成，最终用玉米才得以成功。

主流民俗学将这种分布视为独立发明、传播与人类共同经验的混合，并有理由告诫人们不要在每个版本背后都读出同一事件。框架的主张更窄：最紧密的那一组平行——一对最初的夫妇、一口赋予生命的气息、一次经由女人中介进入知识的过渡、一份被扣留的不朽——与其说是巧合，不如解释为对七个创造者团队平行工作的零碎记忆。这是将[双重署名](../doubled-signature/)原则应用于人类的创造，凡超出任何单一来源所述之处，均标为推测性。

## 学术与批评视角

框架的解读与关于《创世记》第 2—3 章的学术研究并列，而非取而代之。

**来源批判。** 主流学术将《创世记》第 1 章归于祭司典，将第 2—3 章归于耶和华典，并将两者读作编修者并置而未加调和的记述——词汇不同，创造顺序不同，还有一位在园中行走的拟人化神祇。斯金纳、冯·拉德、韦斯特曼与萨尔纳的注释，将伊甸叙事视为一个关于人类处境、在神学上严肃的故事，而非历史报告。{{ cite(id="skinner-genesis-icc", text="[5]", title="斯金纳，《创世记》（ICC，1910）") }}{{ cite(id="von-rad-genesis", text="[6]", title="冯·拉德，《创世记注释》（1961）") }}{{ cite(id="westermann-genesis-1-11", text="[7]", title="韦斯特曼，《创世记 1–11》（1974）") }}{{ cite(id="sarna-genesis-jps", text="[8]", title="萨尔纳，《创世记：JPS 托拉注释》（1989）") }} 文集并不质疑这一文本分析；它将两段记述之间的接缝读作经由不止一条渠道传承下来的记忆，并将两者的关系重新界定为范围上的差异，而非矛盾。

**基督教的接受。** 占主导地位的西方解读经由保罗——「罪是从一人入了世界」（《罗马书》5:12）——以及奥古斯丁，后者的遗传性原罪教义使《创世记》第 3 章成为西方人论的枢纽。{{ cite(id="city-of-god", text="[9]", title="奥古斯丁，《上帝之城》——原罪的综合") }} 文集在这里分歧最为尖锐：它保留了这一事件具有关键意义的看法，但拒绝遗传性罪责的那套机制，将其读作一次带有政治代价、专属于一个世系的政治性披露，而非一次普世的堕落。伊莱恩·佩格尔斯的《亚当、夏娃与蛇》记录了奥古斯丁的综合实际上是多么有争议、出现得多么晚——文集将这段历史读作与其自身的诊断相符。{{ cite(id="pagels-adam-eve-serpent", text="[10]", title="佩格尔斯，《亚当、夏娃与蛇》（1988）") }}

**女性主义学术。** 菲莉丝·特里布尔对《创世记》第 2—3 章的细读论证了希伯来原文中的相互性——*ʿēzer kə-negdô* 意为「与他相对应的帮助者」，而非从属者，*ṣēlāʿ* 是平行的一侧而非衍生的部分——而卡萝尔·迈耶斯则将夏娃读作铁器时代以色列的劳作女性，将《创世记》第 3 章的「诅咒」读作对艰苦农耕生活的描述，而非对等级秩序的规定。{{ cite(id="trible-rhetoric-sexuality", text="[11]", title="特里布尔，《上帝与性别修辞》（1978）") }}{{ cite(id="meyers-discovering-eve", text="[12]", title="迈耶斯，《发现夏娃》（1988）") }} 在夏娃并非唯一有罪者这一点上，文集与之一致；它不采纳更广泛的女性主义神学纲领，并注意到但不认可中世纪的莉莉丝传统，雷尔派材料对此从未提及。

**远古外星人解读。** 毛罗·比格利诺严格直译的希伯来文研究，将「尘土」造人与 *ṣēlāʿ* 明确读作生物学意义上的——合成与克隆——这与文集一致；两者的分歧在于比格利诺将该隐视为蛇之世系的后代，文集拒绝这一读法。{{ cite(id="the-naked-bible", text="[13]", title="比格利诺与卡塔内奥，《赤裸的圣经》（2022）") }} 让·桑迪与保罗·沃利斯都将亚当与夏娃读作以色列团队世系的最初人类，是文集在这一点上的主要先驱。{{ cite(id="those-gods-who-made-heaven-and-earth", text="[14]", title="桑迪，*Ces dieux qui firent le ciel et la terre*（1969）") }}{{ cite(id="wallis-eden-conspiracy", text="[15]", title="沃利斯，《伊甸阴谋》（2024）") }}

**人类起源。** 主流古人类学将*智人*追溯至约 20 万至 30 万年间的演化过程，其中没有可识别的最初一对。框架并不就整个物种质疑这一记录；它的主张涉及置于这段更长历史之中的一个经设计制造的世系，并区分科学所确立的内容与框架所增添的内容。
