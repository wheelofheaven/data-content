**撒但**(שָׂטָן,希伯来语:“对手”、“控告者”、“反对者”)是**母星上的一位耶洛因人物**,是耶洛因文明内部一贯反对创造能够与其造物主比肩或超越其造物主之合成存在的政治派系的领袖。他的立场自地球计划开始之前便一以贯之:按耶洛因自身形像造出的存在是危险的,没有任何规程、监督或地理距离可以被信赖来遏制此风险。当母星上的实验室事故造成首批死亡时(见 {% wiki(slug="dragons") %}龙{% end %} 条目的母星序幕),撒但的派系借此迫使母星上的生物计划停止。当科学家们迁往地球时,他的派系怀着猜疑注视,并定期通过永恒者议会进行干预,施加限制。当人类创造证明能够做出撒但所预言的那种不服从时,正是他在议会厅中最大声地呼吁将其毁灭。

本框架的分析贡献,在于将撒但与另外三位人物区分开来 — 西方宗教传统在第二圣殿时期及其后的基督教神学中,将这四位混同为单一的宇宙性邪恶人格化。四者各不相同:**撒但**(母星议会反对派领袖,从未到过地球);**路西法**(地球上被流放的创造者派系领袖,伊甸披露者);**蛇**(在伊甸披露角色中集体行动的路西法派系);以及**魔鬼**(希腊语 *diabolos*,“诽谤者”,指撒但在测试先知中的对抗功能)。现代基督教中撒但/路西法/魔鬼的形象,是大约两千年来混同这四者的产物。本文集阐述原本的分类及其丧失的机制 — 索多玛之后曾保存这些区分的教育框架的崩溃、波斯二元论对第二圣殿犹太教的影响,以及基督教将混同后的人物阐发为中世纪鬼神学{{ footnote(id="1") }}。

在源材料中,撒但是有原则的,而非被妖魔化的:*“撒但只是耶洛因之一,在某种程度上,他领导着该行星上一个政党,该党反对其他耶洛因按其形像创造人造存在 — 后者认为他们能够创造出积极的、非暴力的存在。”*{{ cite(id="the-book-which-tells-the-truth", text="[1]", title="沃里隆(雷尔),《讲述真相之书》(1974)— “撒但”一节,撒但作为反对派系领袖的奠基性阐述") }}撒但是一位政治家,而非鬼魔:他领导一个政党,该党有政纲,政纲有论点。这些论点是否正确 — 即能与其造物主比肩的合成创造必将变得危险 — 是本文集在从伊甸驱逐直到当今的人类历史中所检验的一个核心问题,而证据仍是复杂且有争议的。本框架对此存而不论。

在大洪水后时期,撒但的角色是通过对抗性面谈测试先知。在议会投票永不再毁灭人类之后 — 这一反转紧随耶洛因发现他们自身亦曾被创造({% wiki(slug="cosmic-chain") %}宇宙链{% end %})— 他持续的反对便在测试功能中被制度化。*“撒但仍坚信人类的恶,但他在永恒者议会内屈服于站在耶和华身后、持相反观点者的多数。”*{{ cite(id="extraterrestrials-took-me-to-their-planet", text="[2]", title="沃里隆(雷尔),《外星人带我去他们的行星》(1975)— 大洪水后转变段落,撒但在制度上服从议会多数") }}其逻辑是运作性的:一位能被测试所策反的先知会成为累赘;一位能够抵抗的先知则可以被信任,正是因为反对派出于动机的怀疑能暴露任何弱点。有文献记载的案例 — 对约伯的测试({% libref(book="job-woh", chapter=1) %}约伯记 1{% end %}-{% libref(book="job-woh", chapter=2) %}2{% end %}){{ footnote(id="2") }}与对耶稣的测试({% libref(book="matthew-woh", chapter=4, verse=1) %}马太福音 4:1-11{% end %};{% libref(book="luke-woh", chapter=4, verse=1) %}路加福音 4:1-13{% end %})— 展示了这一程序{{ footnote(id="3") }}。

这一解读有源材料依据。雷尔派材料在《讲述真相之书》(1974)、《外星人带我去他们的行星》(1975)及更广的文集中明确阐述了撒但的派系角色,{{ cite(id="lets-welcome-the-extraterrestrials", text="[10]", title="沃里隆(雷尔),《让我们欢迎外星人》(1979)— 更广的议会政治—制度框架") }}{{ cite(id="intelligent-design-message-from-the-designers", text="[11]", title="沃里隆(雷尔),《智能设计:来自设计者的讯息》— 三部雷尔派源材料著作的合集正典版") }}并在 *timeline.epub* 中有后续发展(巨蟹座时代,四人物分类;双子座时代,决定;双鱼座时代,耶稣的测试)。混同史 — 尤其是索多玛之后区分的丧失 — 超出了源材料,但仍锚定于其对四位人物的论述:有源材料依据,并有系统性的文集扩展。

## 词源与命名

撒但在各语言与宗教传统中的称谓之所以重要,是因为词源塑造了该人物在每一语境中的含义。

### 希伯来语 “satan” 作为普通名词

在希伯来圣经中,**satan**(שָׂטָן)是**普通名词**,而非专有名称{{ footnote(id="4") }}。它源自词根 *s-t-n*(שׂ-ט-ן),意为“反对”、“阻碍”、“敌对于”,词义为“对手”、“控告者”、“反对者”。

希伯来圣经在非神学语境中将 *satan* 用作普通名词:

- **{% libref(book="1-samuel", chapter=29, verse=4) %}撒母耳记上 29:4{% end %}**:大卫可能成为非利士人的 *satan*(对手)
- **{% libref(book="2-samuel", chapter=19, verse=22) %}撒母耳记下 19:22{% end %}**:大卫的政治对手被称为 *satanim*(对手)
- **{% libref(book="1-kings", chapter=5, verse=4) %}列王纪上 5:4(希伯来文 5:18){% end %}**:所罗门治下没有 *satan*(对手)
- **{% libref(book="1-kings", chapter=11, verse=14) %}列王纪上 11:14、23、25{% end %}**:神兴起 *satanim*(对手)敌对所罗门 — 地缘政治上的对手
- **{% libref(book="numbers", chapter=22, verse=22) %}民数记 22:22、32{% end %}**:耶和华的使者作为 *satan*(对手)拦阻巴兰

因此,“satan”是一种关系性称谓,而非专有名称:该人物因其功能 — 对抗性的反对 — 而得名,而非因某种个人身份。

### “ha-satan” 作为制度性称谓

定冠词形式 **ha-satan**(הַשָּׂטָן,“那撒但”、“那对手”)是希伯来圣经对在神圣议会中执行对抗性反对之人物的制度性称谓:

- **{% libref(book="job-woh", chapter=1, verse=6) %}约伯记 1:6-12{% end %}、{% libref(book="job-woh", chapter=2, verse=1) %}2:1-7{% end %}**:最主要的撒但段落;该人物在 *benei ha-Elohim*(耶洛因的众子)中侍立于耶和华面前,并参与制度性对话
- **撒迦利亚书 3:1-2**:该人物站在大祭司约书亚的右边“与他作对”(*l'sitno*);耶和华斥责它
- **{% libref(book="1-chronicles", chapter=21, verse=1) %}历代志上 21:1{% end %}**:该人物激动大卫数点人口(平行段落 {% libref(book="2-samuel", chapter=24, verse=1) %}撒母耳记下 24:1{% end %} 则称激动者为耶和华)

该人物是神圣议会的一员,担任对抗性反对的职位 — 是某一职位的担任者,而非邪恶的化身。

### 希腊语 “diabolos” 作为功能性称谓

希腊语 **diabolos**(διάβολος,“诽谤者”、“讲反对话的人”)是新约对 *satan* 的翻译{{ footnote(id="5") }},源自 *diaballein*(διαβάλλειν,“扔过去”、“诽谤”)。它的意思是“诽谤者” — 攻讦、提出反对、发起挑战的人 — 保留了功能性的特征。

新约对 *diabolos* 的使用:

- **{% libref(book="matthew-woh", chapter=4, verse=1) %}马太福音 4:1、5、8、11{% end %}**:旷野测试叙事
- **{% libref(book="luke-woh", chapter=4, verse=2) %}路加福音 4:2-13{% end %}**:平行的旷野测试
- **{% libref(book="john", chapter=8, verse=44) %}约翰福音 8:44{% end %}**:“你们父 *diabolos* 的私欲”
- **保罗书信及其他段落**:延续的制度性称谓

两个词都以功能而非个人名称来指称该人物。中世纪将 *diabolos* 阐发为长着红皮肤、犄角与偶蹄的“魔鬼”,是一层遮蔽了原意的文化覆盖。

### 其他语言称谓

跨文化传统中的其他称谓:

- **拉丁语**:*Satanas*(源自希伯来语);*Diabolus*(源自希腊语)
- **阿拉伯语**:*Shaytan*(شيطان),古兰经的称谓,与希伯来语 *satan* 平行{{ cite(id="the-qur-an", text="[3]", title="《古兰经》— 与希伯来 *satan* 平行的 Shaytan 与 Iblis 材料") }}
- **阿拉米语**:*Satana*(סטנא),同源的对抗性词语
- **吉兹语**:*Saytan*,见于埃塞俄比亚基督教传统

### “撒但”作为混同传统中的专有名称

当代西方基督教将“撒但”视为某个宇宙性邪恶人物的专有名称 — 这是第二圣殿时期与基督教发展将功能性称谓实化为个人身份的结果。本框架将此视为后来的发展,而非该人物的原本性格:希伯来圣经中制度性的 *satan* 并不是中世纪的宇宙性邪恶人格化。混同史在下文*该人物的内容*中论述。

### 文集内部用法

本文集以**撒但**为主要称谓,同时将该人物视为母星耶洛因派系领袖,而非中世纪的宇宙性邪恶人格化 — 沿用西方的标准名称,同时保留四人物分类与原则性反对的解读。

## 传统理解

对撒但的传统理解是层叠的:希伯来圣经、第二圣殿时期的发展、基督教的阐发,以及中世纪—现代的西方接受。

### 希伯来圣经中的形象

按主流学术,希伯来圣经的 *satan* 是一位有限的制度性人物,而非后来传统中的宇宙性邪恶人格化。

**约伯记事件**。约伯记(约写于公元前 6–4 世纪)给出了主要的阐述。该人物在 {% libref(book="job-woh", chapter=1, verse=6) %}约伯记 1:6-12{% end %} 与 {% libref(book="job-woh", chapter=2, verse=1) %}约伯记 2:1-7{% end %} 中作为神圣议会(*benei ha-Elohim*,“耶洛因的众子”)的一员出现,充当对抗性的测试者 — 与耶和华是同僚关系,处于制度性对话之中,并在耶和华的明确授权下行事。

**撒迦利亚事件**。撒迦利亚书 3:1-2(公元前 6 世纪末至 5 世纪初)保留了同样的制度角色 — 站在大祭司约书亚的右边“与他作对”(*l'sitno*)。耶和华斥责该人物,但这是议会之内的对抗性反对,而非宇宙性邪恶。

**历代志作者的转变**。{% libref(book="1-chronicles", chapter=21, verse=1) %}历代志上 21:1{% end %}(约公元前 4 世纪)有所不同:“撒但起来攻击以色列,激动大卫数点以色列人。”平行段落 {% libref(book="2-samuel", chapter=24, verse=1) %}撒母耳记下 24:1{% end %} 则将激动归于耶和华:“耶和华又向以色列人发怒,就激动大卫,使他吩咐人去数点以色列人。”这一替换标志着撒但早期向独立于耶和华直接行动之人物的发展。

**更广的语境**。与后来的传统相比,希伯来圣经的论述是有限的。该人物在创世记、出埃及记或五经早期材料中并非宇宙性的存在;伊甸的蛇在希伯来文本中并未被认同为撒但{{ cite(id="genesis", text="[4]", title="创世记 — 伊甸蛇之叙事(第 3 章);希伯来文本中并未将该形象认同为撒但") }}(这是后圣经的认同);宇宙性邪恶人格化在希伯来圣经中并不存在。

### 第二圣殿时期的发展

第二圣殿时期(约公元前 6 世纪至公元 1 世纪)重塑了 satan 的形象,并塑造了其后的基督教接受。

**波斯二元论**。阿契美尼德时期的琐罗亚斯德教以 Ahura Mazda(善)对立于 Angra Mainyu / Ahriman(恶)。流亡后犹太人与之接触,塑造了犹太鬼神学,有限的 *satan* 形象吸收了二元论框架的若干方面。

**守望者**。{% wiki(slug="book-of-enoch") %}以诺一书{% end %}(约公元前 3 世纪至公元 1 世纪)从 {% libref(book="genesis-woh", chapter=6, verse=1) %}创世记 6:1-4{% end %} 的 *benei ha-Elohim* 材料发展出天使叛乱叙事。守望者 — 降临地上并与人间女子生子的有名天使,Azazel 为其首领之一 — 在该框架中成为世上邪恶的主要源头。{{ cite(id="1-enoch-the-book-of-the-watchers", text="[5]", title="《以诺一书:守望者之书》— 作为宇宙性邪恶人物发展之主要第二圣殿来源的守望者与 Azazel 材料") }}{{ cite(id="book-of-enoch", text="[6]", title="《以诺书》— 更广的以诺文集对天使叛乱叙事的阐发") }}这些材料塑造了整个第二圣殿犹太教中的宇宙性邪恶传统。

**库姆兰**。死海古卷以“真理之灵”对立于“虚假之灵”(或“彼列”),将宇宙性邪恶传统推向后来影响基督教的二元论框架。

**两约之间的混同**。在这一时期,各不相同的人物逐渐汇合,趋向基督教传统中统一的宇宙性邪恶人物:希伯来圣经的 *satan*(制度性反对);伊甸的蛇({% libref(book="genesis-woh", chapter=3) %}创世记 3{% end %});{% libref(book="isaiah-woh", chapter=14, verse=12) %}以赛亚书 14:12{% end %} 的晨星(希伯来语 *helel ben shachar*,“闪耀者,清晨之子”);{% libref(book="ezekiel-woh", chapter=28, verse=11) %}以西结书 28:11-19{% end %} 的推罗王;守望者;以及其他对抗性人物。

### 基督教传统的发展

新约、教父与中世纪神学造就了近两千年来主导西方想象的宇宙性邪恶人格化。

**新约中的形象**。新约使撒但成为耶稣及其使命的主要宇宙对手:旷野测试({% libref(book="matthew-woh", chapter=4, verse=1) %}马太福音 4:1-11{% end %};{% libref(book="luke-woh", chapter=4, verse=1) %}路加福音 4:1-13{% end %});对观福音中的鬼附与驱鬼;保罗的提及;以及 {% libref(book="revelation-woh", chapter=12) %}启示录 12{% end %} 的龙,“大龙就是那古蛇,名叫魔鬼,又叫撒但”。

**教父时期的发展**。游斯丁、奥利金、奥古斯丁等人将 satan-lucifer-devil 形象阐发为宇宙性邪恶人格化,并以取自以赛亚书 14:12 与路加福音 10:18 的“从天坠落”叙事加以补充。

**奥古斯丁**。希波的奥古斯丁(公元 354–430 年)对该人物作了系统论述,尤其在《上帝之城》中,并奠定了中世纪的模式:撒但作为在整个历史中与神对立的宇宙性邪恶人格化。

**中世纪鬼神学**。中世纪神学建立起繁复的鬼神学,统治西方思想达一千年之久 — 红皮肤、犄角、偶蹄的魔鬼,附属的鬼魔,详尽的地狱,以及广泛的民俗接受。

**宗教改革及其后**。路德、加尔文等人保留了中世纪的宇宙性邪恶框架,同时修订了具体论点,撒但神学在各宗派中继续发展。

### 伊斯兰传统

伊斯兰教保存了关于 **shaytan**(شيطان)与 **Iblis**(إبليس)的平行材料。

**古兰经中的 Iblis**。Iblis 拒绝遵照神圣命令向亚当俯首({% libref(book="quran-woh", chapter=2, verse=34) %}古兰经 2:34{% end %}、{% libref(book="quran-woh", chapter=7, verse=11) %}7:11-13{% end %}、{% libref(book="quran-woh", chapter=15, verse=28) %}15:28-44{% end %}、{% libref(book="quran-woh", chapter=17, verse=61) %}17:61-65{% end %}、{% libref(book="quran-woh", chapter=18, verse=50) %}18:50{% end %}、{% libref(book="quran-woh", chapter=20, verse=116) %}20:116{% end %}、{% libref(book="quran-woh", chapter=38, verse=71) %}38:71-85{% end %})。他的拒绝出于骄傲与悖逆,他获准宽限至审判日以测试人类 — 这一测试功能与希伯来的 *satan* 相平行。

**作为范畴的 Shaytan**。古兰经的 *shaytan*(复数 *shayatin*)是一个更广的对抗者类别 — Iblis 及附属的存在 — 充当试探者。

**与希伯来/基督教传统的关系**。Iblis/shaytan 与希伯来/基督教的 satan 共享结构与功能上的内容,同时发展出自己的神学:失宠、测试角色以及对抗立场都与较早的框架相平行。

### 主流学术的介入

主流希伯来圣经学术致力于将 *satan* 与后来的宇宙性邪恶人格化相区分。**Peggy L. Day**(1988)、**Marvin H. Pope**(1973)、**Norman C. Habel**(1985)、**Jeffrey Burton Russell** 的四卷本历史、**Elaine Pagels**(1995)以及 **Henry Ansgar Kelly**(2006)是主要的声音 — 详见下文*现代再解释*。Kelly 的《撒但:一部传记》在结构上与本文集对混同过程的叙述相一致,同时以主流历史—语文学为依据。

**Mauro Biglino 的严格翻译进路**。比利诺关于希伯来圣经的工作(《赤裸的圣经:关于历史上最著名之书的真相》,与 Giorgio Cattaneo 合著,Uno,2022){{ cite(id="the-naked-bible", text="[7]", title="比利诺与卡塔涅奥,《赤裸的圣经》(2022)— 严格字面希伯来翻译,包括 *satan* 材料") }}在该人物的原本性格上与本文集一致,主张严格字面的希伯来文揭示了主流翻译所遮蔽的内容。{{ cite(id="the-bible-is-not-a-sacred-book", text="[8]", title="比利诺,《那本将永远改变我们关于圣经观念的书》/《圣经不是一本神圣的书》— 严格字面希伯来圣经系列,奠基性的语文学论证") }}

本框架在该人物原本有限且制度性的性格上与主流学术一致;它自身的贡献是四人物分类,以主流学术未曾达到的运作具体性,将撒但与路西法、蛇及魔鬼相区分。

## 在原典中

关于撒但的原典材料,是雷尔派著作中一组由耶和华传达的段落,并在 *timeline.epub* 中有后续发展。

### 《讲述真相之书》中的约伯记段落

确立撒但制度角色的第一个段落,见于《讲述真相之书》(1974)的“撒但”一节{{ cite(id="the-book-which-tells-the-truth", text="[1]", title="沃里隆(雷尔),《讲述真相之书》(1974)— “撒但”一节,约伯记段落注释") }}:

> *“在约伯记第一章中,你可以找到对撒但的解释:”*
> 
> > *“有一天,耶洛因的众子来侍立在耶和华面前,撒但也来在其中。 — 约伯记 1:6”*
> 
> *“希伯来语中‘耶洛因’字面意为‘从天而来者’。‘耶洛因的众子’,换言之,即注视着人类的造物主们,定期向其起源行星汇报,大多数情况下表明人类尊敬并爱戴耶洛因。但其中一位名叫撒但的耶洛因,属于一个群体,该群体一直反对在像地球这般接近的行星上创造其他智慧存在,视其为可能的威胁。这就是为什么,当看到约伯的虔诚 — 那是人类爱戴其造物主的最佳例子之一 — 他说:”*
> 
> > *“约伯敬畏耶洛因岂是无故呢?……你且伸手毁他一切所有的;他必当面弃掉你。耶和华对撒但说:‘凡他所有的都在你手中;只是不可伸手加害于他。’ — 约伯记 1:9-12”*
> 
> *“政府听到撒但断言若约伯不富有便不会爱其造物主,便授予撒但全权摧毁约伯。然后将可看出他是否仍尊敬其造物主,这就是为什么禁止杀害他。”*
> 
> *“看到约伯即使在被毁灭时仍致力于尊敬其造物主,政府战胜了反对派撒但。但撒但反驳说,虽然约伯失去了许多东西,他仍然身体健康。所以政府给了撒但全权,只要他不杀死约伯:”*
> 
> > *“看哪,他在你手中,只要存留他的性命。 — 约伯记 2:6”*
> 
> *“最终,鉴于约伯的谦卑,造物主治愈了他,归还了他的财富、儿女与健康。”*

这一段落确立了几个要素:

**1. 制度地位**。撒但是“一位名叫撒但的耶洛因”,属于“一个群体,该群体一直反对在像地球这般接近的行星上创造其他智慧存在,视其为可能的威胁” — 即议会内部的一个派系。

**2. 同僚关系**。这段对话显示了“耶和华与撒但之间的良好关系,甚至兄弟般的关系”。耶和华是上级权威,撒但是反对派领袖;这番交流是正常的政治审议,而非善恶对峙。

**3. 测试规程**。撒但在耶和华的明确授权与限制下(“只是不可伸手加害于他”;随后“存留他的性命”),以毁灭与疾病测试约伯的忠诚 — 这是程序性的,而非恶意的。

**4. 解决**。约伯的忠诚经受住考验之后,“造物主治愈了他,归还了他的财富、儿女与健康” — 这一恢复证实了程序性的性质。

### “人类不能理解”段落

下一个段落见于《外星人带我去他们的行星》(1975),将撒但置于派系动态之中{{ cite(id="extraterrestrials-took-me-to-their-planet", text="[2]", title="沃里隆(雷尔),《外星人带我去他们的行星》(1975)— “人类不能理解”一节,大洪水前毁灭决定的背景") }}:

> *“随着时间的流逝,撒但通过观察人类如何用路西法那群被流放的耶洛因之子给予他们的武器互相残杀,累积着人类侵略性的证据。后者卷入了与人间女子的‘温情’关系中,这些女子设法通过其魅力换取武器,假托是给她们的父亲或兄弟以便狩猎食物。事实上,人类却选择以此军火库进行可憎的互相争斗。”*
> 
> *“看到撒但带到永恒者议会面前的此种屠杀证据,耶和华决定按撒但所要求的去做,即彻底毁灭在地球上所造的生命,同时藉此使路西法的群体得以返回他们自己的行星并获得宽恕,从而结束他们的流放。”*

这一段落确立了撒但在大洪水前毁灭决定中的角色:

**1. 累积证据**。撒但通过观察地球搜集人类侵略性的证据,大洪水前的暴力为反对派的论点提供了材料。

**2. 向议会陈述**。他将证据带到永恒者议会面前,毁灭正是通过这一程序被决定的。

**3. 耶和华的转变**。耶和华曾支持人类创造,并在威胁尚属推测时抵制该派系的毁灭呼吁,如今基于累积的证据转向毁灭。

### 大洪水后转变段落

撒但在大洪水后的转变见于同一部书{{ cite(id="extraterrestrials-took-me-to-their-planet", text="[2]", title="沃里隆(雷尔),《外星人带我去他们的行星》(1975)— 宇宙链发现与大洪水后议会投票") }}:

> *“正是在那时,耶洛因才发现他们也是以他们曾创造人类的同样方式 — 科学地、在实验室中 — 由来自另一世界的其他人所创造的。他们于是决定永不再毁灭人类,并帮助路西法的群体重新植入‘方舟’中保存的生命形态。撒但仍坚信人类的恶,但他在永恒者议会内屈服于站在耶和华身后、持相反观点者的多数。耶和华通过从另一行星来到他们行星上的那艘无人飞船所含讯息明白了:若人类是暴力的,当他们发现能使其进入星际文明层次的能源时,便会‘自我毁灭’。”*

这一段落确立了撒但在大洪水后的立场:

**1. 宇宙链**。耶洛因得知他们自身也曾被创造 — 见 {% wiki(slug="cosmic-chain") %}宇宙链{% end %} 条目。

**2. 议会投票**。议会投票永不再毁灭人类,他们自身的受造身份促成了这一反转。

**3. 反对而服从**。*“撒但仍坚信人类的恶,但他屈服于站在耶和华身后、持相反观点者的多数。”*他的原则性反对仍在继续,但他接受了多数的结果。

### 先知测试段落

撒但的先知测试角色见于与耶稣相关的内容{{ cite(id="extraterrestrials-took-me-to-their-planet", text="[2]", title="沃里隆(雷尔),《外星人带我去他们的行星》(1975)— 先知测试功能与 diabolos 词源") }}:

> *“如此重要的讯息只能交给值得信赖的人,因此首先,耶洛因必须确保他们所选定的人忠于其造物主,以免他们背叛所启示给他们的东西。所以撒但被授予了测试先知的责任。”*
> 
> *“他们将如何测试这些人的忠诚?一旦某人被耶洛因的使者接触,告知他其使命之后,撒但或他的人之一会接触这位准先知,通过诽谤摧毁他心中的耶洛因,设法使该人弃绝他的父辈,或接受以背叛其使命换取物质利益的承诺,例如。希腊语中‘诽谤者’怎么说?就是 diablos。这就是我们著名的魔鬼,但他仍没有犄角、没有偶蹄……”*

这一段落确立了:

**1. 测试角色**。撒但在大洪水后的功能,是以对抗性面谈系统地测试先知。

**2. 方法**。诽谤耶洛因、施压使其弃绝造物主,以及以物质回报换取背叛。

**3. *diabolos* 词源**。希腊语中的“魔鬼”*diabolos* 意为“诽谤者”:以诽谤测试先知的人物,而非中世纪神学的宇宙性邪恶人格化。源文本的表述 — *“这就是我们著名的魔鬼,但他仍没有犄角、没有偶蹄”* — 以温和的讽刺点明了这一点。

### 耶稣测试段落

耶稣的测试引用 {% libref(book="matthew-woh", chapter=4, verse=1) %}马太福音 4:1-11{% end %} 的旷野叙事并加以注释:

> *“例如,耶稣被带到旷野中四十天作为他的入门时期,在某些时候被与‘魔鬼’对峙,以看他是否会否认其父:”*
> 
> > *“当时,耶稣被圣灵引到旷野,受魔鬼的试探。 — 马太福音 4:1”*
> 
> *“或者,更清楚地说:‘耶稣被带到旷野,受诽谤者的测试。’”*

这一段落将“受诽谤者测试”的解读应用于旷野叙事:

**1. 三项测试**。面包测试(将其能力用于安适)、圣殿测试(要求联盟干预以证明其身份)与万国测试(以其承诺换取政治权力) — 涵盖自我利益、骄傲与世俗野心。

**2. 结果**。耶稣通过了全部三项测试,证明其可靠。

**3. 完成**。*“于是魔鬼离了耶稣,有天使来伺候他。”*({% libref(book="matthew-woh", chapter=4, verse=11) %}马太福音 4:11{% end %}) — 联盟官员恢复接触,耶稣被释放去履行其使命。

## 该人物的内容

### 撒但的派系—政治立场

撒但领导议会的反对党 — 一贯反对创造能够与其造物主比肩或超越其造物主之合成存在的派系。其论点是:这类创造是危险的,没有任何规程、监督或地理距离能遏制此风险。撒但将此作为原则性立场而非恶意提出,并援引经验上的支持 — 母星实验室事故、大洪水前人类的侵略性以及后来的暴力。这一立场自地球计划开始之前便一以贯之;它是根本性的,而非投机性的。约伯记的对话显示了一种同僚关系 — “耶和华与撒但之间的良好关系,甚至兄弟般的关系” — 是制度政治,而非善恶之争。

### 四人物分类

本框架的核心贡献,是将撒但与西方传统所混同的另外三位人物相区分:

- **撒但**:母星议会反对派领袖,从未到过地球 — 反对按耶洛因自身形像创造存在的派系;他在大洪水后对先知的测试延续了这一反对。
- **路西法**:地球上被流放的创造者派系领袖与伊甸披露者,主张向人类完全披露其起源及议会的禁令;后来成为人类的教导者,以及大洪水后人类创造的联盟伙伴。见 {% wiki(slug="lucifer") %}路西法{% end %} 条目。
- **蛇**:在披露角色中集体行动的路西法派系 — 创世记 3 章叙事中的希伯来 *ha-nachash*,并有更广的跨文化蛇传统。见 {% wiki(slug="serpent") %}蛇{% end %} 条目。
- **魔鬼 / *diabolos***:并非另一个人物,而是希腊语对撒但先知测试角色的称谓 — 以对抗性面谈验证先知的诽谤者—测试者。

四者在所在地(母星与地球)、政治立场与叙事角色上各不相同。将四者混同为一个宇宙性邪恶人格化,遮蔽了原本的政治结构。

### 混同史

**索多玛作为催化剂**。本文集将所多玛与蛾摩拉的毁灭(见 {% wiki(slug="sodom-and-gomorrah") %}所多玛与蛾摩拉{% end %} 条目)解读为终结了保存这些区分之框架的断裂:受过教育的阶层被毁灭后,索多玛之后的人群再也无法维持这些区分。

**逐步合并**。从索多玛到后来的先知文学,四位人物逐渐合并。蛇被与叛乱而非路西法派系的披露角色联系起来,叛乱之蛇被与撒但在母星的反对联系起来,路西法则与二者都联系在一起。

**波斯二元论**。琐罗亚斯德教二元论塑造了第二圣殿犹太教,有限的 *satan* 吸收了 Angra Mainyu / Ahriman 的框架及其善恶对立轴。

**基督教的综合**。到第二圣殿晚期,合并已告完成:路西法与撒但融合为单一的宇宙性邪恶人物,蛇被认同于它,原本的区分失落了。基督教将其阐发为魔鬼、黑暗之君;中世纪神学将其精炼为统治西方思想一千年的鬼神学。

**延续**。这一混同后的人物至今仍是西方对“撒但”的主导理解。区分这四者,须逆着两千年累积的阐发而行。

### 大洪水后的制度角色

撒但的反对在大洪水后的投票之后依然存在 — *“撒但仍坚信人类的恶,但他在永恒者议会内屈服于站在耶和华身后、持相反观点者的多数”* — 并被导向对先知的测试。其逻辑是:一位能被策反的先知会成为累赘;一位能够抵抗的先知则可以被信任,因为反对派真诚的怀疑能暴露任何弱点。方法包括诽谤耶洛因、施压使其弃绝造物主、以物质回报换取背叛,以及针对个人量身定制的情境测试 — 对禁食之人的面包测试,对需要证实之人的圣殿测试,对可能怀有政治野心之人的万国测试。真诚的反对恰恰是测试有价值的原因;由立场一致者进行的走过场测试则毫无价值。

### 更广的意义

**原则性反对**。将撒但解读为原则性的反对者而非宇宙性邪恶人格化,以寻常的制度审议取代了善恶对立轴,并将西方的宇宙性邪恶人物视为历史—文化的产物,而非该人物的原本性格。

**民主制度**。撒但服从议会多数,这将耶洛因文明呈现为民主—制度性的而非神权性的 — 反对在接受投票结果的同时继续存在。

**一个开放的问题**。撒但的论点是否正确 — 能与其造物主比肩的合成创造是否必将变得危险 — 已在大洪水后时期、先知传统与当今中受到检验,本框架对此存而不论。

## 与邻近概念的区分

### 撒但与路西法

{% claim(type="framework", id="woh-claim-0013") %}路西法是地球上被流放的创造者派系领袖;撒但是母星议会反对派领袖 — 所在地、立场与角色均不相同。{% end %}他们是政治上的对手,而非善恶的人格化:路西法主张向人类完全披露;撒但则完全反对人类创造。基督教对二者的混同,是两千年发展的产物,遮蔽了他们各自的身份。

### 撒但与蛇

蛇是希伯来语的 *ha-nachash*,即在地球上承担创世记 3 章披露角色的路西法派系;撒但则是从未到过地球的母星反对派领袖。二者后来的混同是一种神学发展。

### 撒但与魔鬼

魔鬼 — 希腊语 *diabolos*,“诽谤者” — 并非另一个人物,而是撒但在测试角色中的功能性称谓。两者都以功能命名该人物:希伯来语的撒但、希腊语的 *diabolos*、拉丁语的 *Diabolus*、英语的“the Devil”。红皮肤、犄角与偶蹄是中世纪的覆盖。

### 撒但与宇宙性邪恶人格化

中世纪的宇宙性邪恶人格化,是两千年来将四位人物(撒但、路西法、蛇、魔鬼)与其他对抗性人物 — 守望者、伊甸的蛇、以赛亚书 14 章的晨星、以西结书 28 章的推罗王 — 相混同的结果。这是一个历史结果,而非这些人物的原本性格:希伯来的 *satan* 与四人物分类正是被混同所遮蔽之物。

## 现代再解释

### 主流希伯来圣经学术

主流学术将希伯来圣经的 *satan* 与后来的宇宙性邪恶人格化相区分。**Peggy L. Day** 的《天上的对手:希伯来圣经中的撒但》(Scholars Press,1988)主张该人物是有限且制度性的,其三个主要段落(约伯记 1-2、撒迦利亚书 3、历代志上 21)以制度性而非宇宙性邪恶的语汇呈现它,并在流亡后时期逐步发展。**Marvin H. Pope** 的《约伯记》(Anchor Bible,Doubleday,1965;第 3 版,1973)记录了近东神圣议会的平行材料以及约伯记对话的程序性特征。**Norman C. Habel** 的《约伯记》(Westminster Press,1985)关注该人物的制度角色。**Carol A. Newsom** 的《约伯记:道德想象的较量》(Oxford University Press,2003)与 **David J. A. Clines** 的三卷本《约伯记》(Word Biblical Commentary)进一步发展了这一解读。

### 第二圣殿时期 satan 发展研究

**Mary Boyce** 的《琐罗亚斯德教徒:他们的宗教信仰与实践》(Routledge,1979)记录了琐罗亚斯德教对第二圣殿犹太教的影响 — Ahura Mazda 与 Angra Mainyu / Ahriman 的二元论被吸收进流亡后的犹太思想。**George W. E. Nickelsburg** 的《以诺一书 1:以诺一书第 1-36、81-108 章注释》(Hermeneia,Fortress Press,2001)与 **Annette Yoshiko Reed** 的《堕落天使与犹太教和基督教的历史:以诺文献的接受》(Cambridge University Press,2005)追溯了守望者传统在塑造鬼神学发展中的作用。库姆兰研究 — **Geza Vermes**、**Lawrence H. Schiffman** 的《重新认领死海古卷》、**James VanderKam** 的《今日死海古卷》— 记录了该社团的二元论框架及其后来的影响。

### 基督教传统鬼神学的发展

**Jeffrey Burton Russell** 的四卷本历史是奠基性的论述:

- *The Devil: Perceptions of Evil from Antiquity to Primitive Christianity*(《魔鬼:从古代到原始基督教对邪恶的认识》,Cornell University Press,1977)
- *Satan: The Early Christian Tradition*(《撒但:早期基督教传统》,Cornell University Press,1981)
- *Lucifer: The Devil in the Middle Ages*(《路西法:中世纪的魔鬼》,Cornell University Press,1984)
- *Mephistopheles: The Devil in the Modern World*(《靡菲斯特:现代世界中的魔鬼》,Cornell University Press,1986)

它追溯了大约三千年间,有限的希伯来圣经人物如何演变为中世纪—现代的宇宙性邪恶人格化。**Elaine Pagels** 的《撒但的起源》(Random House,1995)表明,这一人格化服务于早期基督教社团对抗其竞争者 — 犹太人、异教徒与异端基督徒 — 的自我界定,这一发展受社会—政治动态所塑造。**Henry Ansgar Kelly** 的《撒但:一部传记》(Cambridge University Press,2006)主张中世纪的人物不同于希伯来圣经中的人物,以主流语文学为依据,在结构上与本文集对混同过程的叙述相一致。**Bernard McGinn** 的《敌基督:人类对邪恶两千年的迷恋》(Harper,1994)与 **W. Sibley Towner** 进一步扩展了这一图景。

### 伊斯兰 shaytan/Iblis 传统

**Whitney S. Bodman** 的《Iblīs 的诗学:古兰经中的叙事神学》(Harvard Theological Studies,2011)论述古兰经中 Iblis 的叙事—神学角色,**Peter J. Awn** 的《撒但的悲剧与救赎:苏菲心理学中的 Iblīs》(Brill,1983)则论述苏菲派对该人物的阐发。

### 本框架与更广景观的关系

本文集在图景的大部分上与主流学术一致:该人物原本的制度性性格(希伯来圣经学术)、波斯与守望者的贡献(第二圣殿学术),以及后圣经时期的阐发(基督教传统学术)。它在底层事件上有所分歧:主流学术将该人物视为没有历史指涉的宗教—文化发展,本文集则将 *satan* 及相关人物解读为对涉及一位真实耶洛因人物之真实事件的记忆 — 这一解读与比利诺的翻译工作和 Kelly 的修正主义等另类历史进路共享。

## 比较观察

撒但形象在世界各地都有跨文化的平行。

### 琐罗亚斯德教 Angra Mainyu / Ahriman

琐罗亚斯德教的 *Angra Mainyu*(阿维斯陀语:𐬀𐬢𐬭𐬀⸱𐬨𐬀𐬌𐬥𐬌𐬌𐬎,“毁灭之灵”)是琐罗亚斯德教的宇宙性邪恶人物,与 **Ahura Mazda**(善、光明、真理、秩序)相对立,与混乱和欺骗相关联。{{ cite(id="avesta", text="[9]", title="《阿维斯塔》— 琐罗亚斯德教经典;Angra Mainyu / Ahura Mazda 的宇宙二元论框架") }}后来的巴列维语名称为 **Ahriman**。两个原则同样永恒,宇宙秩序由二者的对立构成 — 正是这一二元论通过阿契美尼德时期的接触注入了第二圣殿时期 *satan* 的发展。本文集将这一琐罗亚斯德教人物解读为对同一宇宙—政治对立的可能文化记忆,是更广的 {% wiki(slug="theomachy") %}神战{% end %} 模式的一种表述。

### 吠陀—印度教对抗形象

*asuras*(असुर)与其译作“恶魔”,不如译作“强大者”,它们与既有秩序的 *devas* 相对立;其冲突见 {% wiki(slug="theomachy") %}神战{% end %} 条目。有名的人物包括 **Vritra**(被因陀罗所杀的龙蛇)、**Bali**(被毗湿奴的侏儒化身所败)、**Hiranyakashipu**(被人狮所败)以及 **Mahishasura**(被杜尔迦所败)。天神与阿修罗的冲突是循环的,在各宇宙时代中反复出现 — 本文集将其解读为对一场多阶段历史冲突的记忆。

### 佛教 Mara

**Mara**(梵语:माय,“死亡”、“毁灭者”)试图阻止佛陀在菩提树下证悟 — 魔女作为感官的诱惑者,魔军作为恐惧,以及对其证悟资格的挑战。这一对峙与撒但—耶稣的旷野测试相平行:一位宇宙对手,在同样的弱点范畴(欲望、恐惧、骄傲)上的诱惑,成功的抵抗,以及对手的离去。本文集将 Mara 解读为佛教框架中的先知测试模式。

### 埃及的 Set

**Set**(*Sutekh*),混乱、沙漠与扰乱之神,谋杀了奥西里斯,与荷鲁斯争斗,最终只得到沙漠与异邦之地,而荷鲁斯取得王权。本文集将 Set 解读为对蛇/路西法派系在冲突之后被边缘化的记忆 — 保有一些权力,但被排斥于中心之外;见 {% wiki(slug="theomachy") %}神战{% end %} 条目。

### 美索不达米亚对抗形象

**Pazuzu** 是一位疾病恶魔,具有辟邪功能(抵御其他邪恶)。巫术传统中还有 **Lamashtu**(流产与婴儿死亡)与 **Lilitu**(希伯来莉莉丝的前身) — 这是希伯来圣经对抗性人物的背景。*《埃努玛·埃利什》*中的蛇形母神 **Tiamat** 与蛇/路西法传统而非特指撒但相平行;见 {% wiki(slug="theomachy") %}神战{% end %} 条目。

### 中国宇宙—官僚反对形象

中国神话让反叛的神祇人物与天庭官僚体系相对立:**孙悟空**(美猴王,挑战天庭)与**共工**(损毁天柱)。他们挑战的是既有的官僚秩序,而非体现原初的混沌 — 本文集将此解读为中国框架中的政治—制度反对模式。

### 北欧 Loki

**Loki** 既在阿萨神族之内又与之作对:参与他们的冒险,欺骗并惹是生非,杀死巴德尔,最终被缚以待诸神黄昏。他是带有对抗倾向的制度内部人士,而非外部的宇宙对手 — 既非纯恶亦非纯善,这与本文集将撒但解读为原则性反对而非宇宙性邪恶人格化相平行。

### 原住民对抗—宇宙形象

美洲原住民的恶作剧者形象 — 郊狼、太平洋西北岸的渡鸦 — 占据着类似 Loki 的道德—政治位置。非洲传统有其自身的对抗性人物(约鲁巴的 Eshu、多位班图人物),波利尼西亚与澳大利亚原住民传统亦然。

### “原则性反对”的跨文化模式

本文集将原则性反对人物的广泛分布视为一种共同模式的证据。主流学术以独立发展、共享的认知—原型基底(荣格的“阴影”)以及有限的传播来解释它;本文集则将其解读为对一种真实政治结构的共同记忆 — 撒但的反对在其中运作的耶洛因政治。每一传统都以自己的框架保存了这一模式:琐罗亚斯德教的二元论、循环往复的印度教阿修罗、佛教 Mara 的先知测试、被边缘化的埃及 Set、道德复杂的北欧 Loki,以及各原住民传统。

本文集并不拒绝主流的解释 — 传播、共享基底与独立发展可能都有所贡献。它在这些共性之下增添了历史—政治基础:这些人物作为文化记忆所记录的耶洛因政治结构{{ footnote(id="6") }}。其独特之处在于**原则性反对的框架** — 不将这些人物解读为宇宙性邪恶人格化,而是解读为一个运作中的宇宙—政治秩序之内的原则性政治反对,以制度动态取代西方想象中的善恶对立轴。
