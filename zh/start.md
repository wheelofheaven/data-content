## 1. 前提，以及提出它的人

*约一分钟。*

Wheel of Heaven 提出，《创世记》称为{% wiki(slug="elohim") %}耶洛因{% end %}的存在，是一支来自另一个世界、小型而技术发达的人类文明。
他们设计了地球上的生命，包括人类；许多传统的宗教文本以压缩的形式保存了对他们这项工作的记忆。

这一提议来自雷尔派讯息，由克劳德·沃利隆（雷尔）自 1974 年起发表。
本站透过这一透镜阅读古代材料，并公开说明这一点。
本站由一位{% wiki(slug="raelism") %}雷尔派{% end %}作者以笔名写作，并借助人工智能辅助，它不是雷尔运动的官方出版物。
[关于](/zh/about/)页与[作者](/author/zara-zinsfuss/)页提供详细信息。

## 2. 如何区分源头与诠释

*约两分钟。*

每一页都带有一枚徽章，标示其主要论断的类型：

- **直接**：在一手资料中明确陈述，且并无争议。*希伯来词* elohim *在形式上是复数。*
- **框架**：在雷尔派正典中明确陈述，但不为主流学界所接受。*耶洛因是一个由实体存在构成的文明。*
- **推断**：对某一源头的合理解读，该源头并未逐字如此陈述。*巴别塔是作为献给造物者的和解之礼而建造的。*
- **思辨**：超出任何单一源头的综合。*希腊、美索不达米亚与迦南的神战故事记住的是同一场冲突。*

一篇较长的页面包含不止一种论断。
徽章标示的是主要的那一种；其余的由行文随处标出，使用诸如「按这一阅读」或「主流学术认为」之类的说法。
[方法](/zh/method/)页对这些标签有完整的说明。

## 3. 细读一节经文

*约三分钟。*

{% library(book="genesis-woh", chapter=1, verse=26) %}
厄罗音说：「让我们按我们的形象，依我们的样式造人；让他们管理海中的鱼、诸天的飞鸟、牲畜、整片大地，以及在大地上爬行的一切爬行之物。」
{% end %}

**希伯来文怎么说。**
说话者是 *Elohim*，一个形式上为复数的名词。
动词 *na'aseh*（「让我们造」）是第一人称复数，所有格 *be-tzalmenu*（「按我们的形象」）与 *ki-dmutenu*（「依我们的样式」）也是如此。
这些形式本身并无争议。

**通常如何解读。**
读者解决这一复数的方式主要有四种：读作君王式的「我们」（尊严复数），读作三位一体的预示，读作神对一个由侍立的天上存在者组成的议会说话，或读作字面意义上的多位造物者。
今天大多数圣经学者倾向于议会说，并以{% libref(book="psalms", chapter=82, verse=1) %}诗篇 82 篇{% end %}与{% libref(book="1-kings", chapter=22, verse=19) %}列王纪上 22 章{% end %}中的天上集会作比较。

**Wheel of Heaven 的提议。**
第四种解读：耶洛因之所以作为一个群体商议，是因为他们本来就是一个群体，一支即将按自己的身体样貌造人的设计团队。
名词 *tselem*（「形象」）通常指具体的形体，即一尊雕像或刻出的肖像，因此它更契合身体上的相似，而非精神上的相似。

**理由。**
复数的言语在同一类时刻反复出现：在造人之时，在伊甸之后（「那人已经与我们中的一位相似」，{% libref(book="genesis-woh", chapter=3, verse=22) %}创世记 3:22{% end %}），以及在{% wiki(slug="babel") %}巴别{% end %}（{% libref(book="genesis-woh", chapter=11, verse=7) %}创世记 11:7{% end %}）。
每一次，这些以复数说话的存在者都就人类作出某项决定，随后付诸行动。
雷尔派讯息对创造给出了同样的叙述，而这一叙述并不依赖于语法。

## 4. 最有力的反驳

*约两分钟。*

当 *Elohim* 指以色列的神时，它通常带单数动词。
圣经的第一节经文读作 *bara Elohim*，即「Elohim 创造」，其中动词为单数。
对大多数读者而言，这就足以定论：该名词形式上是复数、意义上是单数，而第 26 节中的「我们」是对一个由从属存在者组成的议会说的。

Wheel of Heaven 接受这一语法，也不把自己的论证建立在复数形式之上。
它建立在文本以复数说话的那些段落上，也建立在雷尔派的叙述上，后者将单数动词读作一位代表群体行事者的言语。
议会说与多位造物者说都认真对待这一复数；它们的分歧在于，当时在场的是谁。
单凭希伯来文无法在二者之间作出裁决，而[耶洛因](/zh/wiki/elohim/#what-would-revise-this-reading)条目列出了会削弱本项目这一阅读的发现。

## 5. 接下来去哪里

*约两分钟。*

- **跟随故事。** [时间线](/zh/timeline/)以十二章讲述这个故事，每一章对应一个岁差时代。
- **查阅术语。** [耶洛因](/zh/wiki/elohim/)条目是本站被链接最多的页面；[百科](/zh/wiki/)收有约 150 个条目。
- **阅读源头。** [图书馆](/zh/library/)收有雷尔派书籍，以及《创世记》等文本的新译本，原文与译文并列，并为每一个有争议的词附上注释。
- **看完整篇幅的方法。** [桑迪与雷尔派讯息](/zh/articles/sendy-and-the-raelian-messages/)将第一本雷尔派书籍与让·桑迪更早的著作逐段对照，并权衡雷尔借用桑迪之说的论据。
- **使用数据。** [神圣议会索引](/datasets/divine-council-index/)列出十二种传统中的神圣议会及其出处位置，提供 CSV 与 JSON 格式，任何人都可以核查或重新使用。
