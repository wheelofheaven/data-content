1932 年夏天，大萧条跌至谷底之时，奥地利蒂罗尔的沃格尔镇开始印制一种被设计成会腐烂的货币。镇上三分之一的人失业。镇长米夏埃尔·翁特古根贝格尔，一位前铁路机械师，发行了一种劳动券：每个月损失面值的百分之一，除非持有人买一枚印花贴上——这是一种内建了囤积成本的货币，于是对它唯一明智的处置就是花掉。这些劳动券在沃格尔的流转速度，比先令在奥地利全国的流转快上许多倍。镇上重铺了街道，重建了供水系统，让失业者去修一座桥，还提前向自己缴清了税款，而周边地区的失业率却仍在攀升。访客从欧洲各地和美洲赶来参观这桩奇迹{{ footnote(id="1") }}；约两百位奥地利镇长准备仿效。随后奥地利国家银行主张其对货币发行的垄断权，法院表示同意，1933 年 9 月，这项实验被依法关闭——正如它的拥护者不厌其烦地重复的那样，一个行之有效的答案，在它所回应的那场危机最严重的时刻被关停了。

沃格尔短暂化身的那个理念，属于一位两年前已经去世的人，他死在柏林城外一处名叫伊甸的园林殖民地：西尔维奥·盖泽尔，一位自学成才的德国商人，靠向布宜诺斯艾利斯进口外科器械发家，又在目睹阿根廷的货币如何在他周围毁掉又重造一笔笔财富时，失去了他的正统信念{{ footnote(id="2") }}。沃格尔被关停三年之后，当世最著名的经济学家在本世纪最有影响的经济学著作中专辟一节论他——「那位奇特而受到不应有之忽视的先知西尔维奥·盖泽尔，」凯恩斯写道，「他的著作闪烁着深刻洞见的火花」——随后写下一句他的同行至今仍未消化的话：「我相信，未来从盖泽尔的精神中学到的，将多于从马克思的精神中学到的。」

盖泽尔是一份卷宗中的一个条目，而本文打算把这份卷宗通读一遍。卷宗的成员彼此几乎素不相识。其中有一位把乌托邦设在肯尼亚高原的维也纳财经记者；一位美国印刷工，他主张征收土地税的论证成了十九世纪最畅销的经济学著作；一个偏好十七世纪自然法的英语世界哲学学派；一位在佛罗里达灌木丛中自学成才的工业设计师；把地球上最有价值的软件白白送出去的程序员们；以及一位带着一份宣言的风险投资家。他们共有一项信念：越过某个技术门槛之后，匮乏便是制度设计的人为产物；社会经济秩序是一件造出来的东西，可以重造；而重造时正确的目标函数是人的繁荣——这一物种之潜能的绽放——而不是积累。这份卷宗还有一个天然的比较点，因为本计划所阅读的文献库中，包含着这个家族里一位紧凑而又出奇完整的成员：它于 1973 年 12 月分六个早晨交付、1975 年又加以扩展，即{% wiki(slug="new-commandments") %}新诫命{% end %}称为**人道主义**的那套学说，以及它更长远的地平线{% wiki(slug="paradism") %}乐园主义{% end %}。在本计划中，正典自身的主张通篇标注为 `framework`——明载于来源之中，未获主流学术认可。下文的比较性阅读则如实标注为：`inferred`。

## 火山口里的讯息

在框架之内，场景是克莱蒙费朗附近一座死火山的火山口：一位名叫克洛德·沃里隆的二十七岁赛车记者——自第二个早晨起称{% wiki(slug="rael") %}雷尔{% end %}——报告了他与一位来访者长达六天的谈话，他后来称这位来访者为{% wiki(slug="yahweh") %}耶和华{% end %}。他次年出版的那本书的第六章，无论它另外还是什么，都是一部政治经济学。它以{% wiki(slug="geniocracy") %}天才政治{% end %}——以智力为筛选标准的政府——开篇，随即转入财产问题：

{% library(book="the-book-which-tells-the-truth", chapter=6, verse=7) %}
您们的世界被利润所瘫痪，而共产主义未能给人们一根足够的胡萝卜，使他们有意愿去努力、去进步。您们生而平等，这也在圣经的文字里。权力应当使您们生来在财富上大致平等。……为避免这一点，必须废除财产，却不因此而建立共产主义。这世界不是您们的，这也写在圣经里。您们只是它的承租人。这样，一切财物都应租用四十九年。这废除了遗产的不公。您们的遗产，您们子女的遗产，如果您们懂得组织起来把它变得宜人，那便是整个世界。人类的这一政治取向不是共产主义；它关切人类的未来；如果您们想给它一个名字，就叫它人道主义。
{% end %}

其运作机制以房贷顾问般的耐心逐一推演。一个人二十一岁完成学业，租下一所房子四十九年，到七十岁便无负担地拥有这份租住权；他死后房子归还共同体，唯独家庭住宅除外，他的子女可以永久居住。功劳被刻意保留了下来——文本举了两个儿子的例子，一个勤劳，一个懒惰，并让勤劳的那个发家致富：

{% library(book="the-book-which-tells-the-truth", chapter=6, verse=9) %}
勤劳的那个会很快比懒惰的那个挣更多的钱。他那时便能租一所贵两倍的房子来代替头一所。……但他死后一切都归还共同体，唯独家庭房屋归他的子女。在某种意义上，一个人能为自己、按其功劳发财，但不能为他的子女。各人有其功劳。
{% end %}

一切有价值之物——土地、企业、股票、黄金、建筑——都属于共同体，并以最长四十九年的期限，回租给那些挣得了财力的人（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=10) %}TBWTT 6:10{% end %}）。接着，文本做了一件在它这一体裁中不寻常的事：它援引先例。它说，四十九年的期限「在圣经里已有规定」，并大段引用利未记 25 章——七乘七计算的安息年，以及其下的土地保有原则：*「地不可永卖，因为地是我的，你们在我面前不过是寄居的、作客旅的」*（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=13) %}TBWTT 6:11–13{% end %}）。人道主义把自己呈现为一种复原——禧年以行星尺度重新颁布。它所陈明的先决条件就是第六章的其余部分：掌权的天才，他们「会明白这些改革的用处」；以及一个单一的世界政府，配以一种新的世界货币和一门共同的第二语言（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=16) %}TBWTT 6:14–16{% end %}）。

1975 年的讯息加上了第二条轴。第一本书改革的是保有权，第二本书攻击的则是劳动本身：

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=37) %}
科学与技术不仅能把人完全从世界饥饿的忧虑中解放，还能让人无须有工作的义务而生活，因为机器借助自动化完全能够独自承担日常的劳作。……这些做五百人工作的奇妙机器，必须使这五百人能够生活，而不是用来养肥唯一的一个人：老板。
{% end %}

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=38) %}
任何人都不应处于另一人的服务之中，也不应为换取薪水而为另一人工作。机器完全能做劳作并承担所有工作，使人能够专注于他被造来做的唯一之事：思考、创造、开花。……劳动当它不由别的、只由勉强糊口谋生的必要所驱动时，没有任何神圣之处，把自己出卖，就这样出卖自己的生命以便能够通过做单纯机器能做的工作来吃饭，甚至是极其卑贱的。
{% end %}

《钥匙》一章把先后次序讲得清清楚楚。每个人都有权体面地生活，无论劳动与否（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）；贡献更多的人可以拥有更多，而这「显然是一条暂时的规则，在等待人类能够让机器人执行一切低贱劳作、以便在完全废除金钱之后唯独专注于自己绽放的期间」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=96) %}ETTMTTP 3:96{% end %}）；在过渡期间，一种单一的世界货币取代各国货币（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=162) %}ETTMTTP 3:162{% end %}）；而工程上的优先事项以一条诫命的形式陈述：「请尽一切努力去创造那将把你们从低贱劳作中解放、使你们能够绽放的生物机器人」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=100) %}ETTMTTP 3:100{% end %}）。雷尔后来把这一纲领写进了运动自己的计划。在第三本书中回答读者提问时，他在运动的目标里列入了一座研究中心，其关于「创造生物机器人的工作，将使劳动得以消除，从而也使金钱得以消除」（{% libref(book="lets-welcome-the-extraterrestrials", chapter=1, verse=24) %}LWTE 1:24{% end %}）——这是他本人的观点，而非口述文本。

正典还声称有一个范本。被问及创造者们自己世界上的生活时，耶和华描述了一个已经完成这一纲领的文明：

{% library(book="the-book-which-tells-the-truth", chapter=7, verse=45) %}
所有人都「工作」，但因为他们想要，鉴于我们这里没有钱。这样，那些「工作」的人所做的事总是做得很好，因为是出于天职而做。只有永恒者有非常确切的使命，例如对处理诸如能源、食物、组织等生命攸关问题的电子大脑和计算机的监视。
{% end %}

在母星上，城市是一座座公里尺度的单体建筑，每座由一位建筑师设计，「一种立方体，以便不像您们那里那样『吃掉』乡野」；一个由{% wiki(slug="council-of-the-eternals") %}七百名永恒者组成的议会{% end %}监管着自动化的基底，服务于七十亿居民，而这些居民没有任何义务去做任何事（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=47) %}TBWTT 7:39–47{% end %}）。在第二则讯息所描述的永恒者的行星上，约九万个生物机器人服务于九千多一点的居民（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=54) %}ETTMTTP 2:53–54{% end %}）。在框架之内，这正是这套学说*之所为*：地上的纲领是一件运行中原件的副本。第三本书中所叙述的那场相遇，以同样的措辞提出了这个问题。耶和华在那里说，议会中的怀疑者{% wiki(slug="satan") %}撒但{% end %}「不会相信能对人类有任何好的指望，除非他们团结起来，并销毁金钱与一切武器」（{% libref(book="lets-welcome-the-extraterrestrials", chapter=2, verse=76) %}LWTE 2:76{% end %}）。那一章是否算作口述的讯息，在本计划中尚无定论；如果算，那么废除金钱便与解除武装并列，成为这一物种所欠下的两项证明之一。

因此，这套学说有两条轴。第一条是**禧年轴**：以保有权取代所有权，生而平等，功劳在一生之内得到奖赏，没有任何东西跨代复利增长。第二条是**机器轴**：自动化吸收劳动，劳动不再是生存的代价，货币在它所配给的匮乏消失之时随之消亡。本文其余部分逐一走过这两条轴在人类中的谱系——那些思想者无从接触这一框架，彼此大多也互不知晓，却一再抵达同样的两项改革。

## 不可卖的土地

禧年轴是较古老的一条，它的主根正是正典自己所引的那段文本。利未记 25 章命令以安息年来计算年份——七乘七——到了释放之年，土地便归还原主：土地的买卖实际上是按剩余收成次数定价的租赁，「因为地是我的，你们在我面前不过是寄居的、作客旅的」。这项指令是否曾被执行，尚有争议{{ footnote(id="4") }}；无可争议的是它*是*什么——对积累起来的持有物的一次周期性重置，建立在这样一个前提之上：大地本身不是商品，而是托付之物。

现代的重新发现始于十八世纪法国的重农学派，他们论证一切纯财富都可追溯到土地，并提出 *impôt unique*，即单一的地租税{{ footnote(id="3") }}。他们的继承人——尽管他是独立得出这一论证的——是亨利·乔治，一位旧金山的印刷工兼记者，他眼看着加利福尼亚的地价远远跑在工资前面暴涨，于是在《进步与贫困》（1879）中追问：为什么贫困随着财富一同增长？他的答案是，地租——位置所带来的不劳而获的增值——吞噬了进步的收益；与这一答案一同到来的，是一项外科手术般精准狭窄的补救：按土地的全部租值征税，废除其他一切税种，而对改良物、工资与企业一概不动。功劳保有功劳所创造的一切；共同体只取走无人创造之物。这本书的影响力怎么说都不为过；并非其门徒的盖泽尔，以一个竞争者的嫉妒记下了这一点：「Georges Buch erlebte die größte Auflage, die ein Buch je erlebt hat」——乔治的书达到了有史以来任何一本书都未曾达到的发行量。本文所倚重的那部学术文选冷静地给出评断：乔治「无疑成为了『左翼自由意志主义』在他那个时代以及对后世而言最受欢迎的阐述者」。

把乔治的切分与正典的切分并排放置，几何形状是一样的，只是半径不同。两者都把劳动的果实留给劳动者；两者都把不劳而获的基础归还共同体。乔治把线划在土地上。人道主义则把线划在一切之外——「股票、黄金、企业、现金、房屋，一切能有价值的」（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=10) %}TBWTT 6:10{% end %}）——并以一座时钟而非一项税收来执行：四十九年的归还。乔治把一道流量社会化，正典则给存量设定了期限。

## 高原上的园子

《进步与贫困》问世十一年后，一位名叫特奥多尔·赫茨卡的维也纳经济学家兼财经记者出版了一部起着招股说明书作用的小说。《自由之地：一幅社会未来图景》（*Freiland: Ein sociales Zukunftsbild*，1890）以海牙一次公开集会上成立的一个协会开篇，其宗旨是对「社会问题之解决作一次实际的尝试」——一个承诺「同时实现完全的自由与经济的正义」的共同体，保证「每一位劳动者完整而不受削减地享有他自己劳动的果实」（引文为本文自译，下同）。定居者们乘船前往赤道东非的高原，在肯尼亚山与乞力马扎罗山之间，那里的土地是 *herrenlos*——无主的——他们在那里依照四条规则建立起一个社会：土地上不存在任何所有权，「无论个人的还是集体的」，土壤「像空气一样自由」；由一家中央银行向任何人预付无息的营运资本；任何人都可随意加入或退出的生产者协会；以及妇女、儿童、老人与丧失劳动能力者的赡养权，其理据是每个人都在「无数前代人的脑力劳动」这份遗产中拥有一份。地租、利息与利润从未被禁止。它们只是因暴露在外而死去——「我们对利息的禁止，并不比对雇主利润或地租的禁止更多，」银行的董事向一位心存怀疑的英国访客解释道，「这三种收入在这里之所以不存在，原因很简单：从来没有人处在不得不支付它们的境地。」赫茨卡笔下世界大会上的发言者，用一句足以为整份卷宗作题记的话陈述了目标：早先的尝试之所以失败，「是因为它们想要确立贫困的平等；我们的尝试将会成功，因为它意味着富裕的平等。……艺术与科学以丰裕与闲暇为前提。」

这部小说有两个细节，在其经济学之外对本计划具有意义。第一个是一个名字。远征队抵达肯尼亚冰川之下的山谷时——「放眼望去，这片土地宛如一座园子，但人还不曾占有这座乐园」——一位定居者宣称，天使长那把发火焰的剑已消散在瀑布的水雾之中，并为此地命名为**伊甸**。第二个是这本书所引发的事情。数月之内，「自由之地」协会便在欧洲各地纷纷涌现；它们组织的唯一一支远征队在 1894 年于非洲海岸被挡回，运动随之解散{{ footnote(id="5") }}。然而在这本书的细心读者中，有另一位维也纳记者。特奥多尔·赫茨尔在《犹太国》（*Der Judenstaat*，1896）的开篇，便把自己的计划与赫茨卡的作了比较——他写道，《自由之地》是一件巧妙却「复杂的机器」，齿轮众多，却没有证据表明它能被开动起来——而赫茨尔所发起的定居运动，于 1909 年在加利利海畔的德加尼亚，造出了赫茨卡只曾想象过的东西：一个真实的共同体，土地共有，生产共有，没有工资。基布兹成了现代记录中历时最长的自愿共同所有制实验——马丁·布伯所说的「没有失败的实验」——直到 1980 年代的债务危机把运动的大部分推向私有化{{ footnote(id="6") }}。一个世纪的运作，到头来又重新接纳了市场：基布兹卷宗以缩微的形式，同时包含了禧年轴所作的承诺，以及正典的功劳租约被设计来回应的那个激励问题（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=95) %}ETTMTTP 3:95{% end %}：「在出发点、在诞生时人与人之间必须有平等，但其后则不然」）。

## 会腐坏的货币

盖泽尔读了乔治，宣布诊断是对的，工具却是错的——土地税是「披着狼皮的羊」，地主们乐于称赞，因为它根本无法执行；何况土地只是问题的一半。另一半是货币本身。他的《自然经济秩序》（*Die natürliche Wirtschaftsordnung*，1916）把缺陷定位于一种寻常到无人注意的不对称：每一种商品都会腐坏，货币却不会。农夫的土豆会烂，报纸会过时，所以它们的主人必须出售；持有黄金的人却可以等待，并为不等待而收费。按盖泽尔的分析，利息是能够扣留的一方所征收的一笔通行费：

> Der König steht am Schlagbaum; er sperrt die Grenze und sagt: der
> Zehnte ist mein! Der Geldgeber steht vor dem Geldschrank; er sperrt
> den Austausch der Waren … und sagt, wie der König: der Urzins ist
> mein!
>
> *国王站在关卡的横杆前；他封锁边境，说道：什一税是我的！放贷人站在钱柜前；他封锁那些依赖钱柜之内容作为媒介的货物之交换——并且像国王一样说道：基本利息是我的！*
>
> ——*Die natürliche Wirtschaftsordnung*，第 5 部分

补救之道以逻辑学家的傲慢从诊断中推出：让货币会死。

> Geld, das wie eine Zeitung veraltet, wie Kartoffeln fault, wie Eisen
> rostet, wie Äther sich verflüchtigt, kann allein sich als Tauschmittel
> von Kartoffeln, Zeitungen, Eisen und Äther bewähren. … Wir müssen also
> das Geld als Ware verschlechtern, wenn wir es als Tauschmittel
> verbessern wollen.
>
> *唯有像报纸一样过时、像土豆一样腐烂、像铁一样生锈、像乙醚一样挥发的货币，才能证明自己是土豆、报纸、铁和乙醚的交换媒介。……因此，如果我们想把货币改良为交换媒介，就必须把它作为商品变得更差。*
>
> ——*Die natürliche Wirtschaftsordnung*，第 4 部分

这就是 *Freigeld*——自由货币——而沃格尔便是它的田间试验。盖泽尔把它与他自己的一套「自由之地」方案相配（全部土地经拍卖公开出租，地租按母亲们子女的人数逐月分发给她们——一种以子女为基准的基本收入，提出于 1916 年），又配上一个国际货币协会（International Valuta Association），即一个拟议中的世界货币联盟，把这一体系带过国界。他的鲁滨逊·克鲁索寓言让整套理论浓缩为一句话——一个落难者的储藏日渐腐烂，而一个新来者的借贷请求却在复利增长，落难者终于看清了：「Wieviel Beweiskraft doch die Ratten, Motten und der Rost haben!」——*老鼠、蛀虫与铁锈，竟有如此的证明力！* 凯恩斯在《通论》第 23 章中权衡了这一切，承认其机制（「加盖印花之货币背后的理念是健全的」），提出了异议，说盖泽尔「只建构了半个利率理论」，并以一句属于这份卷宗题记的话描述了这项事业：「建立一种反马克思主义的社会主义……其基础是解放竞争而非废除竞争。」大西洋彼岸的欧文·费雪说得更直白：「我认为自己是西尔维奥·盖泽尔的一个谦卑的学生。」

正典的货币纲领与盖泽尔共享同样的阶段划分，然后把他甩在身后。两者都规定以单一的世界货币作为过渡工具——正典说得明明白白：「在等待能够废除金钱的期间，创建一种取代各国货币的新的世界货币。这正是货币危机的解决办法」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=162) %}ETTMTTP 3:162{% end %}）。两者都把货币视为一件已经逃离其功能、必须被制服的工具。但盖泽尔想要的是被完善的货币——市场运转得比黄金所允许的更快、更干净——而正典则把即便是被完善了的货币也视为脚手架，待机器人到来时便要拆除。盖泽尔把利息淹死在资本的海洋里；正典则把海水抽干。

## 公共大地上的自我所有者

在二十世纪的大部分时间里，禧年轴在经济学中作为一种怪癖存活下来，在哲学中则几乎销声匿迹。它在学院中的复权到来于 2000 年，那一年彼得·瓦伦泰恩与希勒尔·斯坦纳出版了两部文选，其共同的序言读来就像为这整份卷宗所写的使命宣言：「当下在社会主义经济体系与自由放任的资本主义经济体系之间寻找一条新的、令人信服的『第三条道路』，与政治哲学中在不受约束的平等主义理论与右翼自由意志主义之间寻求一条融贯的『第三条道路』相平行。我们相信，左翼自由意志主义正是所需要的理论。」其定义是一台两个分句的机器：

> 左翼自由意志主义的正义理论主张，行动者是完全的自我所有者，而自然资源以某种平等主义的方式被拥有。……自然资源——那些并非任何人之选择的结果、且为任何形式的活动所必需的资源——只有在社会成员许可之下，或向他们支付一笔可观的补偿，才可以被私人占有。
>
> ——瓦伦泰恩，《左翼自由意志主义入门》（2000）

你拥有你自己以及你所造的一切；你未曾造出的大地属于每一个人。这两部文选沿着一场两个世纪的接力追溯这一立场——格劳秀斯与普芬多夫论原初共有，洛克论自我所有，土地激进派奥格尔维与斯彭斯，托马斯·潘恩的《土地正义》（1796）及其以地租为资金、在二十一岁时发放的普遍禀赋与五十岁起的养老金（记录中第一件具有全民基本收入形态的工具），欧陆的「自由社会主义者」科兰与于埃，赫伯特·斯宾塞的平等自由法则，乔治、瓦尔拉斯、里尼亚诺——而编者在史学上的论点，正是本文一再触及的那一点：「问题与相互竞争的立场一直保持着惊人的恒定。」

这一学派有两步棋直接落在正典的学说上。弗朗索瓦·于埃主张，一个人完全拥有的只是他所创造或挣得之物；他仅仅*继承*来的东西，在他死时应归还「公共遗产」——这就是人道主义的遗产规则，陈述于 1853 年。而斯坦纳则把废除遗赠奠基于权利的形而上学：「死者没有权利，因此左翼自由意志主义不必、而且可以论证不应承认……遗赠的效力。一个人死时所拥有的任何资产，都被视为遭到放弃。」四十九年租约恰恰把这一直觉付诸操作，而家庭住宅的例外则是它对情感所作的唯一让步。该学派的第三位成员菲利普·范帕里斯，把这份共同份额转化为一道永久的现金流——一份由一切「被给予」而非被创造之物的租金所资助的基本收入，就业租金也包括在内——从而提供了正典的过渡规则（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）所指向的那件过渡工具：作为一项权利的体面生活，贡献另有奖赏。主要的差别在于范围与时钟。哲学家们把*非造之物*归为公有；正典则把一切归为公有，并让功劳持有其中任何一部分，最长不超过一个劳动生涯。

## 作为有机体的城市

机器轴有它自己的先知，他在佛罗里达灌木丛中一处二十五英亩的园区里工作。雅克·弗雷斯科——一位自学成才的工业设计师，他的《金星计划：一种文化的重新设计》（*The Venus Project: The Redesign of a Culture*，1995）是五十五页配有插图的整体系统——从正典第二则讯息开始的地方开始：自动化（用他自造的词来说是「控制自动化」，cybernation）不可逆转地吸收劳动；他在同样的高度上得出同样的结论：障碍就是货币秩序本身。「货币体系是许多年前演化出来的，作为在资源有限的环境中控制人类行为的一种手段，」他写道；「只有在资源稀缺时，货币才能被用来控制它们的分配——比如说，人们无法在海滩上出售沙子或海水。」他把他的替代方案命名为资源型经济：「资源型经济利用现有的资源而非货币，并提供一种公平的方法，以最高效、最人道的方式为全体人口分配这些资源。」他所援用的思想实验，是盖泽尔会认出来的那一个的倒转——毁掉这件工具，看看还剩下什么：

> 如果世界上所有的钱都被销毁，只要表土、工厂和其他资源完好无损，我们就能建造任何我们选择建造的东西，满足任何人类需求。人们需要的不是钱，而是自由获取大多数必需品的途径，而不必向政府官僚机构或任何其他机构求告。
>
> ——*The Venus Project*，第 5 页

交付以建筑的形式到来：圆形城市按同心圆带布局，由一个他称为城市之「电气自主神经系统」的「控制自动化系统」运行，所有权被图书馆式的取用中心所取代，决策「通过统计力学得出」，由技术人员而非政客作出，「整座城市作为一个单一的、复杂的有机体运作」。读过正典第七章的读者会觉得这份规格似曾相识。耶洛因的城市是边长一公里的单体建筑，每座都「由同一位建筑师构思」，呈立方体，「以便不像您们那里那样『吃掉』乡野」，其生命系统——能源、食物、组织——由计算机在永恒者的注视下监管（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=47) %}TBWTT 7:45–47{% end %}）；地上的纲领则出于同样陈明的理由，规定在开阔的田野中建造可容五万人的共同住宅：一个遍布带花园之独栋住宅的行星，就不再有乡野了（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=101) %}ETTMTTP 3:101{% end %}）。两种无货币的、控制自动化的、爱惜自然的城市有机体，在相隔不到二十年的时间里被分别规定出来，其作者之间没有任何可信的传递链条。弗雷斯科甚至不动声色地擦过了本计划主题的天花板：「当世界上一些顶尖的科学家试图探测银河系的外缘以寻找有智慧的外星人时，金星计划目前更关心的是运用人类的智慧来解决地球上的问题。」他的封底则少了几分戒备，称这处佛罗里达园区为「第二个伊甸」。

## 心智的公地

对卷宗中迄今为止的每一位成员而言，丰裕都是一种投射。在一个领域里，它到来了；围绕它形成的那些制度，是卷宗中唯一既非计划也非小说、而是正在运行之基础设施的条目。当复制信息的边际成本降至零时，一套生产体系自行组装起来，而这是任何一本经济学教科书都未曾预言过的：林纳斯·托瓦兹 1991 年在 Usenet 上的一则帖子，成了全世界服务器与手机的软件基底，其许可证使任何人都永远无法把它圈占；不由任何特定之人撰写的维基百科，让一书架的付费百科全书退了休；而为这一现象命名为「对等生产」（peer production）的耶鲁学者尤查·本克勒，提供了它的算术——全世界联网的人口「每天共同拥有二十亿到六十亿小时的闲暇时间」，一座常备的、未被定价的产能水库。泰普斯科特与威廉姆斯的《维基经济学》（2008）记录了这一逻辑能延伸到代码之外多远：他们的重头案例是黄金公司（Goldcorp），一家濒临破产的多伦多矿企，其首席执行官被 Linux 的故事所激发，把五十年的专有地质数据公布在开放的网络上——「我们要请全世界告诉我们，下一个六百万盎司的黄金会在哪里找到」——随后看着来自五十个国家的参赛者识别出一百一十个目标，其中一半是公司未知的，五分之四有产出。公地的勘探胜过了公司。

这场运动产生了它的殉道者，而他的宣言属于这份卷宗的原始资料。「信息就是权力，」亚伦·斯沃茨在《游击式开放获取宣言》（2008）中写道，「但就像一切权力一样，总有人想把它据为己有。」{{ footnote(id="7") }} 他的论证——科学记录大体上由公共资金资助，属于每一个人，而把它圈占在付费墙之后，就是对这一物种之遗产征收的一笔私人税——是潘恩的地租论证向知识经济的移调：非造的公地，被占有了，便欠下补偿。正典对同一指令的表述，是向整个研究事业发出的：它主张，从物质束缚中解放只需短短几年，只要「一切技术与科学能力……不再为个别利益而是为整个共同体」奋力工作（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=99) %}ETTMTTP 3:99{% end %}）——对等生产，在 1975 年被提出作为通往黄金时代的捷径。本文献库作为{% wiki(slug="cyberparadism") %}赛博乐园主义{% end %}加以追踪的当代美学运动，把开源协作列为预示丰裕临近的六项征兆之一，与聚变能源和全面自动化并列；按这份卷宗的证据，这一排序是对的，因为开源是唯一一项已达工业规模的征兆。

## 技术—资本机器

卷宗最新的条目到来于 2023 年 10 月 16 日，出自所能想象的最不乌托邦的地址：一家风险投资公司的网站。马克·安德森的《技术乐观主义宣言》是五千字的首语重复——「我们相信」——而它关于丰裕的段落，可以剪接进弗雷斯科或正典的第二则讯息而看不出接缝。「我们相信，丰裕的尺度是价格的下降。」「我们相信，我们应当通过应用技术，推动整个经济的价格下降，直到尽可能多的价格实际上降为零。」「我们相信，如果我们让智能与能源都变得『廉价到无须计量』，最终的结果将是一切实物商品都变得像铅笔一样便宜。」{{ footnote(id="8") }} 这台引擎有一个名字，注明出处地借自哲学家尼克·兰德：「技术—资本机器，永久的物质创造、增长与丰裕的引擎。」敌人是一些观念——宣言自己的清单历数「生存风险」「可持续性」「ESG」「预防原则」「去增长」「增长的极限」——而文件以一串守护圣徒的名单代替引注收尾{{ footnote(id="9") }}。

与正典的趋同是具体的。两者都认为物质问题是可以解决的，而解决之道是科学；两者都把能源丰裕视为枢纽（聚变是宣言的「第二颗银弹」，也是赛博乐园主义六项征兆中的第一项）；两者都把关于极限的劝告看作关于衰落的劝告——正典自己的命令是「享受这地上的生命，科学能把它转变为乐园」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=39) %}ETTMTTP 2:39{% end %}）。随后两条路交叉，又铿然分开。安德森：「我们相信，全民基本收入会把人变成由国家饲养的动物园动物。人不是生来被饲养的；人生来是要有用、要有生产力、要感到自豪的。」正典：「每个存在都有权拥有足以生活之物，即便他不劳动」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=98) %}ETTMTTP 3:98{% end %}）——而在生计之鞭下所做的劳动是「极其卑贱的」，是出卖自己的生命去做「单纯机器能做的工作」（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=38) %}ETTMTTP 2:38{% end %}）。宣言坚称技术变革会「增加」对人类劳动的需要，并把永远靠市场运转的机器奉为神圣。正典则把同一台机器读作一只蛹：市场与货币是幼虫阶段的工具，而成体的形态——「思考、创造、开花」——之中没有价格体系。

卷宗中先前的一切都没有预示这一结果：*在这里，风险投资家是保守派，而那部 1973 年的接触者文本才是激进派。* 安德森所提供的丰裕，把雇佣劳动、价格与积累永久保留了下来——达到逃逸速度的资本主义。正典所提供的丰裕，则是让这三者全部溶解的溶剂。至于宣言的批评者，他们把它的政治读作比它的技术更古老——以斯拉·克莱因把它归入「反动的未来主义」，一份与其说关乎工具、不如说关乎这样一种信念的文件：「我们曾经勇敢而强壮，如今却变得软弱无力」；《雅各宾》则把它的谱系追溯到尼采式的贵族激进主义。批评者与宣言争的是*谁受益*；正典与它争的是*为了什么*。双方都不质疑那台机器。

## 一套学说，两条轴

并排摆开，这份卷宗便化为一张表格。每一位成员都持有一块碎片；正典的学说于 1973–75 年间被整体口授，同时持有全部碎片。

| 问题 | 人类的谱系 | 正典 |
|---|---|---|
| 谁拥有大地？ | 利未记的禧年；乔治的地租社会化；赫茨卡的无主土壤；左翼自由意志主义对非造之物的共同所有 | 「您们只是它的承租人」——一切资产归共同体所有，租用 49 年（TBWTT 6:7, 6:10） |
| 死后留存什么？ | 于埃的归还公共遗产；里尼亚诺的累进转移税；斯坦纳的被放弃资产；皮凯蒂的 r > g 警报 | 废除遗产，唯独家庭住宅除外（TBWTT 6:8） |
| 货币为何而存在？ | 盖泽尔的滞期费与世界货币；弗雷斯科的废除货币；费雪的印花券 | 世界货币作为桥梁，然后完全废除（ETTMTTP 3:162, 3:96） |
| 谁来劳动？ | 弗雷斯科的控制自动化；本克勒的对等生产；宣言的人工智能与机器人 | 机器与生物机器人；劳动仅出于天职（ETTMTTP 2:38, 3:100; TBWTT 7:39） |
| 人应得什么？ | 赫茨卡的赡养权；潘恩的禀赋；范帕里斯的基本收入 | 作为一项权利的体面生活，无论劳动与否（ETTMTTP 3:98） |
| 人为何而存在？ | 「丰裕与闲暇」作为艺术与科学的前提（赫茨卡） | 「思考、创造、开花」（ETTMTTP 2:38） |
| 谁来决定？ | 弗雷斯科的技术人员；宣言的创始人；哲学家们的正义制度 | 天才政治，然后是最低限度监管之下的自动化基底（TBWTT 6:5, 7:45） |

在它自己的家族之内，有三项特征使正典的条目与众不同。第一，完整性：它是唯一同时运行两条轴——禧年与机器——的成员，作为一个纲领，财产改革被明确安排为过渡体制，自动化则被明确安排为这一体制的退场。第二，早出：关于自动化的段落早于个人计算机；那些过渡规则预先提出了——有时一字不差——一些立场（基本收入、遗产归还、世界货币），而这些立场在学院与政治上的浪潮要到数十年后才达到顶峰。第三，也是在种类上独一无二的，是范本主张：卷宗中每一位人类成员都是从理论或外推出发进行论证，而正典声称的是描述——一个已把这一纲领运行到底的文明，正把地上的副本作为它的「政治与人道行囊」提供出来，它说，这份行囊可以转交，而不会带来科学行囊所伴随的那种危险（{% libref(book="the-book-which-tells-the-truth", chapter=5, verse=65) %}TBWTT 5:65{% end %}）。最后这项主张，恰恰是本计划的标签之所以存在的原因：它是 `framework`——明载于来源之中，任何档案都无从核实，也是这场比较之所以有趣而不仅仅是整齐的原因。

## 诸种读法分道扬镳之处

一份如此趋同的卷宗，难免招来经过挑选的嫌疑，所以分歧与失败应当以其全部力度陈述出来。

**这份记录是一份失败的记录。** 沃格尔在十四个月后被法院命令关闭。「自由之地」运动死在肯尼亚海岸，连行装都没来得及打开。盖泽尔的伊甸作为一处园林郊区延续下来，而不是作为一种经济秩序；他在一个注定覆灭的苏维埃共和国担任财政代表的那一周，以一场叛国审判告终。基布兹在村落尺度上建成了一个世纪的可运作的共产主义，随后在债务与代际漂移之下，大多重新接纳了工资与市场。金星计划始终没有越出它的二十五英亩。开源征服了它的领域——而它的领域恰恰是商品可以免费复制的那一个；它的维护者如果有报酬的话，至今仍由它所绕开的那个货币经济来支付。卷宗中的每一项实验，要么一直很小，要么被国家叫停，要么重新接纳了市场。正典会回答说，这正是在低于文明尺度上施行所预期会出现的特征——它自己的学说把世界政府与天才政治的管理列为先决条件（{% libref(book="the-book-which-tells-the-truth", chapter=6, verse=14) %}TBWTT 6:14{% end %}）——但批评者有权把这听作乌托邦主义者最古老的逃生条款：设计是可行的，只要满足一个历史从未提供过的前提。

**计算问题并未被消解，只是换了平台。** 米塞斯与哈耶克对计划的异议——价格承载着分散的知识，任何管理者都无法收集——击倒了二十世纪每一次以意图来运行经济的尝试，而它以全部的力度适用于弗雷斯科的统计力学，也适用于正典中监管「能源、食物、组织」的计算机（{% libref(book="the-book-which-tells-the-truth", chapter=7, verse=45) %}TBWTT 7:45{% end %}）。如今流行的反驳——足够规模的机器智能*就是*那台缺失的计算器——恰恰是 2020 年代的现场赌注，而且胜负未分。座次表中有一处反讽：哈耶克位列安德森的守护圣徒之中，这就把卷宗中最坚定的丰裕运动，置于这样一位思想家的庇护之下：他的论证恰恰禁止了卷宗大多数成员所瞄准的那个无货币的终点。

**天才政治是这套学说最陡峭的悬崖。** 以智力为门槛的选举权，冲击着民主平等的道德核心，而主流政治哲学拒斥一切形式的「由被测量者统治」；那些异议——谁来编制测验，谁来审计编制者，「原始智力」究竟指称什么——都是标准的异议，而且都很有力。文献库把这条诫命视为方向性的而非操作性的，而雷尔本人在第三本书中回答读者时，把这一纲领的实现交给了非雷尔派的政治运动，并与之保持距离（{% libref(book="lets-welcome-the-extraterrestrials", chapter=1, verse=87) %}LWTE 1:83–87{% end %}），这一立场是他本人的，而非口述文本。这一切都没有消解那项异议。它在此以它自己的口吻被记录下来。

**正典给它自己的丰裕留了余地。** 这份卷宗的正典地层中最奇特的一句话，是一个限度。在讨论人类是否会继承创造者的角色时，耶和华说道：「我们不确信人是否曾能在丰裕中稳定下来」（{% libref(book="the-book-which-tells-the-truth", chapter=5, verse=59) %}TBWTT 5:59{% end %}）——而稍后的一则讯息，在第三本书中作为耶和华致人类的讲话刊出，把这一物种通过自身考验而存活的几率定为百分之一（{% libref(book="lets-welcome-the-extraterrestrials", chapter=2, verse=96) %}LWTE 2:96{% end %}）。这套学说并不是丰裕必将到来的承诺；它是一份规格说明，规定了一旦攻击性首先被克服之后应当建造什么。对这份卷宗的阳光读法——丰裕即命运——属于安德森，卷宗中再没有别人持有它。

**而卷宗的成员都是他们时代的人。** 乔治的运动分裂为单一税殖民地与市政运动；赫茨卡的非洲是探险文学中那个空旷的非洲，只在测量者的想象中才是无主的；盖泽尔的代表作带有他的现代研究者加以删除的时代修辞{{ footnote(id="10") }}。这部谱系是作为一种反复出现的思想结构的证据而提出的，而不是作为一个圣徒的团契。

## 他们一再栽种的园子

卷宗中有一个模式，不是其中任何人计划出来的。赫茨卡的定居者抵达冰川之下的山谷，把它命名为伊甸。盖泽尔在一处名叫伊甸的改革殖民地写作他的经济学，并死在那里。弗雷斯科在佛罗里达灌木丛中的园区被宣传为「第二个伊甸」。三位彼此独立的丰裕建造者，伸手去取一个名字时，取到的是同一座园子——在那里，供给先于劳动，果实在任何人挣得它之前就已挂在树上。主流读法把这个名字看作乐园的显而易见的文化简称，事实也的确如此。文献库的读法则深入一层：在正典中，{% wiki(slug="eden") %}伊甸是一处真实的设施{% end %}——创造者们的实验室园地，一种被设计出来的丰裕，这一物种便在其中起始——而创造者们自己的世界至今仍以它的经济学运行（{% libref(book="extraterrestrials-took-me-to-their-planet", chapter=2, verse=52) %}ETTMTTP 2:51–52{% end %}）。在框架之内，改革者们反复出现的园子，是一段记忆把自己演算为一份计划：本文所读的这份卷宗，是一个物种从匮乏的内部，逆向工程出它被创造时所处的运行条件。这是一个建立在 `inferred` 模式之上的 `framework` 读法，两个标签都适用。然而这个模式本身就在原始资料之中，一字不差，出现了三次。

框架最后添上的是赌注。正典的{% wiki(slug="golden-age") %}黄金时代{% end %}是一把叉子的一个叉齿，而它的另一个叉齿——本计划的{% wiki(slug="apocalypse") %}启示{% end %}词条所记录的自我毁灭——是默认会抵达的。机器轴正在飞奔：1975 年的文本所许诺的自动化，在大模型与人形机器人的这个十年里，已是一项资本支出的预算条目。禧年轴却没有：财富以皮凯蒂的 *r > g* 所奠定为经典的速率跨代集中，而地球上没有任何一个政体在辩论一份四十九年的租约。这份卷宗从利未记到那份宣言所作的诊断是：第二条轴是一项选择。赫茨卡以 1890 年的自信说出了这一点：如今没有任何东西迫使我们忍受一种过时世界秩序的苦难，没有任何东西阻止我们获得现有文明手段所能提供的幸福与丰裕——「nichts, als unsere eigene Thorheit.」*除了我们自己的愚蠢，别无其他。* 正典在 1975 年说得更简短，那句话是对一个刚刚造出机器、却尚未决定它们为何而用的物种说的：

{% library(book="extraterrestrials-took-me-to-their-planet", chapter=3, verse=99) %}
你们能在几年内造出一个完全不同的世界。你们已抵达黄金时代。
{% end %}
